# Qt 型线图试点：第一轮结果

> 本页前半保留第一轮记录。独立场景入口及首开优化的后续测量见文末“第二轮：移除旧窗口绘制”。两轮计时范围不同，不直接拿旧 `model_to_scene_ms` 与新首帧字段相减。

日期：2026-11-01。结论：完整矢量场景加 GPU 批量填色值得继续验证；普通 Qt CPU 画布本身不能解决复杂模型的交互开销。首开链路还不具备替换正式版的条件。

## 交付内容

- 程序：`../dist/FreeShipQtPilot.exe`，中文界面，支持读取 FBM、右键平移、滚轮缩放、全图、填色开关、PNG 和原核心 DXF 导出。
- 桥接组件：`../dist/bridge/FreeShipGeometryBridge.exe`。FBM 复制到私有临时目录后读取，用户模型和正式程序不写入。
- 最终报告：`../../FreeShip-Tests/reports/qt-pilot-delivery-20261101/report.json`。
- 基准源码与桥接构建：`../../FreeShip-Tests/reports/qt-pilot-acceptance-20261101/bridge-build/`，包括 `legacy-source.zip` 和适配器指纹。交付轮明确复用这份指纹匹配的构建。
- 测试已接入 `FreeShip-Tests/run_tests.py --suite qt-linesplan`。

这里的“原版”指当前本地 Pascal 工作树，包含此前的修改，不是把所有现状归因于上游作者。

## 检查结果

盒体、合成曲面、9a 实际模型各测试原始版和控制点 Z+0.01 副本。148 项 pass，12 项 review，6 项 not_run，没有 fail/error，总状态为 partial。

通过的检查包括：采集前后原版像素一致；双精度坐标和 UTF-8 标注往返一致；放大 30 倍、平移、还原后无填色丢失；有裁剪和无裁剪的图像一致；合成右键和滚轮事件；可见标注不重叠；150% 绘制；损坏文件拒绝；改点导致新场景；独立进程结果稳定；交付程序实际隐藏加载及导出路径；原模型、产品源码和正式可执行文件保持不变。

独立 CPU 逐图元绘制与 GPU 结果在 9a 有 306 个边缘像素差异，纯色内部差异为 0；合成曲面分别为 613 和 0。保留原始图像，不把不同后端的边缘光栅化称为逐像素完全相同。几何坐标及 DXF 没有走 GPU 舍入。

## 交互耗时

1280×800 离屏绘制，本机 Intel UHD Graphics 770。每组平移/缩放各 120 次；CPU 回退对照为 30 次。GPU 耗时包含帧缓冲读回、Qt 线条和文字绘制。数据不包含真实鼠标排队及桌面合成，不能直接写成显示器 FPS。

| 原始模型 | 填色三角形 | 平移中位数 / P95 | 缩放中位数 / P95 | 同场景 CPU 回退中位数 / P95 |
|---|---:|---:|---:|---:|
| 盒体 | 192 | 1.12 / 1.32 ms | 1.24 / 1.64 ms | 1.37 / 1.53 ms |
| 合成曲面 | 137,472 | 5.91 / 6.38 ms | 5.97 / 6.56 ms | 48.49 / 54.41 ms |
| 9a | 143,940 | 7.03 / 7.87 ms | 7.52 / 8.47 ms | 40.81 / 60.48 ms |

小场景自动使用 CPU，避免为少量三角形付出 GPU 初始化及读回开销。9a 的三角形数量是多个投影及对称展开后的绘制数量，不是原始模型面数。

## 首开仍然慢

9a 场景读取约 82.9 ms、整理约 26.6 ms、GPU 初始化约 183.1 ms，第一次离屏绘制约 446.7 ms。第一次绘制包含尚未分开的绘制系统和文字初始化，不能把它全部归因于某一项。持续操作数据是热状态，不能用它代表首开。

交付程序隐藏加载、一次绘制及测试导出总流程约 2.16 秒。报告中该观测值的字段名仍是 `model_to_scene_ms`，但计时结束点实际包含测试 PNG/DXF/场景写出，应按此完整范围解释，不能当作真实桌面点击到显示耗时。

桥接为了建立基准，仍进行旧窗口完整准备和一次观测重绘。下一步应拆出不依赖窗口的纯场景生成入口；同时拆分首帧初始化成本。当前版本不应以“首次生成更快”为理由替换正式程序。

## 未完成项

- 真实鼠标、窗口显示、不同 DPI 与不同 GPU 的桌面验收。
- 标注视觉质量。拟合视图中 9a 的 140 个标注显示 78 个，拥挤数字会隐藏，缩放后重新布局。它们不移离自己的刻度，纯平移不重新排版。
- 计算核心 C++ 化、局部控制点增量生成/上传、自动持久缓存、其他窗口、打印、镜像和灯光交互。
- 已发现当前屏幕水线投影与 DXF 路径有差异，见“试点边界与验收”。保存旧行为只提供对照，不能代替船舶几何的独立正确性验证。

下一轮建议先做实际交互检查，然后拆出纯场景生成入口。只有这两项有可靠结果，再扩大迁移范围。

## 第二轮：移除旧窗口绘制

用户反馈试点平移、缩放体验顺滑。本轮继续处理首次打开，原正式版 `FreeShip.exe`、Win+R 的 fs 和用户模型未改动。

`bridge/FreeLinesplanScene.pas` 提供 `TLinesplanScene.Generate` 和 `ExportDXF`。前者直接生成完整矢量场景，后者保留原导出计算。生产桥接不再创建主窗口、型线图窗口或视口，不调用 `PrepareForDisplay`、`ViewportRedraw`，也不生成旧位图或填色图集。仅保留 1×1 画布取得与旧版一致的字体度量。模型构造时附带的两个编辑对话框和日志异常窗口也在桥接专用构建中移除。

旧入口保存在 `FreeShip-Tests/QtLegacyBridge.pas`，每轮测试仍从相同当前源码构建。拆分过程见 `bridge/extract_scene.py`，提取来源见 `scene-origin.json`。模型浮点类型、求交、曲线采样、三角形排序和遮挡次序没有改动；没有降精度，也没有使用截图代替场景。

### 同轮首开对照

最终报告：`../../FreeShip-Tests/reports/qt-startup-delivery-20261101/report.json`。它复用初次对照报告 `qt-startup-scene-20261101` 中指纹匹配的新旧桥接构建，并补充同一 Qt 程序下的首张图像对照。每个模型运行三对独立桥接进程，新旧顺序交替，使用私有模型与设置目录；系统文件缓存未清除。以下是桥接进程从启动到输出场景及 DXF 后退出的中位数，不含 Qt 显示。

| 模型 | 旧桥接 | 独立场景桥接 | 减少 |
|---|---:|---:|---:|
| 盒体 | 402.2 ms | 171.9 ms | 57.3% |
| 合成曲面 | 1,328.9 ms | 395.8 ms | 70.2% |
| 9a | 1,646.1 ms | 606.7 ms | 63.1% |

9a 新桥接分段中位数：加载及重建 184.6 ms、独立场景生成 194.4 ms、DXF 生成 136.6 ms。各项中位数不能直接相加当作总中位数；进程启动与退出另有成本。旧桥接还要准备型线图窗口和再绘制一次，这两项已经移除。

另外用同一个 Qt 可执行文件，只替换私有运行目录里的桥接组件，走真实加载入口到首张完整离屏图像。每种入口、每个模型各测一次，因此以下是成对观测值，不是中位数。

| 模型 | 旧桥接到首图 | 新桥接到首图 | 减少 |
|---|---:|---:|---:|
| 盒体 | 892.9 ms | 775.8 ms | 13.1% |
| 合成曲面 | 2,338.2 ms | 1,271.0 ms | 45.6% |
| 9a | 2,489.9 ms | 1,441.5 ms | 42.1% |

9a 该次新路径包含桥接 589.7 ms、场景读取 86.2 ms、整理 29.2 ms、GPU 初始化 172.6 ms、首张图像绘制 559.0 ms；验证导出另外计时，约 93.7 ms。这不是显示器实际呈现延迟，也不包含清空系统缓存后的冷启动。初次对照报告的首图为 1,512.5 ms，实际 `dist` 路径的隐藏交付检查为 2,025.4 ms，其中首张绘制占 973.2 ms，说明初始化耗时有明显波动。首帧中的字体及绘图初始化尚未进一步拆开，不能宣称已经瞬间显示。

### 精度、导出与交互

238 项 pass、23 项 review、6 项 not_run，没有 fail/error，总状态为 partial。覆盖盒体、合成曲面和 9a 的原始模型及改点副本；完整 FSLP 与当前旧入口、上一轮冻结结果均逐字节一致。同一 Qt 程序通过新旧桥接加载后，保存的首张 PNG 逐像素一致。

DXF 的完整实体、精确坐标、顶点连接、图层和颜色一致；没有放宽数值容差。盒体中若干折角线实体的排列或遍历顺序不同，字节比较单列 8 项 review。原因已追到 `FreeSubdivisionSurface.inc` 的 `ExtractAllEdgeLoops` 与 `FasterList.pas`：旧流程按指针地址排序，移除窗口对象后内存分配顺序发生变化。新比较器保留完整折线分组及属性，同时用坐标、颜色篡改负例验证，不只比较一堆线段。Qt 保存的 DXF 另与该次桥接原文件逐字节一致。9a 和合成曲面的 DXF 本轮与旧基准字节相同。

现有填色、缩放恢复、裁剪、标注、鼠标锚点和导出回归继续通过。9a 连续平移离屏中位数 7.96 ms，缩放 7.46 ms；纯色内部差异为零。真实桌面呈现、不同显卡及主观可读性仍不由这些测试代替。实际交付路径的隐藏检查另见 `qt-startup-scene-20261101/installed-verification/delivery-checks.json`，7 项检查通过，旧程序已备份到试点 `build/backups/20261101-scene-entry`。

后续优先看首帧的字体/绘图初始化，以及是否需要将 DXF 准备从首张显示路径移开；局部增量生成和自动磁盘缓存尚未在 Qt 试点中实现。
