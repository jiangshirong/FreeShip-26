# FreeShip_26：Qt 型线图试点

这是迁移验证程序，不替换正式版 FreeShip。保留 Pascal 计算核心，用 C++/Qt 6.8.3 显示型线图，测试数据边界、交互成本及回归方法。

## 运行

双击 `dist/FreeShipQtPilot.exe`，选择 FBM 文件。右键拖曳平移，滚轮以鼠标位置为中心缩放，“全图”恢复视野。“保存图片”导出当前视图的 PNG，“导出 DXF”保存 Pascal 核心产生的结果。

也可以把 FBM 文件路径作为启动参数，或打开测试报告中的 `scene.fslp` 矢量场景。后者是明确保存的中间数据，不是已经实现了内容校验、自动失效的用户文件缓存。

原模型先复制到临时目录，旧计算组件以独立进程读取副本。计算期间窗口事件循环继续运行。模型编辑、撤销、打印、灯光及其他窗口不属于本次试点；填色开关只控制显示，不改变 DXF 内容。

## 数据路径

```text
FBM 副本 → Pascal 模型加载 → TLinesplanScene.Generate
           ├─ FSLP 双精度三角形、线条、标注 → C++ Scene
           │                                ├─ GPU 一次上传完整填色三角形
           │                                ├─ Qt 绘制线条与文字
           │                                └─ 相机变换驱动平移/缩放
           └─ reference.dxf → 原样安全写入用户选择的导出路径
```

GPU 每帧绘制完整场景到离屏缓冲，读回图像供 QWidget 合成。这仍有读回成本，后续可以比较直接呈现；当前没有把等待移到后台的模糊截图。文字每帧以当前设备分辨率绘制，标注避让仅在缩放时更新，平移只加偏移。拥挤时部分标注会隐藏，所有原始标注仍在场景内。

场景生成入口位于 `bridge/FreeLinesplanScene.pas`。它直接输出三角形、折线和标注，不创建主窗口、型线图窗口或视口，也不绘制旧版位图。原有浮点运算类型、采样与排序保留；FSLP 用 Float64 传输，不表示原计算核心已改成双精度。标注度量仍使用一个 1×1 字体画布。

三角形按原顺序提交，保留遮挡次序；GPU 显示顶点使用相对模型中心的浮点数，原始场景保留双精度。超高倍率回退 CPU，DXF 不经过 GPU 坐标。GPU 不可用时也回退 CPU，复杂模型可能明显变慢。

## 构建与测试

工具链：Qt 6.8.3 MinGW 64 位、MinGW 13.1、CMake、Ninja、Python 3.11、已有 Lazarus/FPC。工具链放在 `.tools`，MinGW 实际文件放在 `%LOCALAPPDATA%/FreeShip26QtTools`，避开旧编译器对中文路径的限制。`build.ps1` 建立两个经过目标校验的临时目录联接，只改变构建路径，不搬动源码。

```powershell
.\setup.ps1 # 首次准备工具链
.\build.ps1 -Deploy
python ..\FreeShip-Tests\qt_linesplan_pilot.py --output ..\FreeShip-Tests\reports\qt-pilot-new-run
```

统一测试入口：`python ..\FreeShip-Tests\run_tests.py --suite qt-linesplan`。

测试在隔离副本内分别构建旧窗口对照入口和独立场景入口，保存原源码快照、二进制指纹、模型副本、旧版截图、DXF 和 Qt 截图。候选程序部署在报告目录的 `runtime` 中，通过检查后再交付；测试不替换 `dist`。`--model` 可以重复指定真实模型，`--baseline` 可与上次报告再次对照，`--startup-repeats` 控制成对启动次数。测试操作的是私有对象和事件，不操纵用户桌面。

报告中的 `partial` 表示仍含 `review`/`not_run`，不能解释为全面通过。实际鼠标、显示合成、显卡差异和人工可读性需要单独验收。

## 不应据此得出的结论

- Qt 窗口能显示，不代表计算核心已经迁移到 C++。
- DXF 相同说明旧导出路径被保留，不证明新的 C++ 导出器正确；本次没有实现新导出器。
- 改控制点后的场景重新生成，证明新数据能被显示，不代表局部细分或局部上传已经实现。
- 帧耗时改善不能当作首次打开改善。旧版绘制已移除，进程启动、几何生成、场景解析、GPU 和字体初始化仍分别有成本。报告将首张离屏图像和测试导出耗时分开记录。
- DXF 折角线列表原先按指针地址排序。移除窗口对象后，实体排列或折线遍历方向可能改变；测试比较完整实体、精确坐标、连接关系、图层和颜色，同时单列字节差异。Qt 导出仍原样复制桥接结果。
- 保留原版行为不等于原版行为都是正确的。屏幕绘制与 DXF 有各自的基准，差异需要单独审查。
