# 型线图曲线采样与投影来源

`linesplan.h/.cpp` 直接依据当前 Plus 的 `Units/FreeSpline.inc:GetValues` 和
`Forms/FreeLinesplanFrme.pas` 中活动的 `DrawSpline`、`AddSpline` 改写。
没有采用 ShipCAD 的绘图实现。沿用原 FREE!ship/Plus 的 GPL-2.0-or-later，
署名和完整许可见文件头及项目 `COPYING`。

这里只产生曲线的布局坐标：侧视 XZ、前后体 YZ、俯视 XY。原点和中剖面位置
由调用方提供；三角填色、文字、斜剖线投影、自动布局及完整文档生成不在此接口内。
显示沿用输入采样数；导出顶点沿用原 `AddSpline` 的 100 点采样和折角插入规则。
输入点和采样数不被导出修改。前后体显示保留控制点 X 范围及中剖面的包含判断；
导出辅助函数保留原有“调用方决定哪一体”的约定。

俯视显示有明确修正：原 `DrawSpline` 将横坐标写成 `Origin.X + YSign * P.Y`，
而且镜像支路使用 `YSign=0`，不会生成正确的对侧曲线。候选使用 XY 坐标并翻转 Y，
与原 `AddSpline` 的导出投影一致。有斜剖线时不生成额外俯视镜像，保留已有开关约定。
此变化须在测试中以旧显示错误公式、正确 XY 投影和实际旧导出顶点三方核对。

`GetValues` 的采样字段此处表示点数，而平面求交接口把它当区间数。至少两点的
曲线若采样数为 0 或 1，候选明确拒绝；空或单点输入返回空路径。保留原样条求值
精度和折角插入次序。原插入规则在稀疏采样下可能跳过多个中间折角，这一限制
仍待处理，不能以本批兼容检查代替精度保证。坐标溢出拒绝，不发布半条路径。

Pascal 对照从原文件提取实际活动例程。显示例程逐字保留，在像素投影前读取
坐标；导出例程仅加入四个只读回调，移除回调后必须还原原字节。
未采用独立重写的 Pascal 投影公式充当参考。详细验证结果见
`docs/migration/NATIVE-LINESPLAN-CURVES.md`。
