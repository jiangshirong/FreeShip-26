# 曲面剖切与交线拼接来源

`sections.h/.cpp` 是独立的 C++17 计算候选，输入为已验证的静态控制网、
同一版本的细分结果和原始平面系数。本轮只覆盖
`Surface.IntersectPlane → CalculateIntersections → JoinSplineSegments`。
没有替换正式计算入口，也没有迁移完整 `Intersection.Rebuild`、镜像、
交线简化、静水力、绘图、缓存或导出。

## 来源与许可

实现按本工作区当前 FreeShip Plus 的活动代码改写，使用标准 C++ 容器和
索引。ShipCAD 不是本模块的实现依据；没有为保持“借用”形式而引入其类、
界面或旧文件读写。

## 保留的计算语义

`intersectSections` 先用控制网包围盒筛选，再按图层顺序和该层根控制面顺序
检查子网范围。普通模式只看 `useForIntersections`，静水力层模式只看
`useInHydrostatics`；可见性、对称标记和 `showInLinesplan` 不在此改变筛选。
独立 `calculateSections` 入口按调用者明确给出的根面顺序工作，不额外套层
或全局范围筛选。

当前静态输入保留全局控制面顺序和层号，可以还原重新加载文件时的
`Layer.Items` 顺序。任意已经编辑的旧对象可能有不同的层内插入顺序；本轮
没有声称这种未导出的历史顺序也相同。生产接入还须由文档 ID、版本和完整
输入保证两个参数同源，不能仅凭数组长度判断快照没有过期。

第 0 级保留旧 Surface 的行为：没有子面，所以不生成剖切曲线。全局范围
采用有边或面关联的原控制点，孤立点不参与；新建空表的范围为 `[0,1]^3`，
只有孤立点的新对象保留原点零盒。旧活动对象里可能残留的范围不在静态输入
契约内。根面的范围来自实际子面；第 0 级来自原控制面。

面内计算按原始有向点循环，从末点到首点开始。原来的 float/Single 落点、
插值方向、交点重数、折角标记和边身份均保留；不以规范边端点次序改写插值。
全共面边只在拓扑边界或至少一个邻面不共面时加入，且按边身份只加一次。
多于两个命中点时仍按原循环顺序连接相邻命中点，没有擅自改成三角剖分或
另一种配对算法。

拼接分为两步：先以相同边身份和距离连接，另处理相邻共面边；之后才是
旧的几何近邻拼接。原函数从最后一个片段开始，扫描顺序、等距优先级和
重启位置都会影响结果，本模块保留这些规则。规范 ID 只替代对象身份，
没有按坐标排序，更没有先调换曲线方向来凑对照结果。

旧常量的实际含义如下，没有换成更宽松的容差：

| 位置 | 活动判断 |
| --- | --- |
| 盒相交 | 严格跨零/含零，不按面内阈值扩盒 |
| 边严格穿面 | 方程值分别严格小于 `-1e-5`、大于 `1e-5` |
| 整边共面 | 两端绝对方程值均 `<=1e-5` |
| 单点命中 | 绝对方程值 `<1e-5` |
| 同边连接与近重复端点 | 实际点距 `<1e-4` |
| 判断曲线闭合 | 实际点距 `<1e-5` |
| 几何拼接 | **平方点距** `<JoinError`；Surface 传 `0.01`，不是距离小于 `0.01` |
| 近邻搜索提前命中 | **平方点距** `<1e-5` |
| 碎片删除 | 包围盒对角线平方 `<1e-3`，不是弧长；只在进入拼接前有多条曲线时执行 |

平面系数不归一化，因此面内 `1e-5` 是代数方程值阈值；同一几何平面换
一组缩放系数，近面分类可能变化。`JoinError` 是 Single 参数，其他比较
保留原常量对应的精度。编译禁用 fast-math 和浮点融合。前面的“几何拼接”
不检查来源图层或连通分量，也保留了原策略可能连接附近独立片段的行为；
这不是新的拓扑正确性保证。

`fragments` 随 Add/Insert 提升到至少点数减一。合并时保留固定曲线原值并
按合并后点数提升，不接管来源曲线更大的 fragments。输出的 closed 是从
当前坐标重新计算的字段，不相信调用者传入的旧标志。

## 明确修复的旧问题

`FreeSpline.InsertSpline` 的两个前插分支先向旧下标写入共享点折角 OR，
随后复制源点和折角时又覆盖了这个位置；真正共享点已经被后移，折角可能
丢失，所选源端点也与实际匹配端不一致。

例如固定曲线 `(0,0)→(1,0)` 没有折角，来源曲线 `(-1,1)→(0,0)` 的末点
有折角。两条前后拼成一条后，共享 `(0,0)` 应保留折角；旧函数会丢掉它。
候选在前插完成后向实际共享下标写两端 OR，后插也使用实际匹配端点。
原坐标、点顺序和阈值不改。旧 oracle 保留原行为，独立预期要求保留折角，
这种差异单列 review，不用调基准掩盖。由于折角影响样条形状，本模块尚不
能据此直接替换正式导出。

`CalculateIntersections` 另有一处 `Move` 按 `SizeOf(T3DCoordinate)` 移动
含 Point/Knuckle/Edge 的完整记录数组，字节数不足。候选改用整条记录删除，
不会模拟内存破坏。输入面要求唯一点和完整边拓扑；该异常分支是否在某种旧
非法拓扑上可达须独立证明，不能把静态发现说成已在用户模型中复现。

## 输出与安全边界

结果保留四个阶段：`segments` 原始切段、`connectedCurves` 拓扑连接后的链、
`joinedCurves` 几何拼接后但尚未删碎片的链，以及最终 `curves`。原始端点带
边 ID，直接命中网格顶点时可另带顶点 ID；片段带面和根控制面 ID。曲线的
`sourceSegments` 是带方向的原始片段编号，仅作候选诊断，不伪造旧 oracle
未记录的身份。

所有输出重用入口在临时局部结果中完成计算。成功时整份替换，成功空结果
会清除旧结果；发生异常时保留调用者原结果。直接拼接也采用相同事务语义。
会检查点/边/面的索引、重复点边、子面次序、根面层号、边面邻接、有限值和
数量上限，拒绝无效平面及不可表示的数值结果。没有声称这些检查证明了任意
手工构造快照的几何流形性或与原控制网完全一致。

本模块没有为统一状态而提前调用旧 Spline.Rebuild/Simplify，也没有复现
上层 `Intersection.Rebuild` 的简化开关、缓存和绘图副作用。该上层仍需另一批
独立对照；这批测试只确认所写明的计算入口和安全变化。
