# 原生交线简化

2026-11-01。本批由主代理独立完成，复用剖切阶段的构建、Pascal 探针和报告程序。
`Spline::simplify` 是独立候选里的显式接口，正式型线图和导出尚未调用它。

实现直接对照当前 Plus 的 `Units/FreeSpline.inc:313`，保留原来的权重、删点顺序、
严格小于阈值的判断及相邻权重更新。没有引用 ShipCAD 的简化实现。
无缓存时只累加弦长，不求解随后会失效的样条系数；修改成功后才替换对象，
非法阈值或计算溢出不会留下删了一半的曲线。采样段数不变。

## 发现的旧行为

- **调用顺序影响结果。** 原函数直接使用 `FTotalLength`。刚建立的曲线若尚未
  重建，这个值为零，简化直接返回失败。候选自行取得弦长，同一输入不再因为
  是否先读取过曲线而产生不同结果。129 点直线的冷、热调用都留下 12 点；
  旧版冷调用保留 129 点，热调用留下 12 点。此变化单列待看。
- **折角的保护权重不是永久保护。** 原函数用 `1e10 / 总弦长²` 代表不可删点。
  尺度足够大时仍会低于阈值。三个点 `(0,0,0)`、`(100000,100000,0)`、
  `(200000,0,0)`，中点标记折角、阈值为 2，旧版会删掉中点。
  候选明确保留折角。两种结果都用独立输入的旧样条核对采样，差异没有隐藏。
- **原权重不是几何误差上界。** 邻点距离小于 `1e-5` 时，中点权重直接归零。
  `(0,0,0)`、`(1,0,0)`、`(1e-6,0,0)` 这个例子会把长折返删掉。
  本批保留并记录这项已有行为，没有把“与旧版一致”写成精度安全。

首次及删点后的相邻权重计算仍遵循 Single 中间量；平方弦长在 Single 下为零
时返回失败。当前最小权重查找和数组删除仍可能达到平方级复杂度，尚未声称
这一步已经做过性能优化。以后更换算法要先确定误差约束及完整导出预期。
