# M2 独立复核：工程设置、图层与多点移动

日期：2026-11-01。M1 的 Qt 程序已经获得用户实际使用认可。本轮检查工程设置、已有图层属性、框选和批量移动；不新增、删除点线面，也不把其余功能算作完成迁移。已认可的 `dist` 留作基准，新候选通过检查后才替换。

本文先记录从当前 Lazarus 源码核实的语义和迁移风险。实现状态与测试结果分别列出，不能把读过代码当作运行通过。旧产品源码和用户文件不在本轮改写范围内。

## 字段含义

| 字段 | 实际含义 | 旧代码位置 |
|---|---|---|
| 长、宽、吃水 | 公制 m，英制 ft。直接修改是修改工程参数，不会按比例缩放船体。吃水还会使流线失效。 | `FreeProjectSettings.inc` 的 `FSetProjectLength/Beam/Draft` |
| 单位 | 改变数值表达，保持物理船型。需转换锁定点、剖面平面偏移、标记、图层材料、静水力和阻力计算输入；不能只转换快照中的点。 | `FreeProjectSettings.inc:FSetProjectUnits`，`FreeEdit.inc:Model_Scale` |
| 水密度、材料密度 | 公制 t/m³，英制 lb/ft³；不是 kg/m³，也不是 long ton/ft³。换算因子为 `1000 × 0.3048³ / 0.45359237`。 | `FreeGeometry.pas` 常量；`FreeGometry_Functions.inc:DensityStr` |
| 板厚 | 公制 mm，英制 in，换算因子 25.4。图层重量还要按单位除以 1000 或 `12 × 2240`。 | `FreeGometry_Functions.inc:LenMMStr`；`FreeLayerDlg.pas:SelectLayer` |
| 中剖面位置 | 与坐标同单位，允许负值；使用默认值时取工程长度的一半。不能把它限制在模型包围盒内。 | `FreeProjectSettings.inc:FGetProjectSplitSectionLocation` |
| 附体系数 | 无量纲；单位切换不改变。水密度转换与排水质量 tonne/long ton 转换是两件事。 | `FreeProjectSettings.inc:FSetProjectUnits`，`FreeGometry_Functions.inc:VolumeToDisplacement` |
| 图层可见、型线图显示、参与交线 | 三个独立标志。`visible` 对应 `SurfaceVisible`；不能顺带改 `ControlNetVisible` 或 `UseForIntersections`。旧型线图中的填色/折痕受 `ShowInLinesplan` 控制，剖面交线仍有独立来源。 | `FreeSubdivisionLayer.inc` 各 setter；`FreeLinesplanScene.pas:CalculateExtents/Generate` |

设置窗口切换单位时，应先转换窗口中的长度、密度等值和标签；按取消不提交。一次提交同时带单位与数值时，数值属于目标单位，服务先完成整体换算，再应用显式填写的参数。原 `FreeProjectSettings.Edit`、`FreeProjectSettingsDlg.UnitboxChange` 也是这个顺序。

数值仍受原核心 `TFloatType = Single` 的精度约束。Qt 使用 double 不代表计算核心已经改为双精度。只改备注或图层名时，不应把未改的数值按界面显示小数位重新写回。

## 新界面代码复核

已读 `project_dialog.cpp`、`layer_panel.cpp`、`main_window.cpp`、`model_session.cpp` 和 `hull_view.cpp`。下列处理已在代码中核到；M2-d 另有 81 项实际 Qt 控件测试通过，真实桌面操作仍待验收：

- 工程设置使用独立草稿，只提交改动字段。数值没有改过时，不从显示文本反写。单位切换先在草稿中预览，取消不调用服务。
- 发现初版名称框的 4096 字限制会截断已有名称，备注控件也可能把 CRLF 规范化后误认为用户修改。现已取消初始化截断，并记录显示基准，避免开窗后无关改动连带改写旧文本。
- 发现图层草稿在单位转换后超出编辑框范围时会静默变成边界值。现已单独保存未截断的草稿值，提交前报告越界。
- 单位、属性和批量命令通过原有串行会话提交。新快照先交给视图和面板，再恢复编辑；失败回包保留旧模型。图层面板等待中的草稿不会因为恢复按钮而提前丢失。
- 四视图按源控点 ID 选择，图层隐藏后剔除不可见选点；新文档清空选择，新版本取消旧拖曳。显示镜像没有生成新的可编辑 ID。

界面正确显示草稿不等于文件已经更新。图层需要按“应用”，工程设置需要按“确定”；服务失败后不能以草稿文本代替保存回读证据。

## 多点移动的边界

单点 `SetCoordinate` 会传播到锚定点、约束点，并可能移动选中控制点组。直接对选择集依次调用它，可能重复移动或因遍历顺序不同得到不同结果。`Coordinate` 属性则不走这些依赖传播；它不能无条件替代单点编辑语义。

本轮约定：批量请求涉及锁定点或任何锚定/线性约束关联时，整个请求拒绝，不能先改一部分；不相关的点仍可批量移动。单点入口继续保留原有依赖行为。服务应同时检查关联的两端，而不只检查被移动点自身是否写有 AnchorPoint。协议校验应先完成，再做任何赋值。

现有 `ModelService.BindIds` 已一次计算正反关联资格并导出 `batch_movable`；`BatchMove` 先检查全部 ID、重复项、资格和坐标，再赋值。视图和坐标面板也使用该标志提前拒绝整组移动。后端检查仍是最终约束，前端过滤不构成编辑权限。

框选和镜像只是视图选择：同一源点不能因为对称显示被放入请求两次。拖动期间收到单位切换或新模型版本时，旧的拖动起点不能继续提交。选择集应按文档身份和稳定 ID 更新；请求失败后显示模型恢复到已确认的快照。

## 独立验收清单

- 仅改名称/备注/颜色，未修改的浮点坐标和参数原样保留；取消、同值提交保留撤销/重做边界。
- 改主尺度不改变控制点；改吃水更新绝对水线高度和型线图填色。默认中剖面随长度变化，自定义中剖面可为负值。
- 公制↔英制检查独立物理量和常量，包含锁点、四类剖面、标记、图层厚度/密度、背景 Scale、流线种子及原有计算输入；撤销、重做、保存重开一致。
- 每个图层属性独立修改，另测复合修改、大小写改名、全部隐藏、全部关闭型线图显示，以及保留未开放的旧属性。
- 老版本 FBM 修改新字段后保存重开，字段和单位不丢失；旧源文件字节保持不变。
- 批量移动既有正常集，也有重复 ID、未知 ID、锁点、锚点正反关联、线性约束正反关联、非法坐标、陈旧文档和版本；错误项放在末尾仍必须零局部修改。
- 一次批量移动仅有一步撤销；点线面数量和引用关系不变。失败回滚后仍可继续编辑、撤销、保存。
- 保存和产物生成失败保留旧版本、旧历史和修改状态；正常操作后对新服务重复生成、undo/redo/reopen 的 FSLP 与 DXF 仍执行既有严格比较。

JPEG 复核证据：[服务请求与回包](../../build/m2-core-05/jpeg-check/service/protocol.jsonl)。本审查另行只读提取了 `input.fbm` 和 `2/4/6/8/10/12/saved.fbm` 中唯一的 JPEG，各份 SHA256 均为 `30f8297a573449b5ad37c8e258d9dca09a7ad4e4b0078f7a049351458288e0f1`。操作包含公英转换、撤销、重做及同一服务中的新文档重载；这条证据不冒充进程重启测试。

还有两项补核需要关联到 [STATUS.md](STATUS.md) 的补充报告：批量移动资格目前已执行正反顺序拒绝，但还应把服务 `batch_movable` 与专用样本中独立扫描的关联资格逐点比对；纯大小写图层改名也需要专门保存回环。这两项不计入上面的 M2-d 数字。

实际框选、拖动手感和窗口布局仍由真实使用验收；M1 的用户认可不替代 M2 新控件验收。新增点线面、其余计算模块和完整 Pascal 核心迁移均不在本轮完成范围内。
