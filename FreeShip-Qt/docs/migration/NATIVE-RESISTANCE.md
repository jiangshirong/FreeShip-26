# C++ 阻力计算

2026-11-03。十个阻力入口的参数装载、船体参数提取、公式、求解器协议、
后处理和曲线已移入 C++。现有 Qt 参数窗口、报告导出和型线图保持原来的入口。
这一步没有重写外部求解器，也没有把经验公式的对照测试当成船模试验认证。

| 入口 | 执行方式 |
|---|---|
| Delft、KAPER | C++ 计算 |
| Holtrop | C++ 公式；可选海况修正和 1984 报告仍调用原程序 |
| Hollenbach、Fung–Leibman、van Oortmerssen | C++ 参数及后处理，调用原求解器 |
| OST、圆舭高速艇、多体船 | C++ 流程，调用 hship 及原数据库 |
| 滑行艇 | 前三种方法在 C++ 中计算，其余已实现方法调用原程序 |

入口是 `src/document/resistance.cpp`，返回 `analysis_engine=cpp-resistance`。
旧适配器拒绝为正式文档执行这些请求，只保留独立对照用途。
船体参数由原生静水力模块提取，补入了水线入水角、球鼻艏截面及水线范围。
有不对称计算层而无法提供必要系数时会说明原因，不拿零代替缺失数据。

公式和原报告通过 `FreeShip-Tests/maintenance/port_resistance.py` 离线转换为
普通 C++。程序运行时不需要 Python 或 Pascal 翻译器。生成文件保留数组上下界，
访问越界会报错；来源和哈希在 `resistance-origin.json`，`--check` 可复核生成结果。
文件、进程、取消、缓存和原生静水力调用由手写的 C++ 入口管理。

Win64 FPC 的 `Extended` 是 64 位，不能直接用 MinGW 的 `long double` 替换。
某些恰好可表示的常量还会使旧表达式按单精度运算。迁移保留这些舍入位置；
曲线对照仍要求坐标精确相等，没有通过扩大容差消除差异。
编译器行为的探针保存在 `FreeShip-Tests/qt/resistance_math.pas`。

## 修正的流程问题

- `FreeResistance_HoltrDlg.pas::CorrectInputData` 在给 `Tc` 赋吃水值之前，
  就调用了依赖它的湿表面积估算。自动估算可能除零。新版先设置吃水，
  另用独立公式核对估算值。
- Holtrop 的 `PowerPrd.EXE` 输出报告后还等待回车。旧调用关闭输入后仍会等待；
  新版发送回车，检查退出状态，再读取报告。保留了直接运行求解器的对照。
- `FreeResistance_PlaningDlg.pas::CalculateInWorkspace` 三行格式用了逗号，
  `Nwj`、`Ct`、`Cp` 显示成了“0f”“3f”。新版显示实际数值。
- 多体船不使用的两项艉型字段，旧标签清空后会显示输入框的“1.00”。
  新版保留字段名称和禁用状态。
- OST 等旧输入数组有未赋值的尾部槽位，新版零初始化，避免把内存残值送入求解器。
  原适配器已有的剩余阻力数组清零、滑行艇有效点数校验和多体船编号检查继续保留。

每个请求使用独立目录。停止计算会终止所属求解器；服务退出时 Windows 进程组
负责清理子进程。输入输出检查大小、数字数量和有限值。缓存按文档及修订号隔离，
重算失败后不再让推进计算读取旧阻力；成功后才发布完整结果。

## 验证与尚未覆盖的范围

`FreeShip-Tests/run_tests.py --suite qt-performance` 已包含
`qt_native_resistance.py`。它核对三份模型、默认值、船体提取、参数保存、英制输入、
十项主样例、系列分支、真实求解器文件，以及坏输出、运行中取消和缓存失效。
停止私有旧适配器后，再执行原生默认参数与计算。原有 Qt 回调继续检查报告、CSV、
PDF，以及计算前后的型线图和 DXF。隐藏回调不替代真实桌面使用验收。

本次样例不能为全部旧选项提供数值证据：Ridgeley–Nevitt 拒绝当前样例，
Neyman/Eroshin 没有得到可用求解结果，多体船列表后五项在原代码中直接提示不可用。
这些项保留 `not_run`。滑行艇 Almeter 原来就没有实现，仍明确提示未提供。
外部程序与数据库只引用本机目录，不随安装包再分发。

完整回归还拦下了一个迁移遗漏：有效点不足四个时，不能只警告后返回已有的
部分曲线。现在在原适配器相同的位置抛出错误，失败时不发布阻力缓存。
旧 CLEMBLOU 在过长的工作目录下会在最后一行输出 NaN。同一份输入改用短目录后
输出有效且一致，长短目录各四次的独立复现已保留。新版使用独立的短临时目录；
旧数值对照也单独用短目录执行，仍完整比较曲线，未跳过失败或自动重试。
这解决了调用环境问题，没有改写外部求解器本身。
