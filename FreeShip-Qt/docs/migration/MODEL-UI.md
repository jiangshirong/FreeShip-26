# 建模窗口和视图交互

2026-11-04。

图层属性从窄侧栏移到独立窗口。左侧列出图层，右侧编辑属性，上方保留新建、
清理空层、上移和下移。透明度用滑块及百分数输入，面积、重量、重心随所选图层
显示。沿用 StudioLight 字体、配色和原图标。

透明度、排序进入 C++ 文档事务，可以撤销、重做并保存到 FBM。排序保留面的
图层归属及当前活动层，不重新分配当前会话里的稳定 ID。重新打开文件按文件
中的顺序恢复图层；会话 ID 不作为文件身份。透明度显示为整数百分数，但未修改
时保留原始 alpha 字节，不因显示舍入改写文件。

面积和重心取当前细分曲面的三角形，按面积加权；对称层面积翻倍、横向重心归零。
公制重量为吨，英制为 long ton。面积积分按快照和所选图层缓存，修改名称、板厚
或密度不会重复扫描三角形。旧窗口禁用的“手动重量/重心”没有搬成可用功能。

“显示此图层的控制网格”只改当前视图状态，不保存进 FBM。隐藏某层控制网后，
其他可见层仍使用的共享点、边继续显示，船体填色不受影响。

不透明填色沿用原 GPU 路径。半透明填色使用缓存的软件光栅化，在每个像素按实际
深度合成，避免相交曲面按三角形中心排序产生错误。共享边采用半开规则，防止
同一条边叠加两次透明度。此路径没有降低网格精度，但大型半透明模型转动时仍可能
比不透明 GPU 模式慢；不能拿不透明模式的帧率代表它。

点菜单增加“放置控制点”，保留按坐标输入。点击纵剖面时 Y=0，俯视图时 Z=0，
横剖面时 X=模型最大 X，与旧 `DoAddPoint` 一致。新点自动选中，放置一次后返回
选择模式。流线保持连续添加，Esc 或右键退出；原源码里的 Alt 手势已被注释，
不按可用旧功能迁移。

四视图右键菜单补上适合窗口、缩放、线框/填色、当前视图 PNG 和打印预览。
图片取被调用的视图，包含完整标注；不会误取整个四视图面板。图片写入失败时
保留原文件。透视镜头档位、光源设置、斑马纹/高斯曲率/可展性着色仍未接入。

标注补上命名数值附近的刻度去重、首选位置/标签类型变化时缓存失效，以及暂时
完全遮挡后的恢复。保留已有边界弹簧逻辑。完整旧布局器仍有局部文字展开节奏
待核对，不能将这些规则通过等同于全部标注视觉一致。
