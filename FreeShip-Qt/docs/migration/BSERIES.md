## 指定雷诺数修正

在“敞水条件”中选择“指定雷诺数（论文修正式）”，输入 0.75R 处雷诺数，
单位为 10⁶。例如 20 对应 Re=2×10⁷；允许 2–2000，即 2×10⁶–2×10⁹。
输入值是用户给定的工况，程序不根据不完整的桨叶几何猜测它。整条曲线使用同一个
Re，改变转速、直径或流速不会自动改变 Re；计算书必须按实际工况核对。

原论文 Section 4 / Table 6 给出 ΔKT、ΔKQ，使用 `L=log10(Re)-0.301`。
这里 Re 是实际数值，不能把以百万计的输入直接代入对数。9 项 ΔKT 和 13 项 ΔKQ
一次合并为 J 的二次式，加到基准三次式；工作点、全部曲线、零点和效率极值
都使用修正后的同一多项式，求解不依赖画图采样。

作者在 Section 4 明确指出：回归式在 Re=2×10⁶ 处不严格为零。因此指定模式
包含下限处的原始拟合残差，没有额外归零或平滑处理。基准模式完全不施加修正式，
即使雷诺数输入框保留了其他值，也不会影响旧结果。这两个模式在下限处可能不同，
报告明确说明原因，并列出工作点的基准 KT/KQ、ΔKT/ΔKQ 和最终结果。

完整参数 JSON 保存两个选项；旧参数文件缺少选项时使用基准模式。
FBM 没有这两个字段，保存到船模只保存原有参数；重开 FBM 回到基准模式，
窗口提示使用“保存参数”保留完整工况。只保存这两个额外字段不修改 FBM、不新增撤销。

## 计算与输入

- 使用 Oosterveld / van Oossanen 1975 年的 39 项 KT、47 项 KQ 多项式。
  系数核对来源和尾数差异见 `FreeShip-Tests/fixtures/bseries/README.md`。
- 数字和中间过程使用 double。给定桨形后一次合并为 J 的三次式，曲线只做
  Horner 求值；工作点不从曲线反查。效率极值由导数方程全部实根比较得到，
  零推力、零转矩使用实根隔离，不受 0.001 绘图步距约束。
- 范围为桨叶数 2–7 的整数、Ae/A0=0.30–1.05、P/D=0.50–1.40、J=0–1.5。
  域外输入报错，不截断成另一个工况。整体回归范围内、但超出相应桨叶数试验
  面积比覆盖的组合会提示。输入速度单位 m/s，含义是桨盘处流速。
- 零流速保留为零，效率为零；不再自动改成 1 m/s。两叶桨可保存到 FBM 并重开。
  FBM 原格式仍用 Single，完整参数 JSON 保留输入 double，报告保留实际输入。
- 不再删除效率超过 .86 的候选值。效率超过 1、转矩先归零或最大值落在计算
  边界时分别说明。非推进区工作点保留 KT/KQ 和有符号载荷，效率为未定义。
- 推力用 kN，转矩用 kN·m，轴收到功率为 2πnQ，有效推力功率为 T·Va。
  水密度取当前工程设置，和船模使用同一单位约定。

## 验证与边界

统一入口：`FreeShip-Tests/run_tests.py --suite qt-bseries --runtime <候选运行包>`。
实现：`src/core/bseries.cpp` 和 `src/document/propulsion.cpp`。
测试：`FreeShip-Tests/qt_bseries.py`，保留数值依据、生成脚本和一次性资料核对脚本。

独立数值检查用高精度直接求和与 numpy 根算法，并核对公开图谱算例。
修正式另用 50 位 Decimal 的未合并原式和 Decimal 对数求值；独立根算法的
二次增量由三个点反求，不照抄 C++ 分组。上下限、紧邻下限、高精度 Re、几何尺度律、
模式/系列切换、无效输入及 FBM 部分保存均进入同一个 `qt-bseries` 测试。
六组旧基准结果从上轮已通过报告冻结，完整曲线摘要及原有数值字段要求完全一致。
正式 Qt 回调覆盖计算、参数往返、船模参数保存、图表显示和四种报告导出；
计算前后比较型线图场景和 DXF。其他系列与旧流程作原始曲线及报告对照。
这些隐藏回调不等于真实桌面验收，也不等于水池试验或实船性能验证。
