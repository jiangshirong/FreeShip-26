# 原生控制网与细分验证

2026-11-01。本轮建立了独立的 C++ 控制网与细分模块。计算输入直接来自当前
Plus 的控制点、边、面和曲线；Qt 显示快照不作为模型来源。它仍未接管正式应用。

## 实现选择

ShipCAD 是可选参考。本轮按当前 Plus 的有效计算规则重新组织数据和所有权，
没有搬入 ShipCAD 的对象体系或内存池。交叉阅读时发现它的全三角邻域平滑系数
用了平方根，而当前 Plus 用平方；本轮没有采用那段 C++ 公式，并以独立三角扇
例题验证这一分支。细节及署名见 [来源记录](../../src/native/SUBDIVISION-PROVENANCE.md)。

候选支持两种细分模式、三角/四边/n 边面、硬边、各类顶点、附面与独立控制曲线，
以及孤立控制点和裸边。每级结果保留有向拓扑和图层归属。图层显示/对称等标记
原样传递，这一层不镜像或删去输入面。完整约定见 [CONTROL-NET.md](CONTROL-NET.md)。

有几处不能凭旧注释实现：当前 Plus 主流程已禁用最终的 `LastAveraging`；每一级
是先分面，再同时更新所有点坐标。独立曲线第一轮只复制并平滑，下一轮才插入
中点。加载文件保存的点型、折痕也不能用编辑 setter 重新猜测。这些实际行为
分别进入对照用例。

## 缓存与失败处理

查询按需计算层级，已经得到的层级直接复用；继续请求更高层时从上一层计算网
继续细分。内部保留最新计算网和已有层级的只读结果。相同坐标修改不失效，
坐标实际变化后再按后续请求重建。当前不是邻域局部增量更新，也不是磁盘缓存。

失败的输入修改保留原状态。计算中溢出或数量超限不会发布半份新层级，已有低层
结果仍可用。查询返回的引用由候选对象持有，坐标修改后失效；未来接入正式模型
需要按既有不可变快照协议交付，不能把这些内部引用直接交给异步界面。

## 测试入口

```powershell
python FreeShip-Tests/run_tests.py --suite qt-native-subdivision --output FreeShip-Tests/reports/native-subdivision-new
```

统一入口会构建独立 C++ 程序和隔离 Pascal 探针，分别运行小网格、完整控制网
回读和真实模型逐级对照。几何算法的 14 个原文件保持原字节，探针的观察接口
与无界面适配单独记录。先验证导出输入能重现原对象，再比较 C++ 结果。

比较区分拓扑、有限 Single 数值、独立数学预期和原对象调试信息。数值没有经验
容差，JSON 无法保证的正负零位模式不作相同承诺。独立例题与旧实现共同存在的
舍入偏差保留为 `review`，不以新旧相同冒充数学上精确。

## 本轮结果

[最终统一报告](../../../FreeShip-Tests/reports/native-subdivision-final-20261101/qt-native-subdivision/report.json)
为 **1097 pass、0 fail、7 review、0 not_run、0 error**，总状态 `review`。
172 个层级对照中的 83,861 个有限 Single 重构值全部一致，有向拓扑没有差异。
覆盖 25 个小型控制网的两种模式，共 50 组，以及三个完整模型；真实模型按各自保存模式检查第 0—3 级，
两种细分模式及指定小例的第 4 级由独立夹具覆盖，不等同于所有模型都测过两种模式。

7 项待看分为两类：5 组独立数学例题保留新旧共有的舍入偏差，涉及三角面心、
五边面心和六价三角扇；另 2 项是旧对象在第 0 级残留之前细分等级的调试字段。
后者的完整控制网、坐标和拓扑均另行精确核对，没有用忽略整个对象来消除差异。
细节见 [独立复核](NATIVE-SUBDIVISION-REVIEW.md)。

旧平面/样条模块也按本轮最终源码重新构建，
[回归报告](../../../FreeShip-Tests/reports/native-geometry-subdivision-20261101-final/qt-native-geometry/report.json)
仍为 **397 pass、0 fail、7 review、2 not_run、0 error**；136 组可比结果的
72,529 个有限 Single 重构值一致，原有待看项和未覆盖项继续保留。

两组运行的源码、测试和二进制清单已核对。旧源码、输入模型、旧正式程序、
试点源码及两个交付目录的指纹均保持不变。这批仅新增独立计算目标，没有重新打包。

## 尚未覆盖

候选目前明确拒绝非流形边、同时经过附面与游离点的曲线、通过无面边跨接曲面的
曲线，以及重复经过同一条边的曲线。这些是当前支持范围，不代表旧程序都禁止它们。
静态输入也不包含完整编辑约束、撤销或 FBM 数据；正式计算服务仍持有完整文档。

旧核心在独立曲线首轮重建时会修改控制点类型和折痕，重复调用可能已面对另一份
控制网。本轮逐级基准每次重新载入同一输入，验证静态结果；候选保持输入不变。
因此这里不声称所有旧文档的调用历史都等价。接入实际编辑流程时，曲线规范化与
文档状态变化还要另行验证。

后续先接平面剖切和交线拼接，再与现有型线图、DXF 和其他输出核对。专业计算、
完整读写及正式入口切换另行推进。这一轮没有新的界面速度或帧率结论。
