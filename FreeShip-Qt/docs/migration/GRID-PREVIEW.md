# 型值输入预览

2026-11-04。Michlet 输入导出、AddMass 输入导出和 AddMass 计算窗口均增加「型值预览」页。
沿用当前 StudioLight 样式。打开这一页后生成网格，支持侧视、横剖、俯视和三维视角；
左键旋转、右键平移、滚轮缩放，双击或「全图」恢复范围。

## 数据与更新

预览使用 `grid_export.cpp` 在写文件时已经求出的半宽表，逐个数值与文件相同。
没有另算一份粗网格，也没有用控制网或屏幕截图替代型值。原导出 API 的调用方可不请求预览，
输出字节保持不变。AddMass 这里显示的是求解器的输入型值，最终面元仍由外部求解器生成。

每个片体显示两舷的横剖站和水线。单体、复制双体、已有双体提取沿用已验证的生成规则。
预览坐标使用米，X 从艉至艏，Z 从船底向上；双体在显示中心面的两侧摆放，间距保持实际值。
这只是观察坐标，Michlet 文件中以第一片体为原点的相对位置记录没有改变。

窗口首次显示预览时才启动后台生成；参数编辑有短暂合并间隔，未改变的完整请求复用已有结果。
镜头动作只更新投影，不启动型值生成器。每个保留点每帧只变换一次，按完整折线提交绘制。
最大支持 81×81、两片体共 26,244 个显示顶点，未通过删点或减小精度来改善速度。

参数变更立即标记旧预览；无效参数会显示具体原因，不把上一份图当作新结果。
工作完成时再次核对文档、版本及请求，过期结果不采用。每次任务使用独立临时目录，
关闭窗口或取消会结束预览进程。取消预览与导出、AddMass 计算互相独立。

主要代码：

- `src/core/grid_export.cpp`：原型值表的可选只读输出。
- `src/native/export_worker.cpp`：私有任务、文件校验值与版本标识。
- `src/render/grid_preview.*`：网格校验、两舷和片体布局、只读镜头与绘制。
- `src/app/grid_preview_panel.*`：延迟生成、更新、取消和旧结果标识。
- `src/app/exchange_dialog.cpp`、`performance_dialog.cpp`：三个实际入口。

布局参考 Plus 的 `FreeMichletOutputDlg.ViewportRedraw` 与 `FreeAddMassOutputDlg`，
绘图及异步任务为新的 Qt 实现；型值和求交精度仍沿用现有 C++ 生成器。

## 验证

统一入口：`python FreeShip-Tests/run_tests.py --suite qt-grid-preview --runtime FreeShip-Qt/dist`。
源码保存在 `FreeShip-Tests/qt_grid_preview.py` 和 `FreeShip-Tests/qt/grid_preview_tests.cpp`，
另复用原有文件格式解析器及 AddMass 样本构造代码。

独立尖艏样本核对半宽、长度、吃水、片体间距、公英制和双体中心面。
解析导出的每一个型值，与预览数值逐项精确相等；与解析几何的比较沿用既有 Single 坐标容差。
原导出与请求预览后的文件逐字节相同。还验证了真实船模 `9a-Женя.fbm`、过期版本、
非法参数、取消、旧预览保留、参数重算、文件保护、模型/型线图/DXF 不变，以及实际菜单和按钮。

镜头测试向真实预览控件发送 Qt 鼠标事件，检查旋转图像变化、平移距离、滚轮缩放、全图恢复，
并确认网格版本及校验值不变。隐藏绘制耗时记录在报告中，它包含图像读回，不代表桌面帧率。
三个入口的隐藏窗口截图已查看。真实桌面交互和旧版所有窗口的完整视觉一致性仍分别待验收。

`FreeShip-Tests/maintenance/grid-preview-installed-20261104.json`。
