# 四视图辅助线、标注与动画

2026-11-01。本轮把既有 FreeShip_26 的四视图辅助显示接入 Qt，保留 StudioLight
顶栏、原图标和现有操作。交付程序为 `FreeShip-Qt/dist/FreeShipQt.exe`。
这只是迁移中的一个完整功能批次，旧版、QtPilot 和 Win+R `fs` 入口没有切换。

## 已接入的行为

- 网格、基线、DWL、中心线及分割剖面，跟随各视图独立相机。
- 控制点名称及 X/Y/Z 坐标。坐标保留三位小数；网格尺寸沿用公制毫米、
  英制英尺英寸格式。选中点优先布局，同位置同数值去重。
- 静水力标记和横剖面积曲线，读取同一模型版本的计算结果。
- 进入动画：线框预览、控制点从右向左逐点高亮、蓝红线从交点扩散、文字展开。
  数字只淡入，避免把半个数值当成完整结果。逐点高亮从实际出现的帧开始计时。
- 隐藏视图暂停动画，显示后恢复。平移、缩放和开始编辑立即结束动画；图片输出
  始终绘制完整状态，不受动画时间和屏幕裁切影响。
- 右键单击打开当前视图的显示菜单；右键拖动保持平移，不弹菜单。
  主窗口“视图”菜单可统一切换四视图的坐标轴、网格和静水力显示。

## 数据和性能

`bridge/OverlaySnapshot.inc` 从原核心提取只读显示数据；`model_snapshot.*`
验证颜色、字号、点类型、唯一标记和有限坐标后发布不可变快照。相机移动和绘图
不调用静水力计算，也不修改模型。Qt 的 `view_overlay.*` 生成屏幕辅助图形，
`label_layout.*` 做避让，`overlay_animation.*` 管理扩散图和进入时间。

静水力显示单独持有一个延迟计算对象。不能借用并设置原 `FDesignHydrostatics`
的吃水：它同时注册为 `HydrostaticCalculation[0]`，型线图会读取它的中剖位置。
在移植排查中，这种共享状态导致移动后与重做后的型线图不同。现已隔离计算对象，
并显式处理控制点、工程设置、图层、拓扑和剖面变化后的分析缓存失效。

避让器用屏幕空间索引减少线段候选，最终仍使用同一精确线段/矩形相交判定。
测试另用逐条遍历核对索引结果；没有通过少画曲线或降低精度换取速度。
扩散图仅对屏幕可见线段构建，几何未变时复用；动画完成后停止定时刷新。

本机 800×520 离屏测量中，9a 的四视图平移平均约 2.7–7.2 ms/幅。
大量控制点坐标同时打开时，首次布局约 79.9 ms，后续 11 帧平均约 14.2 ms。
这只是本次采样，包含图像生成开销，不是桌面真实帧率，也不代表首次布局已优化完。
逐帧数据保存在 `model-3/widgets/report.json`，没有设置人为性能通过线。

## 验证和运行入口

完整回归：[qt-overlays-20261101-e](../../../FreeShip-Tests/reports/qt-overlays-20261101-e/report.json)，
**755 pass、0 fail、47 review、8 not_run、0 error**，总状态 `partial`。
样本为盒体、合成船型和 9a。实际隐藏应用依次修改、撤销、重做、保存和重开，
每个阶段对照原参考路径的完整场景、DXF、几何及静水力显示结果。盒体排水量与
浮心另有独立数值预期，并验证修改确实使缓存失效、重做恢复相同结果。

动画测试检查末帧、交点传播、孤立连通分量、循环边、暂停、延迟首帧、逐点计时、
导航中断及动画期间的完整导出。原编辑控件和型线图绘制回归同时运行。
入口按动作元数据发现，保存候选与执行后状态；缺失、歧义或禁用记 `not_run`。

交付路径的独立复核记录在
[qt-overlays-delivery-20261101](../../../FreeShip-Tests/reports/qt-overlays-delivery-20261101/report.json)。
该入口直接运行 `dist/FreeShipQt.exe`，校验包内源码/程序指纹，再比较三种模型五个
阶段的场景、DXF 和剖面数据。实际执行状态以该报告为准，不能拿复制出的测试程序
代替运行路径验证。构建复用 `overlay-service-05` 和 `topology-qt-01`。

可复用源码全部保存在 `FreeShip-Tests/qt_overlays.py`、`qt/overlay_tests.cpp`
及产品的 `src/app/overlay_workflow.cpp`，统一入口为：

```powershell
python -B run_tests.py --suite qt-overlays --output reports/<新目录>
```

一次排查脚本 `FreeShip-Tests/maintenance/overlay_history_probe.py` 另行保留。
它保存原始计算输入并列出移动/重做差异；日常回归由上述实际应用历史流程覆盖，
无需每轮再生成一套重复诊断文件。
