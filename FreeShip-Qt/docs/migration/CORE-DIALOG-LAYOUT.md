# 常用窗口布局修整

2026-11-05。

工程设置还保留着试点时期的窄窗口和底部按钮。已按旧版
`Forms/FreeProjectSettingsDlg.lfm` 恢复 800×600 初始尺寸、右上角确定/取消、
常规／主尺度／静水力三个分组，继续使用原 StudioLight 图标。
单位、细分精度和水下显示放在常规页，分界位置放在主尺度页，
水密度和附体系数放在静水力页。改动只涉及布局，字段提交和单位换算代码保持原样。

剖面线标签栏原先被限制为 32 像素，大字号时会裁切。现在按字体计算高度；
编号、曲率列按内容伸缩，并保留原来的最小宽度。编辑、分类切换和忙碌时禁用仍用原回调。

偏好设置的常规、目录页增加滚动容器，表单空间不足时换行；图形页同样支持表单换行。
工程设置各页也可滚动。修复前，18 磅字体下的目录输入框出现压缩，工程设置无法缩到
600×420；修复后测试窗口可保持该尺寸，末行控件仍可滚动到完整可见的位置。

## 边界

本次恢复的是这三个常用窗口已有功能的布局。随后已接入预览保存开关，以及
[系数口径和静水力显示](PROJECT-HYDRO-OPTIONS.md)。水温及其他旧设置仍未全部接入 Qt，
不用没有后端支持的控件凑齐外观。
专业计算窗口的完整旧布局、密集标注、原生文件框、真实鼠标焦点及多屏观感仍待验收。
本次截图和隐藏事件验证不替代实际桌面验收。语言支持仍由专门的翻译工作流负责。
