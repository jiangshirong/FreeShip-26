# 原生曲面剖切与交线拼接

2026-11-01。本轮接在控制网细分之后，验证如何用平面切开细分曲面，再将交段
连成带折角的样条点链。输入来自完整静态控制网及对应层级，不从四视图画面取点。
候选作为独立 C++ 计算目标，正式程序仍使用当前计算服务。

## 检查的过程

计算保留四个阶段：原始交段、沿拓扑连接的点链、相近端点拼接后的点链，以及
过滤小段后的最终曲线。这样可以分别判断差异来自交点、连线还是过滤。站线、水线、纵剖线
和斜剖线都归结为平面系数；图层是否参与普通交线或静水力剖切分别处理。

本轮保留当前 Plus 的 Single 运算和实际容差语义。旧拼接函数把 `0.01` 与距离
平方比较，对应距离小于 `0.1`；不是距离小于 `0.01`。旧流程还会在多段时过滤
包围盒对角线平方小于 `0.001` 的片段。这些行为需要兼容对照，也需要独立几何
例题判断，不能因为新旧相同就认定适合所有尺度的模型。

旧 `InsertSpline` 两个前插分支会丢掉共享点的折角。隔离运行已复现：将
`(-1,1)→(0,0)` 与 `(0,0)→(1,0)` 相接，来源末点明明带折角，旧结果却清掉了
该标记，随后样条越过原来的水平线。候选在实际共享点上保留两端折角的 OR；
原坐标和拼接次序不变。旧行为、正确折角预期和修正后采样分别验证，差异不计作
旧新完全一致，也不直接发布到正式输出。具体位置和来源见
[来源记录](../../src/native/SECTIONS-PROVENANCE.md)。

ShipCAD 仍为可选参考。当前 Plus 也只用于兼容性对照，独立数学预期另行检查。
没有通过减少交点、降低细分级别或放宽比较容差来消除迁移差异。

## 测试入口

```powershell
python FreeShip-Tests/run_tests.py --suite qt-native-sections --output FreeShip-Tests/reports/native-sections-new
```

统一入口构建隔离的 C++ 目标和原 Pascal 探针。旧核心的局部交段通过私有副本中
的只读观察插入点记录，原文件不修改，观察插入与算术实现分开审计。每次运行
保留输入、输出、源码和构建清单；测试脚本纳入统一测试程序。

静态控制网保留全局控制面顺序及层号，能够还原重新加载文件后的层内顺序。
任意旧活动文档的编辑历史顺序、懒构建状态不在这个输入内，不能由文件对照通过
推导所有旧活动对象都完全等价。正式接入时还必须核对文档版本，防止控制网和
细分结果来自不同次编辑。

## 本轮结果

[最终统一报告](../../../FreeShip-Tests/reports/native-sections-final-20261101/qt-native-sections/report.json)
为 **646 pass、0 fail、7 review、2 not_run、0 error**，总状态 `review`。
43 个小例包含 20 组直接拼接和 51 次曲面剖切；三个完整模型另做 31 次剖切，
产生 3,844 个原始交段。盒体、合成曲面、9a 分别使用文件实际的第 1、4、3 级，
不是每个模型都执行所有级别。9a 保存的 22 个平面全部覆盖，其余补充平面在输入
中明确标为测试夹具。

三模型的原文件对象与导出控制网重建结果一致；C++ 的逐阶段坐标、拓扑、折角及
样条采样也与旧结果一致。包含小例在内，除两个明确修正的前插例外，100 组对照
的 71,747 个有限浮点值经 Single 重构后全部相同，拓扑字段无差异。

两个前插例另外统计：两个共享点折角由 false 改为 true，共 68 个样条值或导数
随之变化；这些变化逐项等于“将独立正确点链交给原 Pascal 样条”得到的结果。
总报告仍保留这 68 个数值差异和 2 个折角差异，没有从汇总中排除。

7 项 `review` 是：两个前插修正例；两组新旧共有的面心舍入观察（理想 Y=4，
实际均为 4.000000476837158）；三组继承的几何策略——重合但不相连的截面被
合并、短片段在多段情形被删除，以及跨越 0.0625 间隙拼接。它们的独立预期
及旧、新结果分别保留，不以兼容相同代替正确性判断。

两项未覆盖也明确保留：旧去重代码错误搬移整条记录的分支尚未用合法面网触发；
同边连接距离恰在 `1e-4` 两侧的相邻 Single 边界尚无可靠夹具。已做平面方程值、
闭合距离及碎片阈值检查，不能拿它们替代这两条分支。

跨独立进程重复、观察回调开关对照、输出失败保留、成功空结果替换均已验证。
当前源码与构建清单一致，旧源码、模型、原程序、试点源码及两个交付目录未改变。
详细复核见 [NATIVE-SECTIONS-REVIEW.md](NATIVE-SECTIONS-REVIEW.md)。

## 本轮边界

本轮输出是剖切点链及其样条计算验证，还没有替换正式型线图的场景生成。
三个模型保存的交线简化开关均为开启，本套对照只调用底层曲面剖切，没有执行
上层 `Simplify`；所以不能用本轮数值相同代替实际显示及导出的全流程验收。
自动镜像、上层交线简化、曲率显示、面积与静水力积分、完整 DXF/图片/打印输出
仍需在后续接入时逐项核对。原生 FBM 读写和完整编辑文档也不在本轮范围。

已有层级缓存继续用于细分。局部增量剖切、跨重启缓存和界面速度需要单独实现与
测量；本套计算验证不提供帧率或首次打开时间结论。
