# 非对称船体侧投影和静水力标注

2026-11-09。

非对称船体的侧投影面积、投影形心已接入单次静水力、吃水表及报告。
四视图可以显示这些船体的排水量/浮心、KMt、漂心、侧投影中心、风压中心和横剖面积曲线。
这项补齐不涉及船模格式、型线图曲线、细分精度或几何导出。

## 面积是什么

侧投影是实际参与静水力的船面经水线裁切后，在船体 XZ 平面上的正投影并集。
两船体在侧视图重叠时，重叠部分只计一次。沿 Y 方向真正贯通的孔洞要扣掉；
垂直月池被外侧船壁遮住，不应在侧影上挖洞。中心纵剖面积不能代替这个量。
横倾、纵倾仍在实际三维面上裁切，之后投影到船体坐标，不换成倾斜后的屏幕面积。

计算位于 `src/document/hydrostatics.cpp::projectedArea`：

- 与体积、截面积共用细分船面及固定三角拆分，只取参与计算的图层；对称层补镜像。
- 先用 Double 裁切三角面，再投影，统一输入朝向，避免两舷法向相反导致抵消。
- 采用 Clipper2 的 NonZero 并集合并投影轮廓，保留结果的反向内轮廓。
  每批最多 512 个投影多边形，按平衡树合并中间结果，批间检查取消及超时。
- 在船体 XZ 范围中心平移后，把最长边映射到 1e12 的整数网格。
  单次坐标量化误差不超过最长边的 0.5e-12，布尔交点也受整数网格精度限制。
  这不是解析实数运算；精度仍以所选细分船面为基础。原模型坐标不会量化或改写。
- 并集的有向轮廓用 long double 累计面积及一次矩，再转回模型单位和已有 Single 输出。
- 水线及水上/水下方向作缓存键，每个不可变文档版本最多存 512 个结果。
  改点后使用新版本，撤销可恢复前一版本，不沿用过期面积。

全对称船体暂保留已对照的原计算路径，不把这次新算法悄悄套到已有对称报告上。

## 标注坐标

原来用“主报告部分完成”挡住全部非对称标注，现在只缺旧单侧进流角时仍可显示已完成的量。
漂心、浮心和稳心保留实际横向坐标。非对称 KM 标注数值是距船底高度，位置才加船底 Z；
漂心位置也只补一次船底高度。没有把横向偏置船体强行放回 Y=0。
侧投影中心和风压中心本身属于 XZ 投影平面，因此这两项 Y=0。
某个投影中心在当前视野之外时，沿用现有标注裁剪规则，不把画外标记强行画到船体上。

风压侧影直接计算水上部分的投影并集，不用“全部面积减水下投影”猜算。
完全潜没或水上面积为零时不产生风压标记。这里只统计参与静水力的船面，
不是包含全部上层建筑、设备及风压系数的完整风载荷计算。
五组工程显示开关分别生效，隐藏标注不会改动几何数据或导出。

## 外部代码来源

[Clipper2](https://github.com/AngusJohnson/Clipper2) 固定到 `Clipper2_2.0.1`，
提交 `21ebba05db8894f0c7217ad35ea518080f324946`，许可证 BSL-1.0。
`third_party/clipper2` 保留未修改源码、许可证和 `origin.json` 摘要。
只编译布尔运算引擎，不使用偏移、三角化等其他功能，也不在构建时联网取最新版。
源码获取脚本为 `FreeShip-Tests/maintenance/vendor_clipper2.py`；它用于固定来源，
不是数值正确性的回归测试。运行包与正式打包脚本都保留第三方源码及许可证。

## 验证

统一入口 `run_tests.py --suite qt-lateral-projection`，测试源码 `qt_lateral_projection.py`。
矩形包含/排除公式与三角剖面积分给出独立面积、形心；另查横倾/纵倾、大小尺度、
平移、单位换算、混合图层、隐藏/排除层、窄缝、边界接触、各细分级别、全潜没、
重复缓存、编辑/撤销、保存重开、取消及取消后继续计算。
生产回调检查四视图显示开关、实际标记、动画、编辑/撤销及几何输出不变。
非对称静水力既有套件增加 JSON/CSV 中侧投影数值检查；原有对称静水力、工程显示开关
及模型发布另跑回归，不改历史基准。
