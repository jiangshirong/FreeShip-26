# 高斯曲率、可展性和斑马纹

2026-11-04。四个视图的右键菜单增加三种特殊着色，与线框、普通填色互斥。
保留现有 StudioLight 界面和原色标口径，图片和打印预览使用当前绘制模式。

## 数据和缓存

细分计算已有的顶点编号、顶点类型及多边形连接关系放入曲面显示文件。加载时
逐个核对三角形坐标，确认拓扑确实属于当前显示网格；不按相同坐标焊接顶点。
新增数据只用于显示，不进入 FBM，也不改变型线图、求交或 DXF。

普通打开和填色不计算曲率。首次选择特殊着色才计算，四个视图共享同一份分析。
平移、缩放、转动和切换模式复用结果；编辑后使用新快照，撤销后重新绑定恢复的
网格。GPU 的分析属性也只上传一次，导航时更换相机参数。软件回退使用同样的
顶点属性和透视插值，半船裁切、镜像及透明度继续生效。

主要实现：`src/native/surface_display.cpp` 携带拓扑，
`src/core/model_snapshot.cpp::loadSurfaceDisplay` 核对数据，
`src/render/surface_analysis.cpp` 生成分析，`hull_view.cpp` 和 `hull_gpu.cpp` 绘制。

## 三个模式的含义

**高斯曲率**沿用旧版的角亏：360° 减去相邻面在该顶点处的角度之和。
正值偏红，负值偏蓝紫，接近零偏绿；色阶范围随模型变化。它没有除以顶点面积，
不是单位为 1/m² 的曲率值。细分级别会影响数值，不能把不同精度下的颜色直接当作
同一个物理量比较。视图底部明确标出角亏单位和范围。

**可展性检查**沿用旧判据：角亏绝对值小于 0.0001° 为绿，其余为红。
这是一项局部形状检查，不能代替板材展开、应变和加工工艺验证。

**斑马纹**使用观察方向与顶点法向夹角余弦的绝对值，每 0.02 切换一次条带。
规则点和镖点使用相邻面的平滑法向，折角点使用三角面法向；镜像时法向一起
翻转。条带在 GPU 中直接绘出，不像旧版那样先切成许多小多边形再逐个绘制。

## 没有照搬的旧问题

- `FreeSubdivisionPoint.FGetCurvature` 遇到开口边就返回零，因而旧可展性视图
  会把尚未评估的边界画绿。Qt 的曲率和可展性视图对边界、非流形连接、分离的
  顶点邻域和退化面显示灰色，不把它们归为可展。孤立点不参与曲率范围。
- 旧 `FGetNormal` 使用的 `AddPoint` 会把负 Y 分量夹成零。这会扭曲斑马纹的
  方向。特殊着色使用普通向量相加；已有流线算法和法向叠加显示保持原口径，
  本轮没有顺带改动它们的计算结果。
- 旧 `FreeSubdivisionControlFace.ZebraStripe` 为每条色带生成裁切多边形。
  Qt 保留条带定义，改为顶点属性加像素着色；不增加几何，也不降低模型精度。

## 测试

统一入口：`FreeShip-Tests/run_tests.py --suite qt-shading --runtime <运行包> --output <独立目录>`。
测试代码在 `qt_shading.py`、`qt/shading_tests.cpp`，生产回调探针在
`src/app/shading_workflow.cpp`。

独立样本包括平面、鞍面、圆柱和封闭八面体，另检查重合但分离的曲面、非流形边、
分离的顶点邻域和折角法向。GPU/软件图像对照涵盖三个模式、四个投影和真实船型。
实际菜单、图片保存、编辑后刷新与撤销恢复另走主窗口回调。模式切换前后比较
完整模型、型线图场景、DXF；编辑并撤销后再次核对场景、DXF 和保存 FBM。

隐藏窗口截图用于检查颜色、文字和裁切；真实桌面输入、系统文件框、多屏 DPI
及纸面打印仍未验收。语言支持由专门的翻译模型负责。

最初的开口圆柱测试从俯视方向没有可采样面，三个图像检查因此失败；数学测试
继续用开口圆柱，四投影绘图另用带端盖的圆柱。原报告保留，不把零采样记作通过。
