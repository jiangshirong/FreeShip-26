# 工程设置中的静水力选项

2026-11-05。

旧 FBM 已保存系数口径和静水力标注选择，Qt 计算与显示也会读取这些值，
但工程设置没有对应控件。本次补齐静水力页的这一组操作，沿用原三页布局和 StudioLight。

## 可以修改什么

- 系数计算依据：工程设置中的主尺度，或实际水下船体尺度。
- 排水量和浮心、横剖面面积曲线、稳心高度、纵向漂心、侧投影面积和形心的显示。

所有修改在点击“确定”后一次提交，取消不改模型；混合修改只占一条撤销记录。
五个开关只控制各类标注，不擅自打开总显示开关，不修改曲面或型线图导出。
静水力计算窗口会读取新的系数口径；基础体积、面积和浮心仍来自相同船体。

## 实现和数据保全

`document/project_edit.cpp` 在原工程设置事务中增加系数整数和五个可见性字节，
`publication.cpp` 发布实际保存值，`model_snapshot.cpp` 校验后交给 `ProjectDialog`。
没有另建一套计算公式或复制显示状态。

系数口径从格式序号 16 起存在，五个标注位从序号 17 起存在。旧格式的缺省值
沿用 Plus；无变化提交保持原版本，只有实际修改需要新字段时才升级。
撤销会恢复修改前的整个文档，包括原版本和原始字节。

系数公式沿用已经迁入 C++ 的当前 Plus 计算。特别是其工程尺度模式下的 Cwp
仍使用水线尺度；本次没有顺带改变这个已有口径，不能把界面接入当作公式修订。
