# FreeShip_26 菜单对照与取舍

基线是本项目中用户改过的 Lazarus 版。对照了 `FreeShip-Plus-Lazarus/Forms/Main.lfm` 与 `Main.pas` 中实际移除、隐藏和重新归位的菜单项，也检查了 `freehullformwindow_panel.lfm` 和 `.pas` 里按视图及绘制模式显示的项目。Qt 侧覆盖「菜单」、顶栏功能下拉、四视图右键及型线图中与这些入口重复的动作。隐藏的旧动作定义不计入可见入口。

## 「菜单」及文件子菜单

| 对照发现 | 取舍 |
| --- | --- |
| Qt 把「退出」放回「文件」。改过的 Lazarus 版通过窗口关闭 | 删除菜单项，使用窗口的 ×。Qt 的关闭快捷键仍直接执行关闭流程 |
| Qt 在一级放了「切换语言 / Language」。改过的 Lazarus 版从首选项配置双语并用快捷键 | 删除菜单项。「首选项」放在一级，双语切换继续用 `Ctrl+Alt+L` |
| Qt「文件」同时放了「导出型线图 DXF」，型线图窗口也有 DXF | 型线图窗口的 `DXF` 为唯一的**型线图** DXF 入口。「导出模型」中的三维剖面与控制曲线、三维面、折痕与边界线各有不同输出，继续保留 |
| Qt「保存当前视图图片」实际保存整个工作区四视图拼图，是迁移时加的独立导出 | 移除该拼图命令。单张视图用本视图右键「保存图片」，型线图用窗口内 `PNG` |
| Qt 新增「恢复未保存的船模」「恢复当前工作」 | 保留。前者从恢复副本选择，后者在当前编辑服务中断且可重连时出现。健康会话里隐藏「恢复当前工作」 |
| 「新建船型」「打开模型」「保存」「另存为」「最近打开」在两版都有 | 保留，新建排在打开前。一级的「编辑」「视图」「帮助」，以及重复的工程设置、关于、撤销、重做继续不出现 |
| 11 项导入类型都能在旧版找到对应入口 | 保留在「导入模型」下。OBJ、STL、FEF、Polycad 控制网、Carlson Hull、Carene、折角线、曲线拟合曲面、VRML、FreeShip 几何部件、Michlet 波高网格 |
| 模型导出对应旧版的大多数文件交换入口，有几项 Qt 拆分或新增 | OBJ、STL、FEF、IGES、DXF 三维剖面与控制曲线、DXF 三维面、型值（剖面及控制曲线）、坐标点、GHS、PAM、FreeShip 几何部件、Michlet 保留。ArchimedesMB `.hll` 与 Archimedes `.app` 服务不同程序，均保留。AddMass 输入旧版在隐藏的专业计算组，Qt 保留它的独立文件导出。矩形型值表是 CSV，行是横剖站、列是水线。DXF 折痕与边界线只输出细分曲面特征线。这两种输出均保留 |

## 顶栏各下拉

| 对照发现 | 取舍 |
| --- | --- |
| 「视图」新增全局船体填色、型线图填色、适合窗口、四视图、全局坐标轴、收起属性面板 | 移除这六个入口。四视图显隐在各自状态按钮，绘制模式和坐标在各视图右键，型线图填色在型线图窗口，适合窗口走 `F`。点菜单的「所选对象详情」改成同一项开启或收起 |
| 参考网格、静水力数据同时出现在顶栏「视图」与各视图右键 | 按旧版分工，保留顶栏全局开关。控制网格由顶栏独立状态按钮控制。双舷显示、四类剖面、控制曲线、流线显隐、标记也留在「视图」 |
| 法向、曲率梳及大小调整被放回顶栏「视图」，板材展开进了「计算」 | 归回四视图右键。「模式」里的可展性检查是给当前视图着色，「板材展开」是生成展开结果，两者分别保留 |
| Qt 的漏点选择、清理无面控制点、删除负舷面分散在点、选择、面内 | 归并到「模型检查」，与检查报告一起。报告和会改变模型的修整仍是独立动作 |
| 「删除所选对象」在点、边、面、流线重复。「取消选择」也多出一个入口 | 移除这些入口，保留 `Delete` 删除及确认；`Esc` 有正在进行的操作时先结束操作，否则清除选择。显式全选与反选仍是两种独立操作，留在「点 → 选择」 |
| Qt 同时提供单边拆分与拆分所选边，底层共用同一几何实现 | 合并成「拆分所选边」，接受一条或多条。设置和取消折痕保留为明确的两个结果，批量选中不同状态的边时可以直接选定目标状态 |
| 「图层」下拉和「图层属性」窗口都有新建、清理空图层、上移、下移 | 图层的新建、删除所选空图层、清理全部空图层及排序只从图层属性窗口进入。顶栏下拉保留「图层属性」和「按折痕自动分组」。后者重组面片所属图层，是独立建模操作 |
| Qt 将点、边、面、控制曲线和流线选择显式化。按坐标新增点、点属性、控制曲线命名、清除约束、点组管理、将所选面移至指定图层等有专门入口 | 保留这些作用不同的动作。点放置和按坐标新增分别面向交互和精确输入。单点属性可编辑点属性，所选对象详情为可收起的检查面板。对齐、锚定、永久直线约束和重合继续收在同一组 |
| 旧版有些动作在「工具」「选择」或「变换」中，Qt 放在当前对象旁 | 保留就近入口。面下保留组装面片、添加网格面板/圆柱、翻转朝向和镜像。边下保留连接点、挤出边、合并相邻面和控制曲线动作。标记导入/清除、流线放置/选择收在「视图」相关子组。变换下保留移动、缩放、旋转、绕船中旋转和 Lackenby。围绕指定轴旋转和绕船中旋转的参考点不同 |
| 改过的 Lazarus 版隐藏了专业计算组，Qt 恢复了可用的 19 项 | 保留为「计算」下的三个子组。阻力 10 项为 Delft、Holtrop、Hollenbach、van Oortmerssen、Fung–Leibman、OST、圆舭高速艇、多体船、KAPER、滑行艇。螺旋桨与推进 5 项为优化及主机选型、主机匹配、推进特性图、初步设计、系列计算。水动力专用工具 4 项为空气动力、操纵性、加速制动、附加质量。设计静水力、静水力吃水表和稳性曲线与平衡继续放在「计算」直接层级 |

## 四视图右键

| 对照发现 | 取舍 |
| --- | --- |
| Qt 恢复了旧版已删的「缩放至适合窗口」「放大」「缩小」 | 三项全部删除，使用滚轮及 `F`。右键继续不放旧的「取消全部选择」及视图创建/切换子菜单 |
| Qt 把线框、填色、高斯曲率、可展性检查、斑马纹摊在右键一级 | 五种模式收进「模式」。只切换被右击的视图 |
| Qt 的相机在三个平面视图仍显示为禁用 | 相机只出现在透视图，保留 28、50、90、130、200 mm 镜头 |
| Qt 同时显示「启用光照」和「光源」，线框也有 | 只保留「亮度」，在有着色的模式下出现。是否启用光照由亮度窗口控制 |
| Qt 透视图有一个始终不可用的「背景影像」；三个平面视图多一个「启用透明色」 | 透视图隐藏整组。平面视图保留导入、显示、清除、保存、原点、比例、边框、透明色、透明度混合、容差；透明色开关可单独取消透明处理，保留。未开启透明色时禁用容差 |
| Qt 有「打印预览」，旧版打印在填色模式禁用 | 保留打印预览及保存图片。Qt 的打印预览使用当前视图绘制结果，也可用于填色 |
| Qt 既能全局选坐标轴，也能分别选，右键的名称与快捷键未完全恢复 | 只保留每视图的「显示控制点坐标 → 关闭 / X / Y / Z」。`Ctrl+Alt+X/Y/Z` 在视图内切换轴，重复按同一轴即隐藏。选择坐标轴时打开控制网格 |

旧版独有的「窗口」里的新建、平铺、层叠，以及旧工具菜单的移动步长、自由物体/内部边的独立显示、专门的选择对话框，在 Qt 中没有直接对应的这批菜单项。此次保留 Qt 四视图的状态按钮与现有建模路径，这些反向差异另列，不作为恢复旧菜单的理由。

## 验证方式

统一测试入口 `python FreeShip-Tests/run_tests.py --suite qt-menu-parity --runtime FreeShip-Qt/dist`。使用隔离模型副本，以 Windows Qt 插件生成顶栏下拉及四视图线框/填色右键菜单。对首选项里的每种语言使用相同的结构检查，记录动作标识、显隐、启用、勾选与快捷键。中文截图仅作菜单改动示例。测试还覆盖视图内坐标切换、亮度窗口、图片保存和拆分单边。型线图窗口用 `qt-lines-window` 单独复核。翻译质量、真实桌面点击、系统级按键路由和打印仍需单独验收。

StudioLight 菜单保留左侧功能图标，已启用的项目在右侧显示海青圆形对勾。浅海青行底色表示鼠标悬停或键盘当前项。专项回归在实际 Qt 菜单渲染中检查有图标开关、无图标单选项，以及悬停与勾选同时出现的情况。中文样例为 `production-windows/visibility-menu.png` 和 `production-windows/coordinate-menu.png`。

双舷、控制曲线、流线、标记、法向及曲率梳先更新视图预览。等待显示设置提交期间仍可切换，后续点击按字段合并，再按当前文档版本提交；失败时回到后台已确认的状态。几何编辑仍受会话忙状态保护。专项 `qt-display-response` 检查收到后台应答前的画面和菜单、连续点击、最终提交以及几何、型线图与剖面数据的保持。
