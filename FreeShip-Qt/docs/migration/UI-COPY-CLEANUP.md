# 窗口文案清理

完整复查及本轮删改记录见 [2026-11-12 全软件文案清理](UI-COPY-FULL-REVIEW.md)。以下保留此前各轮处理范围，不能把局部记录当作全软件清理完成的依据。

2026-11-10。用户指出，迁移时增加的说明占据操作区，信息密度过高。

本次处理首选项、控制点面板、专业计算、静水力及导入导出窗口：

- 删除常驻语言回退机制说明和鼠标操作教程。
- 删除“原生”“沿用旧版”“保留原算法”等迁移介绍，取消重复的“设置参数后点击计算”。
- 计算状态只说明正在发生什么；参数修改后简短标出结果待更新。
- 保留会影响结果的单位、参考点、总功率定义、方法缺少的校核，以及参数保存范围。
- 导出说明缩短；其余格式细节由“格式说明”按钮按需展开，默认不占据操作区。
- 计算方法、公式、数值精度、模型事务和导出逻辑未改动。

修改前后对照保存在 UI-COPY-CLEANUP.json。它记录迁移中加入的文案，不是上游缺陷清单。
旧的算法依据仍在各专项文档和计算报告中。未做新增翻译，也未改原有 StudioLight 设计。

复用统一入口 qt-calculation-layout-only、qt-dialog-layout、qt-exchange 检查窗口及实际操作。
前者为已有计算窗口回归的仅布局入口，避免文字调整触发不必要的完整求解器测试。
隐藏窗口和截图不代表真实桌面验收，也不表示已经穷尽全部窗口的文案问题。

## 2026-11-12：删除，不再只折叠

用户再次指出 OBJ/STL 导入说明仍然冗余。核查发现，上次保留了原文，只把它放在“格式说明”按钮下；当时的回归检查窗口和导入操作，没有判断说明文字是否已删减。因此此前的局部清理没有满足用户的完整要求。

本次删除 OBJ/STL 导入的通用长说明和几何导出的通用介绍；没有专用说明的格式不再显示空的“格式说明”按钮。保留单位、镜像、控制网等操作选项及错误检查。另删除型值预览下重复出现的鼠标操作教程。格式本身的技术限制记录在各格式文档中，不再用这段通用文字重复介绍。

本轮检查了 src/app 的 QLabel、说明控件和相关状态文案。恢复文件的处理方式、基线平移影响、约束点含义、方法适用条件及数据损失等有实际操作意义的内容保留。其余格式的专用帮助仍然存在；这不是“删除所有帮助文字”，也不以自动回归通过代替用户对文案的判断。翻译文件未修改；旧译文条目已无上述显示调用。
