# 剖面线与图层管理

2026-11-01。四类剖面线的日常编辑流程接入 Qt：横剖线、纵剖线、水线、斜剖线。
顶栏“剖面线”沿用原来的入口、标签顺序和图标；窗口支持单条新增、按起止位置和
间距批量新增、直接改距离、删除所选及清空当前类别。

每次操作进入同一个文档历史，四视图、型线图和导出一起更新。批量新增只产生一步
撤销；取消、重复位置和其他无变化操作不新增历史。列表索引只在当前版本有效，
更新后清空选择，旧请求被拒绝，避免排序后误改另一条线。

图层菜单增加新建、删除所选空图层、清理空图层。原层删除函数会删除层内所有面，
这里先检查是否为空，不把它直接暴露给用户；需要删非空层时先转移面。始终至少
保留一层，删除和撤销也不会让旧编号指向新对象。

## 计算与显示

- 四视图曲线复用 C++ 已完成的求交结果，不再调用旧剖面窗口或重新切一遍模型。
- 显示采样在曲线副本上做，保留原精度档和折点，型线图及 DXF 的采样流程不变。
- 剖面改距不改船壳，服务不再为这种操作重做旧核心的曲面细分。
- 批量添加完统一排序，取消原来每插一条就对整个列表做二重循环排序的步骤。
- 曲线快照连同场景和 DXF 校验后才发布。缓存损坏时重建，不显示缺失的旧曲线。

有两处明确的行为边界：现在允许保留船体范围外的剖面定义，方便后续改型，它们的
曲线可以为空；斜剖线距离沿用旧版的 y+z 坐标口径，不当作平面法向的物理距离。

曲率标志保留并能随 FBM 往返，窗口暂只读显示。曲率梳、半船/分舷开关、控制曲线
和流线编辑仍未迁移，不能把本次管理窗口说成完整旧版 UI 已迁完。实际鼠标体验
和整体外观仍需用户确认；隐藏窗口测试不替代这一步。
