# C++ 完整型线图接入

2026-11-01。本轮交付的是实际 Qt 程序中的完整生成流程，包含编辑后的更新和 DXF，
不再只停留在独立计算候选。现有平移、缩放、GPU 填色和图片导出继续使用原 Qt 渲染器。

## 计算从哪里来

Pascal 文档服务仍持有 FBM 和撤销历史，把控制点、边、面、图层、剖面定义及设置
传给 `FreeShipNativeLinesplan.exe`。C++ 自行细分控制网、求交、拼接曲线，生成布局、
填色、网格、标签和完整 DXF。它没有读取四视图截图，也没有调用旧型线图窗口。

新路径不再调用 `TLinesplanScene.Generate` 或 `ExportDXF`。原入口保留作隔离对照，
生产 Qt 请求明确指定 `native_linesplan=true`。核心位置：

- `bridge/NativeLinesplanInput.pas`：原始输入及计算进程管理。
- `src/native/document.cpp`：输入校验。
- `src/native/scene_builder.cpp`：完整场景、斜剖线、填色、文字和 DXF。
- `src/native/sections.cpp` 的 `SectionIndex`：同一场景内共享曲面索引。
- `src/native/worker.cpp`：输出、缓存、错误报告及服务退出后的进程回收。
- `src/app/model_session.cpp`：文档版本和输出指纹核对，再发布到视图。

仍有一个容易忽略的旧行为：屏幕折痕的前后体分界使用静水力计算找到的最大面积
剖面位置，普通站线和 DXF 使用工程设置中的分界。当前分别传入这两个值，保留原
显示和导出含义；静水力算法尚未迁移。四视图显示网格和 FBM 读写也仍由 Pascal 提供。

## 精度和差异

没有降低细分等级、显示采样或导出采样。基础运算保留原 Single 顺序，禁用快速
浮点重排及 FMA 合并；测试按重构 Single 精确比较。DXF 另兼容旧编译器的十进制
舍入规则，包括英制样本的末位，不用新增容差掩盖差异。

完整场景核对填色坐标、颜色和绘制顺序。曲线的旧采样点必须原样保留；只有下面
几类显示差异单独记为 `review`，不改写成逐字节相同：

1. 原俯视水线把 X 投影写成了 Y。改为实际 XY 投影，有独立投影小例和原 DXF 顶点
   作依据。旧错误公式及新旧全部差异随报告保存。
2. 显示采样补回跨过的已标记折角，原采样点及次序保持。DXF 继续遵守旧采样规则。
3. 文字锚点使用 Qt 字形尺寸及连续世界坐标，替代旧 1280×800 整数投影。文字内容、
   顺序、颜色和字号单独严格核对；标签布局不写入模型或 DXF。

完整 DXF 使用既有实体比较器，检查全部实体和数值，没有数值容差。文本字节因
记录排列不同而不相同的情况另列待看；没有删掉实体或只比较轮廓。
保存重开产生新文档后，临时对象 ID 允许重分配；测试用唯一的精确坐标对应对象，
继续检查点标志、边重数、面绕向、图层、设置和网格。同一文档内的 ID 稳定性检查保留。

## 更新与缓存

生成先写私有暂存目录。输入损坏、组件缺失或生成失败，服务恢复原模型和撤销历史；
Qt 不接收半幅场景。客户端还核对报告中的文档 ID、版本和场景/DXF 的 SHA256。
工作进程以无窗口方式运行，并监视所属文档服务是否已经退出。

当前缓存存放在私有文档会话中，以原始内容和生成器版本作键，校验场景和 DXF 指纹。
撤销回到相同内容可复用；修改坐标、吃水、颜色或算法会失效。坏缓存自动重新生成。
旧项按 16 项和 256 MiB 预算清理，当前正在使用的单项保留，不删除无关文件。
这是磁盘上的派生数据缓存，不是正式模型。当前实现不跨应用重启复用。

局部增量生成尚未在这一条 C++ 路径完成：改点后仍重建完整原生场景。这里先完成
计算替换和一致性验证，后续才能用可靠的局部结果替换完整生成，而不是缓存旧图凑数。

## 回归入口

可复用检查进入同级 `FreeShip-Tests`：

```powershell
python -B run_tests.py --suite qt-native-app --output reports/<新目录>
```

直接入口 `native_linesplan_app.py` 支持 `--reuse-build` 和 `--runtime`，只复用源码、
适配器、测试和二进制哈希一致的构建。默认从当前源码构建。

覆盖盒体、合成曲面和 9a 的原始、工程设置、单位换算、撤销、图层变化、批量移动、
重做和保存重开，并执行实际 Qt 应用的工作流和会话测试。另有斜剖线、系统颜色、
没有剖面、隐藏全部图层、缓存损坏/失效/清理，以及组件失效后的回滚和再次编辑。
基础剖切、共享索引与折角保留继续由 `qt-native-sections` 检查。

## 尚未覆盖

- 原生细分仍拒绝已记录的不支持拓扑，例如一条控制曲线混合附面与游离点、穿过
  无面边连接附面点，以及超过两面共边。遇到这类文件会报错并保留当前模型，
  不静默忽略部分几何。不能把三个模型通过写成任意 FBM 均兼容。
- 显示与导出是派生结果，不能拿来替代完整可编辑 FBM。专业计算、拓扑编辑和
  文件核心仍有独立迁移任务。
- 隐藏 Qt 工作流和离屏图像不等于桌面鼠标操作验收；未测显卡和高 DPI 不计为通过。
- 这次不修改旧版、已验收试点或 Win+R 的 `fs` 入口。
