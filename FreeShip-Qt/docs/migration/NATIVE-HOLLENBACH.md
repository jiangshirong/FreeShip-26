# Hollenbach 阻力原生计算

2026-11-10。Hollenbach 窗口的默认计算接入独立 C++ 核心。单桨设计吃水、
单桨压载吃水、双桨设计吃水三类一起实现，保留旧外部程序作为显式对照。
支持实际面积、四种含附体面积估算式、阻力/有效功率曲线、报告、参数文件和
螺旋桨 Task1/2 提取。不再依赖 HOLLENBH.EXE 才能完成这些静水工况。

## 来源和明确采用的约定

计算依据是 Hollenbach 在 ICCAS 1999 的论文 *Estimating Resistance and Propulsion
for Single-Screw and Twin-Screw Ships in the Preliminary Design*，式 1–12、表 2/3。
[会议论文集原件（NOAA）](https://repository.library.noaa.gov/view/noaa/38581/noaa_38581_DS3.pdf)
的 PDF 第 259–261 页给出长度、面积和阻力系数，267 页给出最小阻力的额外限制。
原件 SHA-256：`65326a0c6693edfcb9e55ce1991114c683fd8d4bc151e2c3ad03b15754c0a3ba`。
原论文扫描表与测试用 CSV 分开保存；没有从生产代码导出测试系数。

有三处需要说清楚，不能只挂一个“Hollenbach”名称：

1. 1999 扫描件式 5 将附体因子印成 `N^a`，正文又允许轴架、包套、侧推数量为零。
   按这个写法直接代入，双桨船可能得到零剩余阻力。本实现采用
   [Steelandt 2020 论文](https://fenix.tecnico.ulisboa.pt/downloadFile/844820067126581/Maxime%20Steelandt%20dissertation%20Propeller%20selection%20based%20on%20real%20weather%20conditions%2012_07%20Tecnico.pdf)
   式 2.7 明示的四个 `(1+N)^a` 因子。这是明确记录的实现约定，不声称找到了
   Hollenbach 本人发布的勘误。其余尺度和系数仍以 1999 原件为准，未照搬后续论文里的不同符号。
2. 原生总阻力采用 `Rf + Rr + Rallow`。摩擦线为 ITTC-1957，雷诺数长度明确取 LPP；
   不加形状因子。给定的 ΔCf 默认零，单独乘总湿表面积。原文剩余阻力和参考面积
   `B×T/10` 不受此附加项影响。旧求解器的粗糙度、空气、自动海况等修正不暗中混入。
3. 最大估计对基础 `Rf+Rr` 乘表 3 的 1.204/1.194/1.206，再加一次给定附加项。
   最小估计使用表 3 的独立多项式和前四项尺度修正；不使用平均阻力的长度、临界速度、
   纵倾、桨和附体修正。最小列中 e1/e2 为零表示不采用该修正，不把整个结果乘成零。
   手动航海余量在这些静水估计之外另列，推进提取采用含该余量的平均阻力。

`g=9.80665 m/s²`，`1 kn=1852/3600 m/s`。分段长度末段保留论文的字面值
`1.0667 LPP`，没有偷偷改成 `16/15 LPP`；在 1.10 LPP 处的小跳变有边界测试。
单桨压载的临界速度因子严格按表中指数和式 7 求值，未另加“低于临界速度就等于 1”的规则。
1999 单桨设计吃水 b11 取 −0.57424，双桨有球鼻艏面积 a6 取 −0.0005。

## 输入、范围和不适用情况

LPP 必须单独填写；不拿项目设计船长或 LWL 猜测。CB 从排水体积、LPP、船宽和
首尾平均吃水计算，旧 Cp、LCB 不参与新方法。纵倾差为 TF−TA，尾吃水
`TA=T−trim/2`，首吃水 `TF=T+trim/2`；接受正负纵倾，不再强行改成小正数。

LOS 在设计吃水取尾水线端到水下最前点；压载取该水线首尾端，都不含舵。
原生提取按当前吃水、纵倾调用现有静水力模块，压载 LOS 取 LWL。
提取不替用户确定垂线位置，也不能证明船模已经建好了全部附体。

LPP、桨直径、另加附体面积始终以 m、m、m² 显示；其余已有船体尺度、面积、
体积、水密度和黏度依工程单位换算。英制控件范围一同换算，负纵倾可保存回旧字段。
黏度原上限 1 会截断常见水黏度，现改为 100；旧对照算例仍显式使用原有效输入 1。

| 条件 | 单桨设计吃水 | 单桨压载 | 双桨设计吃水 |
|---|---:|---:|---:|
| LPP / m | 42–205 | 50.2–224.8 | 30.5–206.8 |
| LPP/∇^(1/3) | 4.49–6.01 | 5.45–7.05 | 4.41–7.27 |
| CB | 0.60–0.83 | 0.56–0.79 | 0.51–0.78 |
| LPP/B | 4.71–7.11 | 4.95–6.62 | 3.96–7.13 |
| B/T | 1.99–4.00 | 2.97–6.12 | 2.31–6.11 |
| LOS/LWL | 1.00–1.05 | 1.00–1.05 | 1.00–1.05 |
| LWL/LPP | 1.00–1.06 | 0.95–1.00 | 1.00–1.07 |
| Dp/TA | 0.43–0.84 | 0.66–1.05 | 0.50–0.86 |

Fn 上下限随船况和 CB 按表 3 计算，不设一个适用于所有船的固定航速范围。
超界、负剩余阻力或非有限结果直接拒绝，不截零、不自动外推。核心零速结果为零，
窗口要求正起始航速；Re≥10⁵ 是本实现另设的数值下限。

最小阻力还要求 CB 0.525–0.825、LPP/B 5–7.5、B/T 2.5–4.5，使用自身 Fn 范围，
只报告它与平均估计适用域的交集。压载没有最小估计；不适用或产生负最小剩余阻力时
该项为 null/“—”，不伪造一个下包络。若最小估计高于平均值，显示提示并保留原值。
201 个绘图点发现平均阻力下降时保留报告但不发布推进输入；采样不等于连续单调性证明。

面积估计包含附体；双桨估计须有 1 或 2 个舵、两副轴架或两个轴包套。
其他配置可以填写实际总面积。若船模面积不含附体，另加面积只补缺少的部分；
启用面积估计时另加面积必须为零，避免重复计算。

## 保存、衔接和复核

沿用现有 Qt 参数、曲线及 JSON/CSV/TXT/PDF 导出。静水平均曲线和手动余量曲线
使用完整 double；报告另外列各阻力分量与最小/最大估计。CSV 是显示曲线的精确数值导出，
完整分项在 JSON、TXT、PDF。报告不把不参与原生计算的旧参数列成有效输入。

桨数由所选船况确定。w、t、ηR 由用户给定，结果通过带版本和校验的
RESIST-native.json 传入 Task1/2，同时保留旧格式表。共享缓存写入器也用于 van Oortmerssen。
重算在参数验证和取消检查之前撤销上次发布；失败不让后续选桨读到旧工况。
只读默认参数/船体提取不清除已有结果。Task3 旧附表精度不在本次改动范围。

新条件保存到完整参数 JSON；FBM 只保存原格式字段，没有塞入私有数据。
重开船模需要重新填 LPP 或载入参数文件，这一点在窗口及报告中保留提示。

统一入口：

```
python FreeShip-Tests/run_tests.py --suite qt-hollenbach --runtime <候选运行包> --output <报告目录>
python FreeShip-Tests/run_tests.py --suite qt-hollenbach --verify-deployment <正式目录> --output <报告目录>
```

独立测试在 `FreeShip-Tests/qt_hollenbach.py`，系数表在 `fixtures/hollenbach`。
用 50 位十进制原式逐项核对整条 201 点曲线，涵盖三种船况、四种面积估式、
零附体、正负纵倾、分段长度、Fn 边界、密度比例和包含长度修正的尺度律。
另查损坏缓存、失败/取消、原生 B 系列匹配、单位和保存往返、实际 Qt 回调及报告导出。
十个旧阻力入口仍与独立旧程序逐点比较，不拿新模型替换旧对照预期。
共享写入器另跑 van Oortmerssen 与 B 系列设计套件。
