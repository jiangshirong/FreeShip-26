# 非对称船体截面与水线面计算

2026-11-09。

以前只给非对称船体提供体积、浮心和稳性结果，面积及稳心字段留空。
现在单次静水力、吃水表和 Bonjean/SAC 表可以计算实际截面积、水线面面积、漂心、
水线面形心惯性矩、KMt/KMl，以及对应的 Cm、Cb、Cp、Cwp、Cvp。
Qt 表格及报告增加“漂心 Y”；原有窗口布局、配色和几何导出流程保留。

## 原算法的问题

`FreeIntersection.inc::CalculateArea` 的面积路径按半船处理截线，将整条曲线镜像，
并把各轮廓转成同向。移植初期保留了这个行为，但没有把结果用于非对称报告。
这种算法会重复完整船体，也无法用内轮廓扣除孔洞。水线面惯性矩还有最后一个轮廓
及对称补偿的历史规则，不能拿来合计不同位置的多个轮廓。

另一个问题出在体积积分：非平面四边形先裁切、再重新拆三角形，裁切后的三角面
与原船面不是同一个曲面。测试中的扭曲四边形，截面面积是 44.6484375，旧体积
对吃水的差分却得到 45.1039327，相差约 1%。这个差异不是显示小数位造成的。

## 现在的处理

实现位于 `src/document/hydrostatics.cpp`。只有实际参与静水力计算的面所属图层含有
非对称层时才进入新路径；空图层、未参与计算的图层不会切换算法。
全对称模型继续使用原有已对照的计算路径，尚未把它的历史积分规则全部统一替换。

- 每个细分面按固定扇形拆成三角面。对称层补镜像并反转面序，非对称层只使用实际面。
- 三角面与平面的交线保留方向。积分直接累加各条有向边，不使用旧的近距离拼线，
  不把邻近船体之间的间隙封起来；孔洞保持反向贡献。
- 竖向截面先按实际水线裁切。积分原点放在该截面与水线的交线上，缺少的水面封口
  对三角扇的面积和矩贡献为零，因此不需要猜测不同轮廓的连接关系。
- 面积、一次矩和二次矩用局部原点及 Double 中间量累加，再移到合成形心。
  水线面在与浮心相同的水平、船底相对坐标系下计算，包含横倾和纵倾变换。
- 非对称体积路径也改为先拆固定三角面、后裁切，面积和体积使用同一份船面。
  原有 Single 输出和体积累加格式保留；没有降低细分精度或减少输出点。
- 对落在顶点或边上的剖切面使用一致的单侧极限；到全船端部时取内侧极限，
  保留平端箱体端面的截面积。共面三角形不重复加入截线。
- 检查参与面的相邻朝向、水下漏点及非流形边。截面缓存绑定不可变文档版本，
  Bonjean 的各条水线复用同一肋位截线；有容量上限，改动模型后重建。

积分依据是有向多边形公式。以局部坐标 `(u,v)` 表示相邻端点，
`c = u₁v₂ − u₂v₁`，则每条边贡献 `c/2` 的面积、
`c(u₁+u₂)/6` 和 `c(v₁+v₂)/6` 的一次矩，以及
`c(v₁²+v₁v₂+v₂²)/12` 的横向二次矩。各轮廓累加后再减去 `A·v̄²`，
得到通过合成形心的惯性矩；纵向同理。没有“最后一个轮廓乘二”的补偿。

## 保留的边界

后续已补齐[侧投影面积及形心](LATERAL-PROJECTION.md)，使用裁切船面的 XZ 投影并集，
不把中心纵剖面积当作侧影。旧单侧进流角仍为 null，状态列明确说明；
主报告因此仍标为部分结果，但已完整计算的 Bonjean/SAC 不被这个无关字段阻断。

新路径要求船面朝向一致、没有水下开口；不能把相互重叠的独立实心船体当作已经做过
布尔并集的几何。孔洞夹具使用实际封闭的环形网格，不靠重叠箱体相减冒充合法拓扑。
精度对应所选细分级别的实际三角船面，并非未离散曲面的解析解。
KMt/KMl 是既有报告约定下的轴向指标，不是规范审批结论。
天气衡准、规范判定和完整破舱稳性不在本轮范围内。

本次截面积交付时未开放非对称四视图标注；后续已在侧投影工作中核对坐标并接入。
实际桌面输入、高 DPI、多屏与整体视觉验收仍单列。下述数字保留为当时交付记录。
