# 移动、缩放、旋转、挤出和镜像

2026-11-01。五项操作已接入 Qt 的选择、参数窗口、撤销/重做、保存和型线图更新。
沿用 StudioLight 顶栏和原图标：变换菜单提供移动、缩放、旋转；边菜单提供挤出；
面菜单提供镜像。没有改四视图和型线图的绘制算法。

## 操作规则

- 移动、缩放、旋转可选点、边、面或控制曲线。关联点去重后只处理一次。
  缩放和旋转以模型原点为基准；旋转轴的符号沿用 FreeShip 的 `RotateVector`。
  输入框去掉多余的末尾零，不改变提交的数值精度。
- 选中全船控制点时，缩放同时更新主尺度及原模型的关联计算参数；可以选择让标记
  一起变换。局部变换不改工程主尺度。整船平移会移动显式中剖位置和四类剖面平面。
- 挤出支持边界边和独立边，可指定新面图层。相连边共用新顶点，新面在公共边上的
  朝向与原面相反。内部边、越过 Y=0 后会被旧辅助函数截断的挤出、零面积方向会拒绝。
- 镜像支持 X/Y/Z 法向的平面及偏移，可合并重合点。新面反转顶点顺序，保留原层和
  边折痕属性。完全位于镜像平面的面不复制；合并形成重复面、重复顶点或非流形边时
  整次取消。图层的对称属性仍沿用原模型，不自动更改。
- 锁定点、锚定和直线约束关联点不能参加这些批量修改。不会跳过其中一部分后继续。
  取消参数窗口或无变化的操作不增加历史、不截断重做；输出失败也恢复旧模型和历史。

## 来源和有意修正

几何和文件编辑仍由单一 Pascal 服务持有。`AdvancedEdits.inc` 从当前 Plus 的
`FreeEdit.inc` 和 `FreeSubdivisionSurface.inc` 拆出无旧窗口依赖的入口，调用原
`Model_Scale`、`RotateVector`、`MirrorPlane`、`ExtrudeEdges`；没有用 Qt 显示网格
反推控制网。Qt 的参数窗口与命令为新代码，完整型线图和 DXF 继续由 C++ 生成。

相对旧入口，挤出会按相邻面的实际方向校正新面朝向，检查只访问该边关联的面；
整船平移使用 `d -= a*dx+b*dy+c*dz` 更新剖面，补上旧移动流程漏掉的斜剖线。
不再静默忽略不合适的选边，也不让中心线截断悄悄改变用户的挤出向量。

正式目录复核还抓到了原挤出入口的顺序假设：`SaveProject` 按地址排序控点，
`ExtrudeEdges` 却用“旧数量之后的数组区间”初始化新点。新点插入排序数组中间时，
新角点可能漏设，使曲面结果随进程中的内存分配变化。新入口在创建前恢复控点/边
的追加语义，保存时可以再排序，稳定编号始终绑定对象。回归另检查新点类型、
未涉及旧点的属性，并在四个独立应用进程中比较模型、完整场景和 DXF。

## 验证

`FreeShip-Tests/qt_advanced.py` 已接入统一 `qt-advanced` 入口：

- 盒体、合成船体、9a 三种模型走真实 Qt 动作和参数窗口，执行五项编辑、取消、
  撤销、重做及保存重开。动作按元数据发现；不依赖菜单位置或固定控件名称。
- 变换坐标与直接调用旧核心的独立探针对照；另检验坐标公式、90° 旋转、共享点、
  面朝向、层及折痕。探针没有调用新的编辑适配器来生成预期。
- 检查整船尺度、标记开关、四类剖面平面、约束拒绝、失败回滚和无变化操作保留重做。
- 保存结果用原读取器检查，完整 DXF 使用精确实体比较，不放宽数值容差。原有曲线、
  流线和型线图交互回归另跑一组。

### 旧画面对照的一个缺口

对 9a 执行本组操作后，原绘制在一条短水线上抛出浮点异常。独立原核心探针看到
该线有 2 个点、`Fragments=1`，调用栈定位到
`FreeShip-Plus-Lazarus/Units/FreeSpline.inc:722` 的 `I/(FFragments-1)`。
同一模型的旧 DXF 导出仍可单独完成，并与 C++ 导出的全部实体一致。

测试保留原异常、采样数量、符号化栈和原 DXF；该完整旧画面对照记 `not_run`，
原因记 `review`，没有生成一个替代旧基准冒充相同。Qt 新生成路径不触发这个异常，
旧项目源码仍未改动。

本批结果及正式目录复核见 [更新记录](DELIVERY-20261101-ADVANCED.md)。离屏事件、
截图不能代表真实桌面输入和整体视觉验收，分别保留 `not_run` 和 `review`。
