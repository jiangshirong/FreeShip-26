# CAD 曲面、三维曲线和坐标输出

2026-11-02。“文件 → 导出模型”增加五个入口；原有型线图 DXF 和
OBJ／STL／FEF 入口继续保留。

| 入口 | 输出内容 |
|---|---|
| IGES 曲面 | 原控制网转换出的 NURBS 曲面片，类型 128；图层颜色用类型 314 |
| DXF 三维剖面与控制曲线 | 全部已定义剖面及控制曲线，按原侧输出三维 SPLINE 实体 |
| DXF 三维面 | 当前精度档的完整细分三角面，3DFACE，保留图层和朝向 |
| 型值 | 剖面和控制曲线的原型值点、分段名、KNUCKLE 标记 |
| 坐标点 | 细分曲面的唯一坐标；可切换为原控制点坐标 |

长度单位可以选择 m、mm、cm、ft、in。IGES 和 DXF 写入相应单位字段；
型值文件首行注明单位。纯坐标文件保持每行 X Y Z，接收端须使用所选单位。
文本数值使用 17 位有效数字，避免写文件时再损失原 Single 坐标。
这不意味着原计算已经变成双精度。

IGES、三维面和细分坐标可以选择包含隐藏层，以及是否补全对称图层。
非对称图层不补镜像；完全处于中心面的几何不重复输出；负 Y 半船也能补全。
镜像曲面只反转一个参数方向，镜像三角面反转顶点顺序，保留朝向。
相机、动画、放大区域和屏幕半船显示不参与输出范围。

剖面和控制曲线导出使用实际定义的原侧数据，不额外镜像，不按显示开关筛选。
三维 DXF 用分段三次样条表示已有插值曲线，保留折角，不把屏幕折线当作曲线。
极短且不重合的参数段会报错，避免静默漏线。型值输出是三维点列，
不是站线与水线交点组成的矩形型值表，也没有根据点列重新拟合船体。

## 曲面从哪里来

2026-11-03：曲面准备已改由 `src/document/cad_patches.cpp` 执行，见
[C++ IGES 曲面准备](NATIVE-CAD.md)。只读 FBM 快照生成私有 Catmull–Clark 曲面，
活动文档、精度档、细分方式、历史和文件修改标记不变。请求按文档 ID 和版本校验，
失败和取消不会发布半份结果。`bridge/cad_adapter.py` 提取的旧转换函数保留为
独立对照，不再用于 Qt 的曲面准备。

**保留的是原转换算法，不是对细分曲面精确等价的承诺。** 非规则顶点附近的
曲面质量、片间连续性和缝合实体仍需检查。若接收方需要当前完整细分网格，
应使用三维面、OBJ 或 STL。IGES 还没有支持导入。

`src/core/cad_export.cpp` 负责新文件的写出。所有输出先写临时文件，再原子替换；
未知格式、错误单位、版本不符、空几何或损坏曲面数据不会覆盖原文件。
Qt 窗口对手填已有路径也确认替换，扩展名错误会拒绝。

## 本轮发现并处理的问题

- 原 `File_ExportIGES` 按屏幕的 `ModelView` 决定是否镜像，并在结束时把
  细分方式硬设为 `fmQuadTriangle`。新请求只操作文档副本，输出范围由参数决定。
- 原 `FreeIGESUnit.pas::Add_Entity_128` 将坐标截成五位小数、节点截成六位；
  原型值和三维 DXF 也截短数值。新写出器保留原值。
- 原 IGES 镜像同时反转行列。新写出器反转一个参数方向，补偿镜像造成的朝向反转。
- 原拼接网格有时以转置方向返回，受对象分配顺序影响；Single 节点插入的顺序
  随之改变。现在先用坐标确定统一旋转方向，保留有向网格，再转换。
- 新写出器第一轮把长数字跨记录拆开。自己的读回能拼接，OpenCascade 却漏面或误读。
  这是本次迁移引入的问题，已改为数字字段整段落在同一记录内；仅 Hollerith 字符串
  可以续行。失败记录保留在 `qt-cad-a`，没有记成上游缺陷。

格式依据：[NIST IGES 4.0 规范](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nbsir88-3813.pdf)
的记录结构和类型 128。IGES 名称等说明字段使用 ASCII；中文文件路径可正常使用，
非 ASCII 元数据以问号替代，窗口已说明此限制。完整工程仍应保存 FBM。
