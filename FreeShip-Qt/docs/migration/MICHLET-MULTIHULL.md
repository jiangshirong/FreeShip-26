# Michlet 双体与波形衔接

2026-11-04。补齐旧 Michlet 窗口的三种船体方式，以及矩形、扇形波形区域参数。
入口仍在“文件 → 导出模型 → Michlet”。窗口沿用 StudioLight，按船体几何、
环境与计算、波形区域分页。几何只读，不临时切换工程单位，不新增撤销记录。

## 船体怎样处理

| 方式 | 输入 | 输出 |
|---|---|---|
| 单体船 | Y≥0 的对称半船 | 一份完整型值表；位置为 0、0。 |
| 单体船，输出为双体船 | 同上，另填片体中心面间距 | 两份相同片体；每份保留原单体体积，总体积为两倍。 |
| 已建好的双体船 | Y>0 的一个完整片体，图层对称生成另一片体 | 检查片体是否关于正半间距处自身对称，再取半宽；每份体积为模型双体体积的一半。 |

两片体的水下宽度不能大于或等于中心面间距。已有双体的检查包括实际细分网格的镜像点、
反向面环及折痕；坐标匹配只容许 Single 运算舍入，不移动点。密集重合点、非对称片体、
敞开水下边、多值半宽会停止输出，原目标文件不被替换。
不同形状的任意多片体编队不在旧三种方式的范围内，本轮也未增加这种建模功能。

## 格式修正

格式依据是 Michlet 作者 Leo Lazauskas 发布的
[9.33 手册](https://www.researchgate.net/publication/380694228_michman_933)，
主要核对 3.1、7.13、7.16 和 8.1 节。没有复制或分发 Michlet 程序。

- 旧 `Forms/FreeMichletOutputDlg.pas::SaveToFile` 只在 `N=1` 时写横向间距，
  第二片体缺一条数值记录；第一片体又被填了非零间距。新输出每片体都有纵、横位置，
  第一片体为原点，第二片体横向位置等于中心面间距。
- 上一批的新输出对箱形船保留了非零艏端行，数值检查虽然通过，却没有检查 Michlet 的
  格式分支。手册要求艏端整行半宽为零。现在明确拒绝平艏，不能把真实艏端压成零来通过。
  箱形船仍用于 AddMass 和型值表检查；Michlet 改用有独立解析体积的尖艏船型验证。
- 零纵倾、零下沉沿用手册支持的 3 号指定值方式；横倾保留 0。没有增加姿态修正或修改船型。
- 单体复制与已有双体的体积含义不同，输出和成功提示均明确“每个船体”的体积。
  米、英尺工程都输出米及 m³，模型本身的单位不变。

## 波形区域与导入位置

窗口可设置 R0、R1、β、径向／角向采样数，以及矩形 X0/X1/Y0/Y1、两向采样数。
留空的距离项按实际水下船长使用原默认值；显式输入不被覆盖。区间必须有正长度，
采样数为整数，每个区域最多一百万点。区域坐标以第一片体中心为原点，X 向艉、Y 向右舷。

“导入 Michlet 波形”增加原点的模型 X、Y（米）。既有默认值仍为半船长与 0；
已有双体通常需要 Y 为负半间距，X 为实际片体纵向中心。需要与产生波形的计算输入一致。
导入执行 X 反向、Y 平移和设计水线高度叠加，支持公英制、撤销与失败回滚。
波形继续排除在静水力、型线图和其 DXF 之外。
