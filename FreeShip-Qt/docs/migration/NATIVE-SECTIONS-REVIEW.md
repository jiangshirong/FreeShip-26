## 筛选与身份

普通剖切只看 `UseForIntersections`；静水力筛选模式只看 `UseInHydrostatics`。图层可见性、对称、`ShowInLinesplan` 不在这里筛除几何，也不在这里自动镜像。

遍历顺序是图层顺序、各层的 `Layer.Items` 顺序、控制面子面顺序。当前静态控制输入保存全局控制面顺序及层索引，能够还原 fresh 加载时各层按该顺序追加的状态；任意已编辑旧对象的层内重排没有单独编码。面换层会删除后重新追加到层列表，因此不能将 fresh 加载对照扩大为所有编辑历史的顺序等价。

全局范围可能来自旧控制点，单个控制面范围来自其子面。它们与上轮定义的“全部被引用细分点范围”不是同一契约。全局和控制面包围盒的平面相交检查使用零界限，没有套下表的 `1e-5` 带宽；不能为了统一接口先改变剔除行为。

原共面边集合按指针排序，仅用于身份查找与防止重复添加，并不通过该排序遍历输出。候选可用稳定网格边索引表示同一性，不应按坐标合并不同边。连接分支有顺序优先级；同一平面上的重合但不相连面，需要独立例子防止被错误地当作同一拓扑对象。

## 阈值不是同一种距离

| 位置 | 原判断 | 含义 |
|---|---|---|
| 穿过一条边 | 两端方程值严格小于 `-1e-5`、大于 `1e-5`，或反向 | 才使用线性插值求交点 |
| 整边共面 | 两端方程值绝对值都 `<=1e-5` | 仍需检查边界或相邻面是否离开平面 |
| 命中单个顶点 | 当前终点方程值绝对值 `<1e-5` | 严格比较与上一行不同 |
| 同边连接及近重复端点 | 欧氏距离 `<1e-4`，另要求边身份关系 | 不能只按距离连接所有面 |
| 闭合样条判断 | 首尾欧氏距离 `<1e-5` | 已闭合点链不参加近邻拼接 |
| `JoinSplineSegments` | 端点**距离平方** `<JoinError` | 调用 `0.01` 对应距离约小于 `0.1`，不是 `0.01` |
| 最近候选搜索提前结束 | 当前最小端点**距离平方** `<1e-5` | 可能接受先遇到的足够近候选，未必搜索到全局最近者 |
| 短碎片过滤 | 控制点包围盒对角线**平方** `<1e-3` | 不是样条弧长阈值；距离尺度约为 `sqrt(0.001)` |

这些尺度跟随模型坐标单位；不能未经说明改成另一套毫米/米意义的容差。平面系数也未在此归一化，`a*x+b*y+c*z+d` 的阈值是方程值。成比例放大同一平面的系数，数学平面不变，近阈值分类却可能改变。

严格比较还涉及常量类型。Single 的最近 `1e-5` 小于对应 Double 常量，不能默认 C++ 加 `f` 后缀与 FPC 完全相同。应以阈值及相邻 Single 的实际分类、必要时编译指令为证；`JoinError` 本身是 Single 参数，和源码直接字面量另行处理。

测试审查发现，若用 `-1 + epsilon` 作为平面常数再转 Single，epsilon 的相邻浮点值会被 1 附近更大的格距吞掉，三组输入实际落成同一平面。测试需将相关边移到 x=0、直接保存 `±epsilon`，并检查转换后的输入仍互不相同。这是测试覆盖的修正，不是产品错误。

## 共面、分支与点链顺序

整条边位于平面时，只有单面边，或至少一个相邻面存在离开平面的顶点，才输出该边。对所有相邻面的检查包含未参加本次图层筛选的面。完全共面的内部共享边不应重复输出，有限平面片的外边界则应保留。端点折角判据也分情况：普通穿边取边的折痕；单顶点命中取“非 Regular”；共面折痕边端点只有 Corner 才标折角。

每个面的命中数组按原有向边环顺序收集。若命中超过两个点，原代码把相邻命中点逐个相连，不是按两两配对；非平面四边形与多分支情形需要明确观察，不能把这个链式规则当作唯一数学截面定义。

生成点链时，从最后一个待处理线段开始，按剩余段原次序扫描。优先尝试尾接首、尾接尾、首接首、首接尾；匹配边身份相同但距离不合格时，该次 `else if` 链不会尝试后面的另一种匹配。共面边另有“共享网格顶点”条件，再按同样端点次序试接。消费一段后从头重新扫描。

随后 `JoinSplineSegments` 按四种端点距离的固定顺序选择相等最小值，允许反向并删除一个匹配端点。它会把坐标足够近的不同连通分量拼起来；即使端点还存在间隙，也会保留固定链的端点、丢掉被匹配链的一个端点。这是继承的拼接启发式行为，不是严格几何相交的证明。

只有进入近邻拼接前结果数大于 1，才执行拼接和短碎片过滤。单条很短交线可能保留，放进多条结果后却被删除；拼接后只剩一条也仍会执行过滤。测试要保留这些条件，而不是把过滤改为无条件统一调用。

## 本轮明确修正的折角丢失

[InsertSpline](D:/桌面文件夹/项目/FreeShip_26/FreeShip-Plus-Lazarus/Units/FreeSpline.inc:880) 的两个向前插入分支存在可定位的写入问题：原固定链先后移，共享点跟着移到 `NoNewPoints`；代码却在原 `Index` 写折角 OR，随后又用源点数组覆盖该处。所读取的源端点也不是这两种匹配的共享端点。向后追加分支没有这项位置错误。

最小例：固定链为 `(0,0,0)→(1,0,0)`，两点都不带折角；匹配链为 `(-1,1,0)→(0,0,0)`，只有末点带折角。正确的拼接点 `(0,0,0)` 应保留折角，因为任一侧的折角不能在连接时丢失。逆转匹配链可覆盖另一种向前拼接。

本轮已决定候选保留正确的共享点 OR，不提供默认复制此错误的策略。已独立读取 [旧核心最小例结果](D:/桌面文件夹/项目/FreeShip_26/FreeShip-Tests/reports/native-sections-oracle-20261101-b/cases/results.json)：两种向前拼接均得到上述三点，但折角都是 `[false,false,false]`，原问题已实际复现。旧样条在 `t=0.75` 的 Y 为 `-0.056190550327301025`，偏离本应在 Y=0 上的后一条直线；它不只是显示字段的差异。

最终运行中，两种候选结果均为 `[false,true,false]`，三点坐标完全不变；`t=0.75` 的 Y 已是 0。候选整条曲线的点、标记、段数、取值、两阶导数和 knots，也与“把独立判定正确的三点及折角直接交给原 Pascal 样条”所得结果相同。测试只允许这两个具名例子的中间标记由 false 变为 true；其它结构、坐标或采样差异仍会失败，没有把任意折角改变笼统归入修复。

另一个静态风险位于原 `CalculateIntersections` 的相邻命中去重：`Move` 以 `SizeOf(T3DCoordinate)` 计算长度，数组元素实际是含坐标、布尔量与边指针的 `IntersectionData`。候选应移动完整结构。当前尚未证明该错误分支在有效、唯一边的面网格中可达，不把源码风险写成已复现的用户故障。

## 上层简化与缓存暂不搬入

`Spline.Simplify` 直接使用 `FTotalLength`，而 `Add`、`SetBuilt(false)` 会将它清零。单条新交线若尚未重建，简化可能因零总长直接退出；多段路径的短碎片过滤会访问 `Min/Max`，从而先触发样条重建。提前读 `Fragments`、`Min/Max` 同样会改变这种懒构建状态。

所以观察探针不能在原算法中途为输出信息调用这些 getter。阶段记录仅读坐标、折角及直接只读的原始字段；如需样条采样，在原算法完成并停止阶段观察后明确重建。上层简化调用若另作比较，应使用独立 fresh 对象。

当前本地 [MeshSectionFingerprint](D:/桌面文件夹/项目/FreeShip_26/FreeShip-Plus-Lazarus/Units/FreeMeshFingerprint.pas:27) 的 `PointData` 只写坐标，没有写顶点类型；而命中顶点或共面边的折角依赖类型。这是本地缓存实现的静态待证遗漏，尚未运行最小复现，也不称为原上游缺陷。本轮不引入该缓存；未来接入前必须验证点型、折角、筛选标记变化都能使相关结果失效。

## 独立验算与证据要求

- 保持尖角的盒体，轴向内部截面应是一个闭合矩形，点落在指定平面上；普通倾斜切面另按平面与盒的解析交点检查。
- 完全共面的有限平面片只输出外边界，内部共享边不重复；只触及单顶点与沿整边接触分别验证，不套一个“有交点”布尔值了事。
- 原始线段、按边连好的链、几何拼接后的链、最终过滤结果分别保留。按输出顺序比较坐标、折角和点数，不能只排序坐标集合掩盖连接错误。
- 直接拼接例覆盖四种方向、等距顺序、已有闭合链、间隙阈值两侧，以及共享折角 OR；强制拼接若纳入接口，也要单独验证。
- 旧新数值使用 JSON 重构 Single 比较，仍不声称原始位模式相同。非有限输入/结果及零法向量拒绝属于安全契约，不伪装成旧行为等价。
- 输出复用、没有交线、失败调用、输入保持不变和重复运行分别检查。实际执行范围与未执行范围需据报告说明。
