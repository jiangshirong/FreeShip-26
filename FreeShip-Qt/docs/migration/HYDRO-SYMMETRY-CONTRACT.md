# 半船与完整船体计算约定

2026-11-11。

对称图层的船面只补一次镜像，非对称图层使用实际船面。完整船面与同一几何的
半船镜像表示应给出相同面积、体积和惯性矩。是否镜像由图层属性决定，不从 Cm 猜测。
Bonjean 和 SAC 共用 A(x,z)，旧文本的排列及小数位数保持不变。

## 本次发现

原生计算已经取消了旧的条件折半，但未检查使用不同顶点编号的重合船面。
长 10、宽 4、高 4 米的完整箱体误开启镜像后，吃水 2 米时仍返回成功：
体积 160 m³、横剖面面积 16 m²、Cm=2，正确几何应为 80 m³、8 m²、Cm=1。
复制一份完整船体也会产生同样的问题，Bonjean/SAC 会照常导出翻倍值。
半船在中纵剖面加封闭面后再镜像，内部面会重合；即使体积碰巧抵消正确，也不能
把这种模型当作有效的外壳边界（内部面仍会影响湿表面等量）。

这不是恢复旧阈值折半的理由。旧补偿不能区分模型重复、尺度口径和真实几何错误。
2026-11-09 改用有向实际截面积分的理由和当时解析样例见
[对称静水力复核](SYMMETRIC-HYDROSTATICS.md)。

## 修正

`Hydrostatics::Impl::prepare` 在生成实际船面时检查非退化面的坐标集合。
相同船面即使顶点编号、面方向或所属图层不同，也拒绝计算；镜像位于中纵剖面的
非退化封闭面同样拒绝。错误会提示检查重复船面和图层对称设置。
主静水力不返回正常数值，独立 Bonjean/SAC 请求不生成文件。

检查不四舍五入坐标，不合并相邻轮廓，不移动控制点，不改变细分精度。
近距离但不重合的船面保持独立，退化的零面积面不作为重合面积判断依据。
校验随当前计算对象缓存；模型或对称设置变化后失效，撤销后重新计算。
两个面积字段直接使用同一份积分结果，不再建立可能独立修正的中间数组。

这项检查只覆盖顶点坐标集合一致的重合面，不是通用的自交检测或实体布尔运算。
不同剖分方式的共面覆盖、部分相交船体仍需专门的几何检查；不能声称全部自动识别。

## 验证

`FreeShip-Tests/qt_hydro_symmetry_contract.py` 接入统一入口 `qt-hydro-symmetry-contract`。

- 半船、负 Y 半船与显式整船：分别和解析面积、体积、水线面惯性矩比较，再作表示等价比较。
- 月池、双体、四浮体、窄缝、微小间隙、非对称及混合图层：孔洞扣除、分离船体相加。
- 倾斜箱体：积分水面高度 h(x,y)，独立检查体积和各肋位面积。
- 主尺度口径切换：指定宽度导致 Cm>1 时，不能偷偷改变实际面积。
- 分别请求 Bonjean/SAC，逐单元检查 JSON 和导出文本的解析值，不只判断两张表相等。
- 重复船面、错误镜像、中央封闭面、错误面方向、水下开口：主计算和附加表均拒绝。
- 对称设置切换与撤销：旧缓存不能绕过校验，恢复有效模型后结果恢复。
- 每次合法计算前后，模型、场景和 DXF 不变。
