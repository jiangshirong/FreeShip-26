# Qt 偏好设置

2026-11-04。入口在主菜单的“编辑 → 偏好设置”。保留旧窗口的“常规、目录、图形”
三页结构和右上角确定、取消按钮，沿用 StudioLight 字体、配色和图标。
语言支持由用户指定的翻译模型负责，本轮没有接入语言选择或修改翻译资源。

## 已接入的功能

- 常规：撤销内存上限、FBM 文字编码。编码只用于之后打开、新建或导入的文档，
  不重新解释当前船模的名称和注释。撤销内存仍沿用现有实现的估算方式，至少保留两个状态。
- 目录：打开、保存、导入、导出、外部计算程序、临时文件。文件对话框只改变初始位置，
  最终写入路径以用户选择为准。背景图片、标记导入、展开图和计算报告也接入对应目录。
  留空时沿用原行为；临时目录用于下次建立计算工作区，已经打开的工作区不搬动。
- 图形：现有主题、控制点大小、绘图标注字号、工具栏图标大小，以及控制网、点、
  剖面线、网格、曲率、法线、标记等颜色。主题文件只读，个别颜色覆盖保存在 Qt 自己的配置中。
  图层颜色用于新建图层，水下颜色用于新船模；已有图层和工程里的颜色保持原样。

没有对应 Qt 功能的旧资源目录和未接入的斑马纹选项未放进窗口。工具栏和窗口外观
仍使用 StudioLight；“绘图配色”改变绘图区，不替换整套界面皮肤。

## 保存与模型边界

配置在 Qt 的 `AppConfigLocation/preferences.json` 中，Windows 通常是
`%LOCALAPPDATA%/FreeShip26/FreeShip_26 Qt/preferences.json`。
正常启动不读取旧程序的用户设置文件。只有在窗口内选择“导入旧版设置…”时才读取指定文件，
不写回旧配置，也不改 `fs` 入口。原运行包中的主题等资源继续只读。
未知的顶层字段和值会保留，其他组件保存的设置不会因本窗口确认而消失。

窗口内修改先留在草稿里，取消不写文件。确定时先校验，再用锁文件、内容摘要和
`QSaveFile` 保存。发现另一个实例已改文件时拒绝覆盖，用户重新打开设置后再处理。
配置写入失败不向计算服务提交。计算请求失败时恢复原设置值，并保留错误提示；
如果恢复文件本身也失败，会明确报出，不伪称保存成功。

`configure_preferences` 由 C++ 文档服务接收，带当前文档 ID 和版本号。
它更新显示绑定，不写入 FBM、不加入撤销步骤、不清除未保存状态；撤销栈中的其他
状态也更新显示绑定，因此撤销和重做不会把新配色改回去。控制点选择、镜头和未提交
的坐标输入草稿均保留。颜色在窗口和 Qt 绘图入口处从旧 `TColor` 的 BGR 顺序转换成 RGB，
原生几何与导出协议中的颜色格式不变。

## 旧设置导入（2026-11-09）

“编辑 → 偏好设置 → 导入旧版设置…”支持 `FreeShip.ini` 和旧文本 `FreeShip.dta`。
导入后可在三页中检查、调整；确定才保存，取消放弃整个草稿。文件选择器取消也不改草稿。
读取结果和跳过原因显示在窗口下方，可滚动、复制。源文件只读。

- INI：撤销内存、FBM 编码、工具图标大小，以及打开、保存、导入、导出、计算程序、临时目录。
  选择便携版 `.coordinate-settings/FreeShip.ini` 时，先读取上一级 `FreeShip.ini`，再覆盖用户项。
  同一文件中的重复键取第一个，与旧 `TIniFile` 一致。其他目录不扫描旧安装或系统用户配置。
- 配色：读取所选配置附近的 `Themes`，用户主题优先，一层父主题后叠加子主题。
  控制点大小、字号、各绘图颜色及透明度存成 Qt 独立值，旧目录移动后仍有效。
  找不到主题或父主题则保留当前配色，不拿新程序中的同名主题冒充旧设置。
  外壳保持 StudioLight。字号输入范围对齐现有计算服务的 1–200，避免导入大字号后显示成 100。
- DTA：按旧源码的固定及可选字段顺序读取点大小、颜色、四类文件目录、撤销内存。
  识别并跳过最近文件、斑马纹、窗口及语言字段，避免后续字段错位。
  DTA 未记录的设置保留当前值。
- 不存在的目录和相对目录不导入。相对路径在旧程序中依赖启动工作目录，不能从 INI 位置推断。
  单项无效数值、颜色或编码会跳过并说明；超大文件、损坏 UTF-8、NUL、DTA 截断或列表长度错误
  拒绝整个文件，先前草稿保留。当前接受 UTF-8（可带 BOM），不猜测旧 ANSI 文本的代码页。
- 语言、最近文件、窗口布局、旧资源目录、尚未接入的线宽与斑马纹选项不导入。
  没有对应设置的主题字段会列出。语言继续由独立翻译工作流负责。

导入使用原有的设置保存事务，不新增绕过校验的写入路径。当前文档的文字编码保持原有归属，
导入的编码只用于之后的文档。水下透明度是显示设置，在快照的 `settings` 中会改变；
这不是船模几何修改，也不写入当前 FBM。配色会按所选值改变 DXF 的颜色，坐标不变。
