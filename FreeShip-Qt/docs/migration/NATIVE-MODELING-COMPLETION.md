# 剩余建模编辑接入 C++

2026-11-03：点属性、点组、标记线和面片整理接入原生文档服务。
这轮完成后，`topology`、`advanced`、`modeling` 三类编辑命令都由 C++
执行；旧桥接拒绝替原生文档执行这三类命令。原 Qt 菜单、窗口和操作方式保留。

| 功能 | 实现位置 | 保留的行为 |
|---|---|---|
| 点名称、点类型 | `src/document/attribute_edit.cpp` | 锁定或约束点可改名称，不能借此改点类型 |
| 创建、编辑、解除点组 | 同上 | 成员点保存锁定状态；允许点组重叠；解除组不删除点，也不自动解锁 |
| 导入、删除标记线 | 同上 | Single 坐标、可见性、曲率字段和已有标记原字节保留 |
| 按折痕分组 | `src/document/face_tools.cpp` | 选定面或可见层内分组，沿非折痕边传播，清理空层 |
| 组装规则面片 | 同上 | 保留 NURBS 规则性、四方向扩展和折痕条件，给面重新分层 |
| 修复相邻面朝向 | 同上 | 先验证全部连通分量，再翻转所需面；非流形、不可定向及受保护面拒绝提交 |

`fbm_codec.cpp` 增加多个记录块一起替换的入口。层记录和面内层引用必须同时
验证，不能先写一半。每次编辑仍在私有候选中进行；发布验证成功后才提交历史。
图层内面顺序与内部层编号计数进入会话绑定，避免连续编辑后编号或遍历顺序丢失。
撤销与重做保留该面顺序；实际 Qt 操作链确认，浮心、稳心和漂心标注恢复到
操作后的精确数值。旧求和使用 Single，不能把遍历顺序变化视为无关细节。
恢复时用保存的层 ID 核对计数，忽略旧装载器临时分配层对象产生的计数。

名称使用会话中的 FBM 编码，包括旧设置中的 Ansi 系统代码页。31 张单字节表来自 LazUtils，原许可证和生成脚本
一起保留；写入前检查往返，无法表示的字符直接拒绝。专项测试发现 FPC 3.2.2
JSON 扫描器会丢掉转义空字符，把 `A\0B` 交给后续逻辑时变成 `AB`。
C++ 请求入口能保留这个字符并拒绝修改；两边的具体行为留在测试证据中。
这是隔离桥接的解析问题，不冒充原 FreeShip 界面已确认的上游缺陷。

## 规则面片与旧版的差异

旧 `AssembleFacesToPatches` 对面对象按内存地址排序。对象分配顺序改变时，
同一组面可能得到另一种合法的矩形分片。新实现用稳定面编号决定顺序。
测试仍严格比较点、边、面朝向、曲面三角形、逐面材料属性和重复项，另外检查
每个面恰好覆盖一次及各片的规则性。合法分片方式不同单列 `review`，不把它
算成与旧版完全相同，也不引入坐标容差。

旧新建层流程没有复制 AlphaBlend，新层为 255；这轮保留该行为。其余可保存
材料、厚度、可见性、水静力、对称、交线及型线图开关按旧流程继承。

## 测试入口

可复用测试源码均留在 `FreeShip-Tests`，接入 `run_tests.py --suite qt-document`：

- `qt_native_attributes.py`：点属性、组成员与锁定、名称、标记、原子拒绝、保存和撤销。
- `qt_native_face_tools.py`：分组、规则分片、朝向、完整图层属性与几何对照。
- `qt/face_tools_probe.cpp`：直接验证不可发布模型的拒绝条件。生产载入已拒绝的
  非流形样本不能靠跳过载入检查进入界面，因此用独立探针验证算法自身的保护。
- `qt/fbm_codec_tests.cpp`：块替换、未改记录原字节保留、名称编码及非法文本。
- `maintenance/generate_fbm_codepages.py`：只读核对生成表与原 LazUtils 映射。
- `qt_modeling.py`：实际 Qt 确认执行分组、分片，以及模型检查窗口内的朝向修复，
  包括取消、撤销、重做。按动作和事件属性发现入口，未执行的入口不会标为通过。

测试输出、私有程序和构建仍在 `C:/FreeShip26Tests`。隐藏 Qt 回调验证不等于
实体鼠标和完整视觉验收；本轮没有使用桌面自动化代替它们。
