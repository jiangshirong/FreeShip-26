## 如何验收

`qt-topology` 收集实际 Qt 主窗口和窄窗口图像，并执行视图开关、选择及编辑动作。
图标逐张比较来源指纹。四视图排列属于用户明确要求的已有设计，因此这里有对应
布局检查；其他未明确固定的尺寸和控件数量不自动判为失败。

像素图和隐藏窗口事件只能证明本机采集到的状态。整体观感仍保留 `review`，实际
鼠标操作仍保留 `not_run`；不能用测试通过代替用户对 UI 是否一致的确认。

`qt-sections-editing` 另采集剖面窗口和四视图交线。曲线使用已完成的 C++ 求交结果，
按旧精度档采样并保留折点；半船/双舷与逐条剖面曲率梳已接入，数值和交互覆盖见 [本批记录](STARTUP-AND-DISPLAY.md)。
新增/删除确认沿用中文按钮，测试走实际动作回调，不通过桌面自动化操作用户窗口。

`qt-overlays` 采集四视图、密集坐标和各动画阶段图像，验证动画期间的完整图片输出、
导航结束动画、隐藏暂停、点计时及交线扩散。测试按动作元数据发现入口，缺失、
匹配不唯一或禁用时记 `not_run`，不以旧菜单位置推断功能失败。
标注布局中的命名文字部分裁切沿用原版规则，不能仅因图像非空就视为可读性通过。
来源、当前覆盖和未完成差异见 [辅助线与标注记录](OVERLAYS.md)。

`qt-backgrounds` 执行隐藏应用的实际背景菜单、文件选择框和标定对话框，再用原
Pascal 文件读取器核对保存的 JPEG 与全部标定参数。测试环境显式加载 Windows
已安装字体，避免离屏截图出现缺字方框；不修改正常应用的字体和设置。入口缺失
或歧义仍记 `not_run`。完整结果与已知绘制差异见 [背景图片记录](BACKGROUND-IMAGES.md)。
