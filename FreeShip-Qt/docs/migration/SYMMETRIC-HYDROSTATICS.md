# 对称船体的截面积与惯性矩

2026-11-09。

全对称船体现在也按实际细分船面计算截面积、水线面、漂心、惯性矩和稳心。
单次计算、吃水表、Bonjean/SAC、CSV/PDF 报告和四视图标注使用同一结果。
图层是否对称只决定是否补镜像，不再决定使用哪套面积公式。

## 旧处理哪里出了问题

原始代码在 `FreeShip-Plus-Lazarus/Units/FreeIntersection.inc::CalculateArea`：
先镜像截线、近距离拼接，再把每个轮廓都转成正向，按 500 段样条积分。
孔洞因此不能作为负面积扣除；计算完多个轮廓后，惯性矩还只保留最后一项。
`FreeHydrostaticCalc.inc` 又按 Cm/Cwp 是否超过阈值决定折半，真实的倾斜截面和多船体
可能被误判。迁移初期保留了这套行为，以便逐项对照；本次有解析例证明后才替换。

## 修改范围

实现位于 `src/document/hydrostatics.cpp`：

- `fullSection/fullArea` 按船面方向累加交线，孔洞自动相减，分离船体完整相加。
  双精度中间量在局部原点积分，最后转换为现有字段类型；不拼近邻，不重采样。
- 对称体积计算也先固定拆分三角面再裁切，使体积和截面积代表同一份曲面。
  相邻面朝向不一致、水下开口、反向封闭船体明确报错。
- 体积、浮心矩、湿面积和裁切坐标使用双精度中间量。复杂船体的一项横倾平衡中，
  原单精度累加得到“已收敛”，独立积分的排水量却相差 0.167 t，超过原 0.088 t 容限。
  修复累加误差后仍按原容限验收，不通过放宽容限接纳这个结果。
- 去掉 Cm/Cwp 触发的折半及 Bonjean/SAC 的倍数补偿。截线缓存仍按文档版本失效。
- 侧面积改用实际 XZ 投影并集。漂心、稳心标记统一使用船底相对坐标，显示时只补一次船底高度。
- 型线图的折角线分区历史上借用了吃水零时的横剖搜索。
  `creaseStationScore/creaseHasVolume` 单独保留这项绘图兼容约定（包括零吃水舍入判定），
  不用于任何物理量、报表或稳性求解。
  这避免数值修复顺带改变折角线显示。原始控制网、细分和型线图导出代码未改。

非平面四边形的体积及平衡纵倾可能与旧的“先裁整个四边形、再拆三角形”结果略有不同。
对称体的倾斜漂心和多轮廓惯性矩还可能有显著修正，不能把旧程序结果一概当作正确基准。
结果仍针对当前精度级别的细分面；不是对无限细分光滑曲面的解析积分。

## 验证与留存

统一入口 `run_tests.py --suite qt-symmetric-hydro --runtime <运行包>`，
安装复验用 `--verify-deployment <dist>`。测试源码在 `FreeShip-Tests/qt_symmetric_hydro.py`。
独立样本覆盖半船、双体、四浮体、月池、窄缝、横倾/纵倾、平移、公英制换算、精度级别、
扭曲面、朝向错误、水下开口、重算缓存和撤销；正式窗口回调检查报告及四视图标记。

新增 `qt_hydro_surface_integrals.py` 从发布的三角船面用散度定理积分。
它对整个湿表面作积分，独立于生产代码的截线边积分，复核水线面面积、形心、二阶矩、
体积和浮心。解析样本同时校验这套参考积分，真实模型和自由纵倾工况也接受检查。
保留原来的 3e-5 数值容差；平衡残差另按求解器原有容限检查。

旧新数值不一致仍留在报告中，以 `review` 单列，不计入通过，也不覆盖历史报告。
非静水力设置、几何、场景和 DXF 继续作精确比较。初次暴露折角线分区变化的失败报告保留。
最终候选、安装复验及文件摘要见
`FreeShip-Tests/maintenance/symmetric-hydro-delivery-20261109.json`。

实际桌面输入、高 DPI、多屏和全窗口视觉验收未执行。非对称船体单侧进流角仍不提供，
外部专业工具、天气衡准及规范验收不是本项工作。相交或重叠的实体还不能当作自动布尔合并的船体。
