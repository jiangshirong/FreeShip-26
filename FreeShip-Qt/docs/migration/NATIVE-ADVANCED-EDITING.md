# C++ 高级建模与约束编辑

2026-11-03：沿用已有 Qt 窗口、菜单和选择流程，将下面 13 个命令的编辑算法及对应
文件写入移到 C++。这是基础控制网之后的完整一组建模工作，不表示整个计算核心已迁完。

| 范围 | 命令 |
|---|---|
| 变换 | 平移、缩放、旋转；点、边、面、曲线选择及全模型 |
| 生成与合并 | 点挤出、边挤出、镜像、合并相邻面 |
| 点约束 | 锚点、直线约束、清除约束、共线、重合、全部解锁 |

`transform_edit.cpp` 负责变换，`topology_edit.cpp` 负责生成、合并和约束定义。
约束定义与单点移动共用 `PointEditor`，保留 Single 运算顺序、锁定及硬锚点规则。
每步先生成私有候选，再校验显示模型、对象 ID 和输出身份，成功后提交同一个撤销步骤。
失败不会更新文档或保存点。旧适配器在外部文档模式下拒绝执行这些命令，避免误走旧算法。

## 需要保留的行为

全模型缩放不只是控制点相乘：主尺度、显式中剖位置、可选标记和十组阻力记录的
长度、面积、体积字段都按原运算顺序更新。速度、系数和其余计算记录不跟着缩放。
原 `Model_Scale` 的剖面平面缩放代码被注释掉；本次保持原行为，只使相交缓存失效。
全模型平移更新剖面平面常数和显式中剖位置；旋转保留原旋转矩阵及可选旋转中心。
持久静水力范围与内存中临时计算对象不是同一字段，不能误把前者也乘上缩放系数。

旋转的直角残差也参加精确对照。当前 FPC 的三角函数与 MinGW `libm` 不完全一致，
因此 `third_party/fpc/trig.h` 保留原 RTL 的参数约化与多项式求值，仅支持既定角度
范围。来源、改动及许可随文件保存；没有通过增大比较容差绕开差异。

FBM 编码器按版本定位这些字段，保留没有修改的记录字节。原读取/保存流程会改变
部分计算记录填充字节，因此原生变换从当前保存状态恢复完整计算记录，再只改目标字段。
这不移动控制点索引，也不改变用户文件格式。旧格式缺少锁定或约束字段时，适配器
只承担格式升级，编辑与最终写入仍由 C++ 完成。

边挤出保留中心线限制、面朝向、折痕及新点类型。点挤出保留负 Y 截至中心线的规则。
镜像保留原平面投影的运算顺序、焊接容差、反向面序和图层。合并面保留线框边、
相关控制曲线拆分及必要的二度点合并；退化面或冲突曲线会在提交前拒绝。

## 约束联动顺序

约束关系相同，更新顺序不同，结果也可能不同。例如根点带动两个点，其中一个点
又参与直线约束；中间投影不是可任意交换的运算。FBM 保存正向引用，没有保存反向列表
的插入顺序。直接重载每个 C++ 候选，会把刚编辑的顺序改掉。

私有绑定增加 `point_anchors`、`point_lines`，保存每个点的有序依赖点 ID。
旧计算副本导出实际列表，C++ 在关系变更时维护，恢复时检查成员后重排。撤销/重做
仍与旧版一致，按文件重建顺序；进程故障恢复保留提交前的实时顺序。这些数据只在
会话里使用，不塞进用户的 FBM。

## 验证与边界

`qt_native_modeling.py` 对照原服务的完整模型、场景、DXF、剖面与历史，并另测
多边挤出、焊接镜像、连接船体上的面合并、反序约束、混合编辑、进程恢复和保存重开。

记录不变、标记跟随开关、旋转中心、边界角度和失败回滚。编码器测试覆盖历史版本。
二者都进入统一 `qt-document`，测试源码留在 `FreeShip-Tests`，报告与构建放 C 盘。
最终测试数和本机程序指纹以 `maintenance/modeling-native-installed-20261103.json` 为准。
