# 编辑、计算窗口与绘图更新的重复工作排查

2026-11-12。这里记录的是当前 Qt 版本的问题，其中多项由迁移后的发布流程引入，
不能拿来指责原版 FreeShip。目标是删除重复工作，不改变船体精度或数值公式。

## 已确认并处理的问题

| 优先级 | 问题与位置 | 处理 |
|---|---|---|
| P1 | `document/document_service.cpp`：没有实际修改的工程设置、重复 snapshot 仍生成并验证完整场景 | 对比实际发布模型和输入，复用已验证的私有产物；修订与历史规则不变 |
| P1 | 同上：保存计算范围、预览开关和附加报告开关，连带重算船体 | 按实际依赖判断，只有几何、显示及计算输入均未变才复用，不仅凭请求名称判断 |
| P1 | 同上：备注修改可快速提交，但撤销、重做又退回全量流程 | 同一判定也覆盖历史切换；文档身份和完整输出仍校验 |
| P1 | `app/model_session.cpp`：后端复用后，界面仍重复解析整个模型、剖面和表面 | 使用旧完整快照哈希及受限元数据补丁构造新快照，并核对完整新文件哈希；不是信任一个 reused 标记 |
| P1 | `render/hull_view.cpp`：纯文字修改也重建四视图显示数据、GPU 状态和标签布局 | 仅在客户端证明绘图不变时替换文档引用；保留已有显示缓存和相机 |
| P2 | `app/model_session.cpp`、`view.cpp`：相同型线图反复解析、上传、布局 | 读取实际文件校验哈希，相同则复用 Scene；同一 Scene 不重建绘图状态 |
| P2 | `document/hydrostatics.cpp`、`document/publication.cpp`：设置、显示和剖面修改反复构建相同细分网格 | 比较网格源块、精度和面累加顺序，复用网格；参数、剖面或格式实际变化时更新或失效对应缓存 |
| P2 | `document/document_service.cpp`：打开静水力窗口再建一套发布阶段已经有的网格 | 窗口默认值和计算共享兼容网格；保存后的范围、名称等仍重新读取 |
| P2 | `document/publication.cpp`：背景、标记等未改变型线图输入的操作仍启动场景进程 | 完整输入一致时从进程内保存的已验证字节写出场景；其余模型内容继续完整验证 |
| P2 | `document/resistance.cpp`、`hydrodynamics.cpp`、`added_mass.cpp`：专业计算提取船型数据另建静水力网格；风力提取又细分一次求长度 | 注入兼容的已有网格；风力长度直接使用同一网格的纵向边界，公式及外部求解器不变 |
| P2 | `document/publication.cpp`、`core/model_snapshot.cpp`：只改几个字段仍将整份几何 JSON 转成文本 | 完整解析后记录三个顶层字段的字节位置，之后只替换名称、修订和设置；其他字节保持原样 |

## 判断边界

- 不是按“这个按钮看起来只影响显示”跳过计算。模型快照、型线图输入必须实际一致，
  元数据补丁也只允许名称、设计者、备注、创建者、预览保存和附加报告开关。
- 静水力网格复用保留控制网、图层、版本、精度及面遍历顺序的比较；
  换模型、变精度、改控制点或参与计算的图层，不会继续用旧网格。
- 几何字节只从本进程已验证的缓存取，不复制调用方可修改的旧输出目录。
  几何缓存字节上限 64 MiB，元数据快照另限 64 MiB；超限使用原完整路径。
- 文件完整性、错误输入、事务失败、保存和撤销规则保留。此处的内存缓存限制
  与用户取消的“测试结果累计 8 GiB 上限”无关。

## 本轮没有删除的工作

检查了编辑/撤销、设置保存、静水力及专业计算入口、前端发布、四视图与型线图更新。
控制点、吃水、单位和精度改变后的必要计算仍然保留。视图相机操作已有独立显示路径，
没有新增后台计算。求解器执行和结果校验不会因曾运行过同名方法而跳过。
本轮没有声称穷尽所有算法优化，也没有以降低精度换取响应速度。

## 测试入口

- `qt-publication-performance`：逐路径耗时，完整产物比较，保存后新进程冷启动重算。
- `qt-publication-ui`：真实 ModelSession 和主窗口回调；检查客户端复用与最新字段，
  不代表实际鼠标/DPI/桌面验收。
- `qt/session_tests.cpp`：非法补丁、嵌套同名键、引号/反斜线、长短字段交替替换与独立 JSON 解析对照。
- 原有剖面、静水力、工程设置、专业计算和编辑回归按变更范围运行。

基线运行包为 `studio-polish-v3-20261112`。相同课程模型私有副本的原始测量、
最终结果和交付哈希见 `FreeShip-Tests/maintenance/publication-audit-20261112.json`。

## 同机实测

课程模型 `9a-Женя.fbm` 的私有副本，Release 构建。以下是同一操作序列中的单次
后端响应时间，包含产物写出，不是所有模型的保证值，也不是鼠标到屏幕的完整延迟。

| 操作 | 优化前 | 优化后 |
|---|---:|---:|
| 重复请求模型快照 | 899.6 ms | 54.5 ms |
| 没有改动直接确认工程设置 | 1238.3 ms | 53.2 ms |
| 修改备注 | 173.7 ms | 57.1 ms |
| 撤销备注修改 | 1393.8 ms | 60.1 ms |
| 重做备注修改 | 1203.3 ms | 60.6 ms |
| 保存预览图开关 | 1165.8 ms | 60.4 ms |
| 附加计算报告开关 | 1166.7 ms | 60.3 ms |
| 保存静水力计算范围 | 1155.1 ms | 61.4 ms |
| 首次获取静水力窗口参数 | 57.9 ms | 2.35 ms |
| 标记显示开关 | 1173.8 ms | 568.2 ms |

真实主窗口回调中，备注修改、撤销、重做约 217～222 ms，包含后台、完整文件哈希
校验及 UI 更新。它们的绘图数据、曲面与型线图对象均复用；四视图更新约 1 ms，
较多时间仍在读出和校验文件。未跳过完整性校验来换取更好看的数字。

改变吃水仍需约 1.33 s，第一次载入约 1.50 s（均仅为本轮后端样本）。
这些路径确实改变计算输入，仍有积分、求交、生成和验证工作；本轮没有将它们说成瞬间完成。

广域回归中遇到两处测试工具问题，保留初次报告：偏好对照测试缺少已经从正式包
移除的旧适配器；旧版本计算缓存的拒绝测试仍要求一段已清理的提示文字。
前者改为显式指定并校验冻结测试适配器，后者核对拒绝、无结果文件和文档未变。
没有为通过测试修改产品计算或恢复旧文案。

最终选定的九组回归合计 **4158 pass、0 fail、0 error、4 review、14 not_run**。
四项 review 是两处外观/桌面对照、原有船型 13 风力系数争议和附加质量工程认证边界。
它们不作为本次性能优化已通过的证据，也没有因本次优化而修改经验系数。
产物沿用统一入口完整上传归档，以服务端回执确认，不下载复核；本地保留报告与索引。
