# 型线图文字避让与边缘吸附

2026-11-10。用户发现型线图缺少四视图已有的文字互斥和边缘吸附。

原 LinesView::layoutLabels 只按缩放比例缓存文字矩形，碰撞时直接略过，
拖动只平移缓存，不看窗口边界。它没有使用四视图的 LabelLayout。

本次让两个视图共用现有 LabelLayout 实现，不复制或修改其物理参数。
型线图屏幕绘制按当前窗口判断碰撞和边缘力；拖动、缩放、调整窗口都会使布局更新。
文字未收敛时以 16 ms 定时器请求下一帧，静止后停止；隐藏窗口不持续重绘。
同值标注的对端位置用来判断刻度方向，命名标注优先于普通刻度。
极拥挤时允许隐藏数值或裁切命名文字，行为与四视图一致，不改标注数值。

image/renderScene 的默认导出路径仍使用原来的固定布局。屏幕动画不写回场景、
模型、DXF，也不进入图片与打印导出；几何精度与剖面生成没有改动。

统一入口：`python FreeShip-Tests/run_tests.py --suite qt-lines-labels --runtime <开发运行包>`。
源码：`FreeShip-Tests/qt/lines_labels_tests.cpp`、`FreeShip-Tests/qt_lines_labels.py`。
检查四边吸附、拖动与缩放期间互斥、移出后恢复、尺寸变化、导出图片不受动画历史影响，
并复用真实船模的原始型线图序列化、填色、裁切、缩放及鼠标事件回归。
计时针对隐藏窗口的实际绘制函数，不作为真实桌面帧率保证；鼠标体验仍需用户确认。
