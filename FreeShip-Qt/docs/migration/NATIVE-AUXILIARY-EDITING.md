# 背景图片、显示和曲线定义的 C++ 实现

`background`、`display`、`auxiliary` 三类编辑请求已在 C++ 执行，代码分别在
`src/document/background_edit.cpp` 和 `auxiliary_edit.cpp`。原 Qt 菜单、窗口、
鼠标标定和曲线选择入口保持不变。修改通过候选校验后才写入同一份撤销历史；
旧适配器在外部文档模式下拒绝代为执行这三类编辑。

## 本轮范围

背景图片支持三个正交视图的导入、替换、平移、比例标定、透明色、容差、透明度、
显示和删除。BMP 继续在原前端转换一次，服务接收 JPEG。原 JPEG 数据与 Quality
字段在移动、标定、保存和撤销中保留；不会因调整位置再次压缩。替换时沿用旧版
“删除该视图记录再追加”的顺序。同值操作不创建历史、不改变图片记录顺序。

显示设置包含半船/全船、法线、标记线、控制曲线、流线、曲率梳及其比例。
隐藏曲线或流线时清除相应的选中状态，其他坐标、图片、计算记录和缓存保持。
曲率比例保留原 Single 值与 `1e-7` 变化阈值。

控制曲线支持按所选边创建、重命名和删除。分叉点拆成多条链，闭环保留重复端点，
已属于曲线的边不会重复分配。删除曲线只删除定义，不删除船体边面；名称引用随
曲线重新编号。曲线稳定 ID 不复用，控制点移动后重新生成相关样条。
独立于船体面的边链还会沿用旧细分规则：边保持折痕，链两端设为角点，中间点
按原规则处理。这些类型变化纳入候选文档，不留给后续显示重建偷偷修改。

流线的起点、投影方向、创建、删除和文件字段由 C++ 管理。**流线沿船体的数值
追踪、控制曲线显示样条仍由只读几何适配器生成**，不算这两项计算算法已迁完。
新增流线的样条少于两个点时拒绝提交；文档、修改标记和撤销记录回到原状态。

旧格式仅在需要新字段时晋级：控制曲线为版本序号 12，背景/流线为 20，名称为 41。
晋级与修改只有一笔历史。无变化、非法输入、过期版本、无效 JPEG、流线未命中船体
及输出发布失败均不提交。原来的图片大小与曲线计数上限继续保留。

## 剩余边界

新建/导入、部分旧格式装载和格式转换、四视图网格与上述辅助曲线计算，仍有
Pascal 依赖。静水力/稳性、阻力推进、板材展开及 IGES 曲面准备也还要迁移，
包括其余分析参数的修改。当前并非全软件迁移完成。
