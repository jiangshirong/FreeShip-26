# 专业计算窗口的参数布局

后续更新：多曲线、图例及量纲轴已在[专业计算图表](CALCULATION-CHARTS.md)完成。
以下保留本轮参数布局的范围与当时边界。

2026-11-09。覆盖十个阻力、五个推进、三个水动力工具及附加质量，共 19 个入口。
这次改动落在 Qt 窗口，不改船体几何、计算公式、求解器协议和报告数值。

## 从长表单恢复分页

原版有“常规”和“附加数据”之分，之前 Qt 把这两页的字段接成了一条长表单。
现在从保留的 18 份 LFM 读取字段的原页面归属，生成 `calculation_pages.h`，
同时记录原文件指纹。七种阻力方法恢复附加数据页，其他方法不显示空页。
附加质量使用独立的 C++ 参数定义，仍放在常规页。

常规页保留参数与曲线并排；附加数据按原分组显示，宽窗口分两列，窄窗口回到一列。
长标签可以换行，参数表可以滚动。大字号下列宽按当前字体调整，不靠截断标签腾空间。
计算、取消、关闭及报告导出放在顶部；完整工况的保存、载入及保存到船模放在底部。
沿用 StudioLight 和原图标，没有改语言目录。

结果和帮助各有独立页面。结果页提供曲线数据、曲线、报告；附加质量保留矩阵与型值预览。
常规页与结果页的曲线选择同步，不必为了换曲线返回参数页。
操纵性及附加质量在常规页显示文本结果，原有完整报告与矩阵仍可单独查看。

## 输入与结果边界

所有页面共用同一组输入值。切页、字号变化和窗口缩放不会重建输入；计算、提取或载入
参数需要刷新字段时，保留当前页和滚动位置。没有编辑的数字继续保留完整值，界面显示
小数位数不参与重新舍入。推进系列的联动选择、水温换算和计算取消沿用原动作。

CSV、TXT、JSON、PDF 的数据和生成函数保持不变，只将四个导出入口收到同一菜单。
运算失败或取消仍保留上一次完整结果，不把不完整输出写进报告。

## 回归

统一入口：`python -B run_tests.py --suite qt-calculation-layout --runtime <运行包>`。

- 19 个正式窗口，9/14/18 点字号及两种窗口尺寸；采集页面、字段、标签、按钮和截图。
- 检查全部参数可通过页面及滚动条访问，切页/缩放不丢值；原页面归属另与 LFM 比较。
- 正式提取、计算、取消、重新计算后取消、保存到船模、参数文件往返，以及附加页往返。
- 表格与曲线值、CSV 数字、报告和 PDF；推进系列联动、水温换算及附加质量预览。
- 核对旧源文件、模型及本轮源码指纹；安装后从实际 `dist` 路径再跑代表入口。

原 CALCPROP 的三个任务仍存在“正常退出但没有结果文件”的依赖问题。
测试先独立复现该问题，再保留 `not_run`；协议样本只能验证这些窗口的结果展示，
不能当成真实工程计算通过。真实数据库查看器缺失的限制也没有消失。

这份记录只收尾参数分页、操作区和结果/帮助组织。原版全部图表的多曲线叠加、
图例与坐标轴细节还需要另一组绘图工作；真实鼠标、焦点、系统文件框、多屏观感
仍需桌面验收。隐藏窗口截图和事件回归不代替这两项。
