# 四视图曲面与控制曲线

2026-11-03。这一轮替换四视图的派生几何生成，继续使用现有 Qt 界面和绘图代码。

`src/native/surface_display.cpp` 从型线图已构建的细分层生成三角网、面上的点法线和
控制曲线样条。没有再建立一份 C++ 细分曲面，也没有简化线条、减少点数或改变导出。
三角形仍按控制面稳定 ID、子面顺序作扇形拆分；不可见图层仍保留几何。控制曲线
保留点序和折点，不把屏幕采样结果写回模型。

`bridge/ModelService.pas` 只负责把结果和现有设置、实体定义一起发布；正式路径跳过
旧三角网复制、旧法线计算及旧控制曲线样条读取。原分支只作测试对照。模型快照和
`surface.json` 都核对完整几何内容，工作进程报告绑定当前文档和版本。校验失败或
输出目录不可写时，不提交候选，也不增加撤销记录。

显示结果纳入原有磁盘缓存，实体 ID、图层状态及显示法线开关参与缓存键。关闭工作
进程后可复用；缺文件或哈希不符时重新生成。缓存容量上限包含这份新增数据。

## 法线的一项历史行为

旧源码 `Units/FreeGometry_Functions.inc:5` 的 `AddPoint` 在向量相加后，会把负 Y
置零。`Units/FreeSubdivisionPoint.inc:101` 的 `FGetNormal` 用它累加相邻面的法线，
因此倾斜面上的显示法线可能偏离普通向量求和结果。第一次对照在这里发现差异。

迁移时用单独的 `legacyNormalAdd` 保留这项行为，避免误伤坐标运算。独立箱体、倾斜
底面和旧核心对照都覆盖它。这里没有把历史行为当成正确数学公式；后续若修正，应
同时核对法线显示、依赖法线的着色和旧流线追踪，另立变更，不能混在迁移中静默修改。
