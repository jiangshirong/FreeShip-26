# FBM 内嵌预览刷新

2026-11-05。

以前 Qt 会原样保留 FBM 中的 JPEG。这样能避免无意重编码，但船模修改后，
旧预览也跟着保留下来。这次接入保存流程：文件已开启预览且模型有修改时，
用当前曲面生成 400×300 的四视图预览；未修改的文件仍逐字节原样保存。
工程设置“常规”页提供“保存预览图片”开关，新建船模默认开启。
开关支持撤销、重做；关闭后会移除内嵌 JPEG，重新开启后在下一次保存时生成当前船模图片。

## 实现

- `render/model_preview.cpp` 复用当前不可变曲面和四视图的软件深度绘制。
  四个投影都按全船范围取景，颜色继续使用 StudioLight 和原图层、水下着色设置。
  缩略图入口只绘制船体，不创建编辑标注和窗口标题。完整曲面、计算精度和正式导出没有改变。
- `document/preview_image.cpp` 只替换原预览的宽高、长度及 JPEG 字节。
  新图片必须是有效的 400×300 JPEG，最多 512 KiB；原文件中的背景图片、
  计算记录、控制网和其他字段均保持。加载原文件仍不解码或重编码旧预览。
- `save` 只准备待保存副本。目标与备份成功写入后，`mark_saved` 才接纳新预览并标记保存。
  取消、失败或过期请求不能把待保存图片提前放进已提交状态。随后再次保存不会恢复旧图。
- 启用开关时，文档服务先存入合法的空白 JPEG，以便不带渲染器的原始保存仍可被旧版读取。
  正式 Qt 保存会在写入目标文件前用当前船模替换它。新建船模沿用 Plus 默认启用预览的行为；
  已加载文件保持自己的设置，不会因打开而自动开启。

初次实现直接调用完整视图绘制，隐藏窗口测到每次生成预览约 477–510 ms；
分段测量显示开销集中在第一次绘制的字体和标注路径。拆出缩略图入口后，
三个模型的正式保存回调分别测得约 2.2、12.6、13.1 ms；9a 为最后一项。
这是预览生成耗时，不含文件写入，也不代表所有机器或复杂船模的保证。

## 验证

统一入口：`python -B run_tests.py --suite qt-preview-image --runtime ../FreeShip-Qt/dist`。

测试代码保存在 `FreeShip-Tests/qt_preview_image.py`、`fbm_preview_bytes.py`、
`qt/preview_image_tests.cpp` 及原来的 `qt/fbm_codec_tests.cpp`。

- 独立的历史格式样本覆盖全部 45 个版本；预览开关两种状态共 90 组。
  用测试写入器的原始偏移核对替换范围，而不是用被测解析器给出的偏移充当预期。
- Python 按原二进制格式独立提取预览，逐字节检查图片之外的数据，并用 Pillow 解码新 JPEG。
- 覆盖损坏图片、超限、尺寸错误、未知扩展、关闭预览、失败重试和过期请求。
- 开关覆盖 29 个支持预览的格式版本；另查旧格式显式开启时升级、撤销恢复原字节，
  以及正式 Qt 的开启、关闭、撤销、重做、新建和首次保存。实际设置控件另跑字体与窗口尺寸回归。
- 三个船模通过正式 Qt 保存动作检查新图、旧备份、重复保存和重启读回；
  独立绘制探针加载与正式窗口相同的曲面和剖面数据，避免只拿控制网作比较。
- 保存后的文件还交给隔离的旧版读取器打开；正式型线图、DXF、曲面及剖面结果保持。
  保存保护、异常恢复和文档发布回归另行运行。

最终安装、报告、图片指纹及测量值见
`FreeShip-Tests/maintenance/preview-image-installed-20261105.json`。

## 仍保留的边界

关闭预览、不支持预览的旧格式，以及带未知扩展数据的文件不会被擅自改写或升级。
只有用户主动在工程设置开启预览时，过旧格式才按现有版本转换流程升级。
缩略图是查看文件用的小图，不承担工程出图功能。
旧版真实文件浏览窗口、原生文件框、多屏和硬件断电仍未验收。
