# 静水力附加报表

## 2026-11-13：统一计算入口

当前设计静水力窗口只保留左侧主「计算」按钮。一次请求同时生成主结果、Bonjean、横剖面面积、重量和首尾水线位置；附加表切换只展示已有结果，原附加表计算按钮已删除。

面积与首尾位置仍使用剖面线中已定义的水平水线，主报告横倾、纵倾不改变这些附加表的参考系。没有有效水线或肋位时显示具体缺项，独立可算的重量仍可保留，不制造面积或首尾位置。重新完成的请求替换整组结果，取消请求保留上一次完整结果。

本轮优化保留细分级别、求交策略、积分精度和文本格式：面积积分跳过不需要的形心/惯性矩；附加水线体积遍历跳过湿表面积和体积矩；重量按预建图层面索引遍历。相同工况复用主结果，附加表复用完整结果；剖面定义变化保留按平面索引的积分缓存，模型、材料或相关设置变化失效重算。缓存有容量限制，且仅驻留当前进程。

可复用验证入口为 `FreeShip-Tests/run_tests.py --suite qt-hydro-combined --runtime <候选运行目录> --baseline <修改前运行目录>`。数值依据、实测耗时和交付记录见同目录 `HYDRO-COMBINED-20261113.md`。

| 文件 | 内容 |
| --- | --- |
| SACs.txt | 各水线下的实际完整横剖面面积，不作系数阈值折半 |
| Bonjean.txt | 同一组水线与肋位的实际截面积矩阵，采用 Bonjean 文本排列 |
| Sterns.txt | 各水线的首尾纵向位置 |
| Weights.txt | 图层各细分面的完整面积、重量、形心及纵向范围 |

附加表使用剖面线窗口中已定义的水平水线，坐标为模型原点下的 Z。它们与主报告的
横倾、纵倾工况分开。计算只读模型：每个肋位求交一次，各条水线复用同一组曲线；
不重建每条水线的细分网格，也不移动船体或改变设计吃水。

历史布尔字段按 `FreeProjectSettings.SaveBinary` 自 39 版起保存。读取和保存时保留该字段，
计算按当前按钮发出的请求执行，模型版本和撤销状态不随之变化。

实现参考 `FreeHydrostaticCalc.BuildAuxiliaryReports`、
`FreeSubdivisionLayer.CalculateSurfaceProperties`，并复用现有 C++ 求交与静水力计算。
这两处旧行为没有照搬：

- 旧首尾水线表把绝对水线 Z 当作吃水，船底不在 Z=0 时重复加上船底高度。
  新表明确区分水线 Z 和相对船底的吃水；无排水的水线在 JSON 中标记为 dry。
- 旧重量明细每个子面只记录最后一个三角形的面积和形心，与图层合计不一致。
  新明细使用完整子面的面积、面积加权形心和纵向范围。

SAC、Bonjean 和首尾表保留原文本排列。重量表改为显式标注的 **Weights v2**，
不冒充旧定宽格式；依赖旧 Weights.txt 列位置的外部程序需要适配。
公制密度为 t/m³、厚度 mm、重量 t；英制分别为 lb/ft³、in、long ton。

Bonjean 和横剖面面积需要 1–99 条水线与 1–99 个肋位。程序计算最低漏点及以下的水线，表格上方列出跳过的水线高度。导出文件的水线数量与实际生成的行一致。
重量独立使用图层和细分面，可以在没有水线和肋位的模型中计算。
