# 工程设置、图层和剖面的 C++ 实现

`update_project`、`update_layer`、`manage_layers` 和 `sections` 已在 C++ 执行。
Qt 继续使用原窗口和菜单；候选文档通过输出校验后才提交历史，旧适配器已禁止
代为执行这四类修改。代码在 `src/document/project_edit.cpp` 和 `definition_edit.cpp`。

## 范围与兼容细节

工程设置包含名称、设计者、说明、单位、主尺度、水密度、附体系数、中船位置、
交线简化、精度和水下颜色。后续补齐了预览保存、[静水力系数口径和五类标注](PROJECT-HYDRO-OPTIONS.md)。
图层包含现有全部可编辑属性、新建和删除空层。
横剖、纵剖、水线和斜剖均支持批量添加、改距、删除、清空及曲率标志。

单位转换先执行，再应用同次请求明确填写的新主尺度。控制点和标记保持旧
Single 运算顺序；密度、质量和部分设置沿用原 Double 换算再写回 Single。
背景图比例、流线起点、剖面、材料和计算参数一并转换。锁定、锚点和直线约束
定义保持原样，不额外触发依赖点移动。自动中船位置打开时，隐藏的手动中船值
仍会换算，关闭自动选项后不会跳回旧单位。

启用静水力会自动打开图层对称；同次提交明确填写“不对称”时，最后执行该
选择。未命名图层的翻译名称仍只是显示值。重复提交该名称或当前系统颜色不会
改写空名称和 Windows 颜色标志。新图层 ID 不复用旧号，至少保留一个图层。

斜剖距按原平面定义换算，重复距离保持原 Single 值及判定阈值。船体外的
剖面仍保留定义；计数限制先于重复值过滤。曲率标志、排序、保存与撤销均对照。
无变化提交不新增历史、不丢失重做分支。输出失败、非法参数和重复 JSON 字段
均被拒绝。格式升级与修改只提交一次；已补齐转换入口遗漏的版本白名单。

## 保留的测试

- `qt_native_project.py`：双向单位转换、显式覆盖、阈值、编码、系统色、缓存、
  保存、撤销、失败恢复，与旧适配器逐步对照完整模型、场景、DXF 和剖面。
- `qt_native_definitions.py`：图层、四类剖面、稳定 ID、旧格式升级、无变化提交、
  重复字段拒绝和输出失败回滚，另有独立平面和持久字段预期。
- `qt/project_edit_probe.cpp`、`qt/definition_edit_probe.cpp`：直接检验早期 FBM
  布局、缓存和无关原字节保留。样本在 C 盘生成，不改用户文件。
- `qt/project_units_math.pas`：使用原编译器核验换算常量和 Single 阈值。

## 剩余边界

原生探针覆盖早期格式，生产装载仍经过旧 loader；1.65 以前的部分布局仍无法
完整加载。不能把“原生能读写”说成“应用能打开所有历史文件”。全部主尺度为
零，以及只剩退化投影的某些图层组合，仍被后续计算/场景校验拒绝；已验证
失败不提交。本轮没有重写这些计算和显示边界。

显示/背景/辅助线的部分字段编辑、新建和导入时的旧装载、四视图网格、完整
静水力、阻力推进、板材展开及 IGES 曲面准备仍有 Pascal 依赖。实体鼠标、
焦点、DPI 和完整视觉保真另行验收；隐藏 Qt 回调不等于桌面验收。
