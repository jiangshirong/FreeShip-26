# 剩余文件交接：部件、VRML、波形与计算输入

2026-11-04。入口均位于 Qt 的“文件 → 导入模型 / 导出模型”。
源码、人工构造样本和故障检查保存在项目内，统一测试入口为 `qt-legacy-exchange`。

后续已补齐 [Michlet 三种船体方式、波形区域及导入原点](MICHLET-MULTIHULL.md)，
并纠正本批未发现的非零艏端兼容性问题。下方结果保留本批当时的验证范围。

## 本次接入

| 入口 | 行为与边界 |
|---|---|
| FreeShip `.part` 导入 | 追加到当前工程，支持撤销、重做、保存重开；不覆盖船名、主尺度、背景图和原有控制点。文件版本按原枚举读取，最高 4.6.2。 |
| FreeShip `.part` 导出 | 输出已选面；没有选面时输出可见图层，可包含隐藏图层。保留控制点、锁定状态、折痕、图层属性和全部边都在部件内的控制曲线。不保存工程参数、背景图及跨部件约束。 |
| VRML `.wrl` / `.vrml` 导入 | 读取 VRML 1/2 静态 IndexedFaceSet，处理嵌套变换、DEF/USE、面朝向和反射。默认保留多边形外形，也可作为平滑控制网。文件 XYZ 不自动换轴。 |
| Michlet 波高 `.mlt` 导入 | 矩形和扇形网格追加到当前模型，使用全部声明的行列。米换算为工程单位，纵向以半船长为原点，波高叠加到设计水线。图层不参与静水力、剖切或型线图，不镜像、不平滑波高。 |
| Michlet `.mlt` 计算输入 | 对称单体半船，生成等距横剖站和水线型值；包括环境、速度区间、摩擦方法及旧版默认波形区域。这里只输出文件，不运行 Michlet。 |
| AddMass `.txt` 计算输入 | 对称单体半船，输出型值和面元、精度、水深、漂角、航速、角速度、对象编号。这里只输出文件，不运行附加质量计算。 |
| 矩形型值表 `.csv` | 使用已定义的横剖站与水线，行列标题保留实际坐标和单位；无交点留空，同一格的多个 Y 值用分号保留。不会把无交点写成零。 |
| 折痕与边界线 `.dxf` | 导出当前精度的细分边线，包含图层与单位；可补对称另一舷。与原控制多边形、三维剖面样条入口分开。 |

部件没有文字编码标记，因此窗口提供 UTF-8、Windows-1252、Windows-1251、GBK。
导入默认沿用当前工程编码，导出默认 UTF-8；接收端须采用相同编码。
编码不兼容会停止写入，不把文字悄悄改成问号。

VRML 的材质、纹理和法线不转换为船体属性。动态节点、外部 Inline、未支持的几何节点会拒绝
整个导入；不读取外部资源，也不只导入文件中碰巧认识的部分。非共面多边形不能作为严格保形
网格导入，但可以明确选择控制网模式。退化面仍拒绝，不自动删除。

本批 Michlet / AddMass 限于 Y≥0 的对称单体半船；Michlet 的单体转双体和已有双体
在后续补齐，AddMass 实际计算与结果流程仍未迁移。
一个水线高度有多个不同正半宽、或水下存在敞开边时停止输出，不取最外点掩盖断面问题。
本批 Michlet 波形区域沿用旧版默认范围；后续已开放区域与采样数设置。
AddMass 的对象编号需按接收版本核对。实际接收程序的兼容性不由“文件写出成功”代替。

## 原流程中的问题及本次处理

- `FreeEdit.inc::File_ImportPart` 在文件尚未读完时向活动曲面添加点、边、面。
  新流程先读完、校验并构造候选，再一次性追加。失败保持原文档和撤销历史。
- 原部件导入只换算点坐标。新流程同时换算图层材料密度和板厚，板厚仍按旧约定使用 mm/in，
  不能与模型坐标的 m/ft 混为一谈。
- `File_Import_MichletWaves` 截去一半矩形网格，强制改写末行横坐标，末列还可能重复前一字段。
  新读取器逐行校验数量、有限值和坐标单调性，完整读取末列与零波高行。
- 波谷曾被算进船底，导致追加波形后水线下降。`hydrostaticKeel` 现在只取静水力船体的基准；
  没有静水力面时才退回全部关联几何。波浪图层仍参与四视图缩放范围。
- 型线图 DXF 原折痕路径未检查 `showInLinesplan`，波形虽不显示，折痕却写进了船体 DXF。
  新路径按图层筛选；测试比较追加波形前后的完整型线图和 DXF。
- `FreeMichletOutputDlg.FBuildOffsets` 的循环遗漏端部横剖站。新输出完整处理两端，
  水下纵向范围也包括三角面与水线的交点，不只看水下已有顶点。
- 原断面与水线相交依赖固定数量采样。新型值输出逐段求三次曲线根，按导数极值分区，
  同时处理相切与多交点。沿用既有断面样条和折角，不降低细分精度。
- 高度整体偏移较大的平面 VRML 网格会触发旧排版边界倒置。仅在边界无效时按实际投影范围恢复，
  不平移源模型或改变普通船体的排版。
