# 板材展开

2026-11-02。入口：计算 → 板材展开。图层需要先勾选“可展开”。

Qt 管理板片列表、显示、布局和输出。2026-11-03 已将展开计算接入 C++ 文档服务，
直接使用原生细分曲面；不替换编辑文档，不增加撤销记录。算法、对照和边界见
[C++ 板材展开](NATIVE-PLATES.md)。下文保留原窗口迁移时的行为说明。

## 已接入的操作

生成/取消；板片选择和显隐；左键移动、右键平移和滚轮缩放；旋转、位置、镜像及
重新排列；填色、水下色、内部边、误差边、名称、角点坐标、包围框；四类剖面线；
网格间距和字号。颜色取自图层和工程设置。

镜头和板片布局变动只操作 Qt 中的几何，不重新展开。计算失败或取消保留上一份
完整结果。新计算成功后重新排列板片；窗口内的布局不写回 FBM。

误差分别显示长度、面积和无量纲值。边误差是展开长度减原长度；面积既保留有符号
总差，也保留各面面积差绝对值之和，避免正负误差抵消。对称合并板片的面积按两半
统计，边误差及无量纲评分不乘二。这些数值不是材料成形余量或加工精度保证。

## 输出约定

- DXF：全部可见板片的完整闭合边界及勾选的剖面线，带孔板保留内轮廓。
  `$INSUNITS` 标明 m 或 ft；坐标保留 17 位有效数字。对称合并板片仍以两侧
  闭合轮廓输出，保留共有中线，不是去重后的自动切割路径。
- TXT：按原版约定，每块板片以其边界最小 X、Y 为原点，保留全部边界顶点和单位。
- JSON：展开数据、误差及当前布局的完整记录，不是可编辑船模；当前没有载入入口。
- PNG：全部可见板片，不受当前屏幕裁切、缩放或平移影响。
- PDF / 打印预览：适合单页或指定 1:n 比例，公制/英制换算成物理尺寸，超出纸面
  自动分页；超过 500 页拒绝生成。实体打印仍要核对驱动是否额外缩放。

文件先写临时目标，成功才替换用户选定的文件。取消、无可见板片、无效格式及
过多打印页等失败不会截断原文件。原算法仍用 Single 坐标；保存更多有效数字
不会提高原曲面的计算精度。

## 发现和处理的旧问题

位置以保留的 `FreeShip-Plus-Lazarus` 为根。修改只用于新程序的隔离构建副本。

| 代码位置 | 情况和处理 |
|---|---|
| `Units/FreeDevelopedPatch.inc::SaveToDXF`，`if FMirror then` | 镜像分支缺少遍历顶点的循环，只写入一个顶点。新 Qt 输出遍历完整边界图，普通侧和镜像侧均形成完整闭合轮廓。 |
| `Units/FreeDevelopedPatch.inc::Unroll`，`for J := 2 to 1 do` | 循环不执行，弯曲的展开中线没有经过共线检查，可能错误合并两半。现在检查全部中线点，并按 `DistancePointToLine(待测点, 起点, 终点)` 调用；不能共线的两半分别保留。 |
| `Units/FreeDevelopedPatch.inc::IntersectPlane`，整条边位于平面的分支 | 分支为空，剖面恰好通过已有边时会丢线。现在收集该边并去重；整张面共面时不凭空生成交线。 |
| `Units/FreeDevelopedPatch.inc::Unroll/ProcessFaces`；`Units/FreeSubdivisionLayer.inc::Unroll` | 临时列表和当前板片缺少异常退出清理。补齐释放后，在展开搜索和剖面收集中检查取消，失败不影响常驻编辑文档。 |
| `Units/FreeEdit.inc::Layer_Develop` | 多创建一个板片后立即用列表中的板片覆盖指针，异常路径还可能跳过清理。新入口直接管理板片列表，不构造原展开窗口。 |

未加入材料补偿、自动排料、碰撞检测、焊接余量或 CAM 路径。双曲率板片仍可能
产生较大展开误差。
