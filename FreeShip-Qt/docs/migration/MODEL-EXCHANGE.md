# OBJ、STL、FEF 模型交接

2026-11-02。Qt 的“文件 → 导入模型／导出模型”已接入这三个格式。
解析和格式输出由 C++ 完成；导入后的编辑、FBM 保存及四视图细分仍由原计算服务管理。
这不是全部文件格式迁移完成。后续已接入 [CAD 曲面与坐标输出](CAD-EXPORT.md)，
GHS、部件、型值建模导入及其余专用格式仍在清单中。

## 可以做什么

| 格式 | 导入 | 导出 |
|---|---|---|
| OBJ | 顶点、正负索引、纹理/法向索引、对象与分组、平面凹多边形；可选择网格或控制网 | 完整细分曲面或原控制网，图层作为分组，17 位有效数字 |
| STL | ASCII、二进制，包括文件头以 `solid` 开头的二进制文件 | ASCII 或二进制，三角面方向及法向一致 |
| FEF | 原字段布局中的主尺度、单位、控制点类型、折痕、图层及材料属性 | 原控制网及上述属性；不会按显示状态筛掉图层或补出镜像 |

OBJ/STL 没有可靠的通用单位标记，需要选择文件单位；支持 m、mm、cm、ft、in。
英尺文件使用英制工程，其他单位换算为米。默认坐标轴就是 FreeShip 的 X/Y/Z；
旧 FreeShip OBJ 的 Y/Z/X 顺序由单独选项控制，不根据外形猜测。

OBJ/STL 默认按网格导入，保留原多边形外形。凹面先按边界三角化，不能用扇形填满缺口。
OBJ 勾选“作为控制网导入”才允许细分平滑；OBJ 本身没有 FreeShip 折痕信息。
STL 只合并在计算核心精度下完全相同的顶点，不做距离容差合并。
完整船体默认不启用额外对称，半船数据可以主动勾选镜像。

OBJ/STL 导出默认包含可见图层，并补全标记为对称的图层；中心面只输出一次，另一舷反转顶点顺序。
负 Y 半船也能正确镜像。半船显示、镜头、缩放和动画不参与导出。
可选择仅原侧或包括隐藏图层。文本保留原 Single 数值，不再先截成四、五位小数；
二进制 STL 按格式使用 32 位浮点数。提高输出位数不等于提高原模型的计算精度。

导入是打开一个新的未保存工程。修改过的旧工程仍使用原保存/放弃/取消流程。
新数据完成校验、构建和型线图生成后才替换活动文档；失败保留旧文档和历史。
之后可正常编辑、撤销、重做、保存 FBM、重开。导出用原子替换，失败不覆盖旧文件；
手输已有路径也要确认替换，扩展名不符会拒绝。

## 从旧代码发现的问题

路径均以 `FreeShip-Plus-Lazarus` 为根。旧项目保持原样，修正在 Qt 工程内完成。

- `Units/FreeSubdivisionSurface.inc::ExportObjFile`：导出交换成 Y/Z/X，导入却直接当 X/Y/Z；
  小数只保留四位，镜像还依赖显示开关。新入口明确坐标轴与输出范围。
- `FreeSubdivisionSurface.inc::ImportObjFile`：直接用正索引取点，负索引、空白和越界处理不足；
  对象分组被丢掉。新解析器先检查完整文件，不调用这个旧入口。
- `FreeSubdivisionSurface.inc::ImportFEFFile`：读完 `FSymmetric` 后又写成 `True`，
  非对称模型往返会变形。新导入按文件中的值恢复。
- `FreeSubdivisionControlPoint.inc::SaveToStream`：控制点先舍入到五位小数；
  `FreeEdit.inc::File_ExportSTL` 的坐标只保留四位。新文本输出保留原数值。
- `FreeEdit.inc::File_ImportSTL`：按首行是否为 `solid ` 判断格式，且读取前清空活动模型。
  新入口优先验证二进制计数与总长度，解析和构建失败不会清空旧工程。
- `FreeEdit.inc::File_ExportSTL`：导出中调用 `Model_Check`，可能顺带改变模型。
  Qt 导出只读完整快照，模型修复仍是单独的编辑操作。

迁移测试还发现一处不能照搬的调用顺序：`FreeSubdivisionSurface.inc::Initialize`
会把少于两个邻面的点改成角点。真实 9a 船模有两个折痕点受到影响。因此先初始化边界，
再恢复文件中的折痕和顶点类型，避免控制点坐标没变、生成曲面却变了。

## 边界

- FEF 不是完整工程备份：不存剖面定义、控制曲线、标记、背景图、锁点/约束、点组和全部计算参数。
  选择状态不作为交接内容。完整保存仍用 FBM。
- OBJ 不导入外部材质/纹理、平滑组或自由曲线/曲面；不读取文件里引用的外部路径。
  不支持的几何记录会拒绝，不默默丢掉。STL 不保留图层材质和颜色扩展。
- 文本格式使用 UTF-8。文件路径可以是中文，但模型文本还受当前 FBM 编码限制；
  默认 cp1252 无法保存的字符会明确报错，不能替换成问号后继续。
  统一 FBM 文本编码仍待原生读写迁移处理。
- 每次导入最多 128 MiB、10 万顶点、10 万面、每面 4096 个顶点、1000 层；
  按原精度估算超过 100 万个细分三角形时拒绝，不暗中降低精度。
  重复面、非流形边、退化面、无效索引和不完整记录均有检查。
- 隐藏 Qt 窗口验证实际菜单和提交回调，不等于真实鼠标、系统文件选择器和外部 CAD 软件验收。
  尚未逐一核对原版所有格式窗口的完整视觉布局。
