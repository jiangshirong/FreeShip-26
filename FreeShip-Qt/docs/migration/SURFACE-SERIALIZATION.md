# 曲面结果编码优化

2026-11-05。上一轮计时显示，四视图曲面结果的 JSON 生成比剖面求交耗时更多。
同一顶点出现在多个三角形里，原实现会重复生成坐标数组、三角形对象，并重复把坐标转换为文本。

本次只修改 `src/native/surface_display.cpp` 的结果编码：

- 每个细分顶点的坐标仍由 Qt 编码一次，保留原 Single 转 Double 后的完整表示。
- 三角形和分析拓扑直接复用该编码。法线按顶点缓存文本，保持原法线算法及输出顺序。
- 固定 JSON 结构直接组装，键序、字段、层号、顶点顺序和三角形扇形拆分均不变。
- 控制曲线和流线仍由原代码生成并由 Qt 编码。格式没有升级，读取端和缓存协议不用改。

没有减少点数、降低精度，也没有改动细分、法线、流线、填色和导出算法。
这一步减少的是完整结果生成中的重复编码，不能称为细分网格的局部更新。

真实非空流线、四档精度及法线、实际船模法线和空模型。输入和旧程序指纹保存在报告里。
参照程序与新程序相同则标记未测，不会拿当前实现自动更新期望。

这是本机后台任务时间，不是整个窗口出现时间，也不是所有船模的性能保证。
