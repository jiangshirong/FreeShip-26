## 本次改动

- 计算工具目录解析共用一个入口：手动选择根目录/Exec、应用旁相对配置、便携目录发现。
  阻力窗口补回原来被隐藏的工具目录入口；偏好设置和计算窗口共用保存位置。
- “检查工具”显示 21 个计算程序及 hship 数据依赖的完整性。可选数据库查看器单独列出。
  正式计算检查并记录所用 EXE、配置、数据库的文件指纹，写入 JSON/TXT/PDF。
- hship 的数据库目录在私有副本中设为 `BD\`，原文件不动。返回的方法编号要与请求一致；
  自动选择（输入为 0）仍允许工具决定具体方法。不能把不同方法的完整形状输出混用。
- 加速/制动读取原生阻力缓存，以及提取推进参数时，会检查对应原生元数据与文本投影的
  SHA-256，避免被改写的文件继续流入计算。已有模型版本隔离和失败失效机制继续保留。
- 加速曲线的海里/节换算使用 1852 m、3600 s 的精确定义，不再用 0.514444 或把转换值
  再压回单精度；原始 RVRSSHIP 数值、输入协议及其他方法精度没有调整。

## 历史 review 的处理

统一回归会读取已保留交付报告，核验报告指纹，生成 `historical-review-ledger.json`。
旧报告保持原状；历史通过不冒充本版新执行，未识别的新 review 会使该台账检查失败。

| 差异 | 结论和处置 |
|---|---|
| 静水力采样轮廓、半剖面与面元积分的差别 | 已有独立面元/体积矩与收敛检查支持原生修正；不恢复旧误差来追求字节相等。详见 SYMMETRIC-HYDROSTATICS 等记录。 |
| 扭曲多边形裁剪与先固定三角剖分的差别 | 已在几何方向保留两种结果及独立积分；沿用修正。 |
| CALCPROP 的 0.5144/0.51444、1.945 近似换算 | 保留原始结果与严格 SI 区间检查；报告新增近似口径说明，不提高容差或比例修正。 |
| 旧适配器拒绝固定 165 数字协议 | 属于旧对照器限制；实际 CALCPROP 完整输出和独立矩阵/曲线预期已有覆盖。 |
| 原生 B 系列常量船体系数与 CALCPROP 随滑失经验模型 | 属于不同数学模型，不能要求相等。内置模型有独立公式验证，旧方法仍可选择。 |
| 船型 13 的 0.91 / 0.091 | 仍缺可靠资料判定哪个经验系数正确。保留原执行值；窗口报告及结构化结果列明未独立核定。 |
| 主机惯性矩 t·m² / kg·m² | 仍缺内部求解器口径。保留原值，不进行没有依据的 1000 倍换算；报告及结构化结果列明限制。 |
| 桌面、视觉、实船/水池验证 | 独立验收范围，未执行就不算通过。 |

最后两项数值资料缺口没有被宣称解决，也不再作为必须反编译或改写 EXE 的理由。
本方向的交付标准是：已知缺陷修复、可复现测试、工具可配置、限制可见且结果可追溯。
不能把这解释成所有外部经验算法已获得独立工程认证。

## 验证方式

- 新测试从原工具包复制一套到含中文和空格的独立目录，故意写入错误的原数据库路径，
  再实际运行 hship 三个入口、CALCPROP 三个任务、Ishercof、ManeuvPP、RVRSSHIP。
- 对外部结果核对程序/数据文件指纹，检查原目录未改变；注入缺表、错误方法编号和损坏
  缓存，确认拒绝发布；内置 Fung 及 B 系列仍在缺工具时完成计算。
- 配置探针检查相对路径不依赖工作目录、便携目录发现、设置持久化和其他偏好保留。
- 生产窗口通过真实动作回调执行工具检查及计算，复核报告和模型/型线图/DXF 不变。
- 复用 CALCPROP、Hydrodyn、AddMass 的完整协议、故障、取消及独立算术检查；
  发布前在实际 `dist` 上复验。结果与文件指纹见本轮交付收据。

使用说明见 [配置外部计算程序](../CALCULATION-TOOLS.md)。
