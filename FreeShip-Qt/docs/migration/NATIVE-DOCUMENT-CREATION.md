# 打开、新建、导入和 FBM 版本转换

2026-11-03。原有 Qt 窗口和菜单继续使用；这轮替换它们背后的文档构造。

## 已接入的路径

- **打开 FBM**：C++ 校验文件、建立可编辑状态和实体 ID。未编辑保存仍输出原文件
  字节，包括预览图片和未知扩展尾部；含未知尾部的文件仍禁止编辑。
- **新建船型**：原来的 7×5 船型模板、横纵样条采样、控制面朝向、船艏折角处理，
  以及默认剖面生成均在 C++。支持原来的 2–100 行列范围和米/英尺设置。
- **导入模型**：现有 OBJ/STL/FEF 解码后的控制网由 C++ 构造。保留独立近邻点、
  顶点类型、内边折痕、非对称图层和材料属性。缺边、重复边、非法索引、非流形
  连接及超出细分预算的输入整笔拒绝。
- **旧格式升级**：新增字段只升级到它需要的最小版本，和编辑一起提交、撤销。
  无关块保留原字节；新增字段使用原程序默认值。早期交线缓存的坐标布局变化时
  清除派生缓存，再按原精度生成，不把旧缓存当作新布局解释。

对应代码：`src/document/document_format.cpp`、`document_create.cpp`，由
`document_service.cpp` 接入；新建控制网复用 `topology_edit.cpp`。格式支持 FBM
版本序号 0–44，默认新文件仍使用当前 Plus 的序号 43，没有擅自切换格式。

旧分析端不能完整读取序号 0–6 的工程设置。现在只把传给它的副本补齐到序号 7；
用户文件和未编辑保存结果仍保留原版本。模型构造和发布都成功后才替换当前文档，
失败时保留原文档、历史、保存点及稳定 ID。

## 验证方式

`FreeShip-Tests/qt_native_create.py` 已接入统一 `qt-document` 套件。
`qt/document_create_probe.cpp` 直接链接 C++，不启动旧核心；独立 Python 编码和读取
夹具检查全部 45 个版本的原样、逐版和跨版转换，并检查预览、背景、标记、计算
参数、名称和引用字段。另覆盖 100×100 新建网格及一百万三角形预算拒绝。

常驻服务同时调用 C++ 与旧版独立路径，精确对比三个模型、米制/英制/最小网格
新建、双材料导入、改点及撤销重做。对照包括控制网、曲面、完整 FSLP、DXF、
剖面结果以及新建文件的非派生字段。没有增加数值容差。

新建文件的首轮二进制对照发现计算参数记录末尾填充不同：旧写入器用 `$FF`，
初版 C++ 用零。这些不是参数值，但已按旧格式补齐，失败报告仍保留。
完整回归又查出加载后的图层分配计数不同：旧版先分配再读入层 ID，计数可能大于
文件中的最大 ID。已保留这条规则，避免随后新建图层的默认名称相差一位。
`qt-exchange` 的服务检查也改为正式文档服务，Qt 导入窗口继续走实际回调。

完整回归与安装证据记入 `FreeShip-Tests/maintenance/create-installed-20261103.json`。
报告、构建和私有运行目录在 `C:/FreeShip26Tests`；测试源码保留在项目中。

## 仍有的旧核心依赖

旧核心仍接收 C++ 生成的 FBM 副本，建立用于分析的对象，并提供系统颜色、编码和
用户偏好。它不再负责正式路径的新建、导入或版本转换；旧实现仅供独立对照。
这不等于完全去除了旧加载器，也不宣称整个打开过程已经没有重复重建。

流线追踪、专业计算设置、静水力/稳性、阻力/推进、板材展开和 IGES 曲面准备仍
待迁移。当前验证使用私有进程和隐藏 Qt 回调，没有替代真实桌面的视觉、鼠标和
焦点验收。完整软件迁移尚未完成。
