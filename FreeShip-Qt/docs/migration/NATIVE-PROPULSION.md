# C++ 螺旋桨与推进流程

2026-11-03。本轮接管五个推进计算入口的参数装载、输入文件、求解器运行、
结果解析、后处理、曲线和结果衔接。现有 Qt 窗口及报告导出继续使用。
这五项不再借用 Lazarus 窗体做计算；外部求解器仍是原有程序，没有被重写。

## 实现

入口在 `src/document/document_service.cpp`，具体实现是
`src/document/propulsion.cpp`、`propulsion_reports.inc` 和 `propulsion_tables.h`。
返回值标记 `analysis_engine=cpp-propulsion`。旧适配器收到正式文档的这五类
请求会拒绝执行；仅独立对照允许调用旧流程。

| 入口 | 本轮迁移的内容 |
|---|---|
| Task1，设计与主机功率 | 参数、CALCPROP 输入/输出、四条曲线和报告插值 |
| Task2，主机匹配 | 五个阻力工况、最多 20 次迭代、八种材料强度表、匹配结果发布 |
| Task3，推进特性图 | 阻力/匹配参数提取、五乘五工况矩阵、主机与总推力曲线 |
| Task4，初步设计 | PropPred 输入、输出核验、附加功率计算与敞水曲线 |
| Task5，敞水计算 | 系列联动、FPPCALC/PROPOL 协议、曲线与工作点报告 |

FBM 中的值是参数来源，静态字段表只描述控件、标签和范围。先处理系列选择，
再应用数值；计算仍按原 Single 精度处理，参数框保留其原有小数值。公制限制不变。

每次计算使用独立临时目录，不再更改整个进程的工作目录，也不靠固定等待猜测
求解器是否结束。检查退出码、文件长度、数字列数及有限值；缺结果时明确报错。
取消会终止运行中的求解器，Windows 进程组在计算服务退出时清理所属进程。

阻力到推进、匹配到特性图的缓存仍限定在同一文档、同一版本。完整结果写入新一代
目录后才切换索引；模型修改后不再读取旧版本数据。诊断文件有数量和大小限制。

## 没有照搬的错误

- `FreePropeller_Task1Dlg.pas::CalculateInWorkspace` 的四点插值区间循环会访问
  第五个元素。新版只遍历三个相邻区间。
- `FreePropeller_Task3Dlg.pas::CalculateInWorkspace` 把展开面积比 `Ae_Ao` 再次赋成
  轴系效率 `Dat14`。B 系列 1–3 现在使用实际输入的面积比；有固定面积比的图谱保持原值。
- `FreePropeller_Task2Dlg.pas::CalculateInWorkspace` 的强度结论只引用循环最后一种
  材料；非均匀流条件写成 `SigmaB > 0.25`，与表中的 `SigmaB/4 > 1` 不一致。
  新版按八种材料分别判断 `SigmaB > 1` 和 `SigmaB > 4`，不改应力公式。
- 旧桥接没有初始化编号报告标签，部分行只剩数值。新版从原资源生成标签，并修正
  初步设计报告空行造成的标签错位。Task1–3 的输入说明采用统一的参数名和值。

这些是流程、赋值、边界和报告问题的修正，不代表原经验公式已获得新的工程认证。

## 证据和限制

统一测试入口为 `FreeShip-Tests/run_tests.py --suite qt-performance`。
`qt_native_propulsion.py` 已接入此套件，覆盖三个模型的默认值、保存/撤销、实际
求解器文件与曲线、全部 11 类 FPPCALC 系列、取消、坏输出、缓存失效，以及关闭
旧适配器后仍可执行的原生入口。完整 Qt 回调继续检查计算前后的型线图和 DXF。

初步设计和 11 类敞水计算使用真实旧求解器，与原流程比较输入/输出文件及完整曲线；
敞水报告逐字对照，初步设计修复了标签，因此另外比较附加计算数字。

**CALCPROP 的现存二进制仍不能输出 Task1–3 结果。** 已在独立目录直接运行确认；
这三项的真实求解仍记 `not_run`。固定数值协议样本仅用于测试读写、后处理、插值、
曲线与失败路径，不能当成真实船舶计算成功。样本源码是
`FreeShip-Tests/qt/propulsion_solver_fixture.cpp`，不会装进正式程序。
旧 Task3 后处理对该完整协议样本报 `Invalid input`，单独记 `review`；新版用矩阵
坐标和独立直线关系核对，未把对照失败隐藏成通过。

PROPOL 的 DOS 程序仍不能直接在当前 64 位 Windows 运行。求解器目录通过配置引用，
本次安装包不附带这些二进制，也不改变其许可条件。

隐藏 Qt 回调证明程序路径接通，不代替真实桌面验收。测试源码、生成脚本、冻结字段
样本和来源哈希均保留；报告和临时运行包放在 `C:/FreeShip26Tests`。
安装后的核验凭据为 `FreeShip-Tests/maintenance/propulsion-native-installed-20261103.json`。

后续十种阻力方法已接入，见 [原生阻力流程](NATIVE-RESISTANCE.md)。板材展开、IGES 曲面准备、旧分析对象装载、
部分内部标注及尚未接入的外围功能仍需继续迁移。
