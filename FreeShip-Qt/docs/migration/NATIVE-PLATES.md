# C++ 板材展开

2026-11-03。计算 → 板材展开现在直接使用 C++ 文档和细分曲面。原有 Qt
窗口、板片摆放、显示选项、DXF/TXT/JSON/PDF 和打印预览继续使用同一份展开结果。

入口在 `src/document/plates.cpp`，文档服务返回 `analysis_engine=cpp-plates`。
输入是当前版本的只读 FBM；成功后原子发布 `plates.json`。计算、取消和输出失败
都不修改工程、保存点或撤销历史。旧适配器拒绝正式文档的展开请求，只保留独立
对照入口。编码、界面用词和颜色仍在打开工程时读取一次应用环境，不参与展开计算。

## 算法和边界

依据当前 Plus 的 `FreeSubdivisionLayer.Unroll`、`FreeDevelopedPatch.Unroll`
及 `IntersectPlane` 移植，保留原作者署名和 GPL-2.0-or-later。没有使用 ShipCAD
的展开实现。

保留三角形边长展开、角点候选起点、方向异常候选、最小归一化误差选择，以及
0.5° 包围框旋转搜索。精度档位、细分层数、完整边界、曲线采样和量纲不变。
坐标继续使用 Single，面积和候选评分使用 Win64 FPC 对应的 Double。

顶点、边和面使用固定索引，邻接关系建立一次。每个候选只遍历自己的面，
保留最优结果，不再通过指针排序、反复查找和删除列表来推进展开，也不用重算
一次最优候选。断开区域单独展开。索引由控制网和细分顺序决定，不取决于内存地址。
因此不承诺板片内部编号、整体旋转和平移或导出文件字节与旧版相同；比较的是
几何形状、误差、边界、单位和实际输出比例。

已有两处修复继续保留：中线展开后弯曲时，不把左右舷错误合为一块；剖面与
整张面共面时不生成假轮廓，与边共面时每条边只计一次。剖线使用原生样条和
既有连接阈值。没有为提高速度删点或降低分辨率。

计算定期检查取消文件，90 秒超时会给出错误。数值异常不发布结果。
Qt 会话也记录取消状态：即使后台已经生成结果，只要界面仍在等待时按下取消，
就不再接入这个迟到结果，保留原板片布局。测试特意等待后台文件生成后再取消。
双曲率表面仍显示面积和边长误差；程序给出展开近似，不把它标成无失真的可展面。

## 测试

统一入口 `FreeShip-Tests/run_tests.py --suite qt-plates` 包含
`qt_plates.py`、`qt_native_plates.py` 和保留的 Pascal 样本观察器。

- 平面、斜板、圆柱、双曲率、孔洞、断开板片、英制、左右舷和弯曲中线。
- 四档细分精度，旧版误差及形状对照，独立边长/三角形面积核算。
- 多次计算和换文件后重开、点编辑、撤销重做、FBM 与型线图只读检查。
- 私有 Pascal 进程终止后的计算、旧入口防回退、运行中取消、写入失败和重试。
- 历史 FBM 版本及工程颜色/水线基准。
- 没有保存图层名称时，沿用旧版按图层编号生成的默认名称。
- 实际 Qt 回调和 DXF 全边界、独立文件读取、TXT、JSON、PDF 比例和分页。

最新报告和本机安装指纹见 `FreeShip-Tests/maintenance/plates-native-installed-20261103.json`。
时间记录区分计算本身和完整服务请求；单次样本计时不代表整窗打开耗时或所有船型。
隐藏 Qt 回调没有覆盖真实桌面操作、实体打印机和加工系统验收。
