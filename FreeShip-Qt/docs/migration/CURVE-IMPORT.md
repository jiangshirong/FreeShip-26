# 折线与型值曲线建模导入

2026-11-04。本轮一起接入 Hull、Carene、折角线文本、曲线拟合曲面四个入口。
从文件读取、曲线采样、拟合建网，到 Qt 参数窗口、编辑、撤销和 FBM 保存重开，
均走 C++。原始曲线作为标记保留，便于与生成的船体核对。

## 使用范围

入口位于“文件 → 导入模型”。参数窗口沿用现有 StudioLight 样式。

| 输入 | 读取内容 | 生成结果 |
|---|---|---|
| Hull `.hul` | 固定的 5/13 肋位表、8 个站位、船名及设计者；选择是否使用中间肋位 | 英制半船，保留折角控制曲线、板带分层、站位和原始曲线标记 |
| Carene `.xyz` | 首行前 18 个字符为船名；LINE 段落后跳过一条标题，再读 X/Y/Z | 半船折角模型；单位由用户选择，默认每条线拟合 8 个点 |
| 折角线 `.txt` | 首行为 0（米）或 1（英尺），每行 X/Y/Z，空行分隔，可用 EOF 结束 | 半船折角模型，可选每条线的拟合点数 |
| 曲线拟合曲面 `.txt` | 同上文本语法，曲线按横向排列、方向一致 | 双向拟合平滑控制网，可选行列数及镜像 |

折角模型的输入须位于 Y≥0 一侧，按龙骨至舷缘排列，各线从艏到艉、方向一致。
各板带分别分层，纵向折角线保留折痕，板带内部保持平滑。艏艉和船底补到中心线，
甲板开放。板带的“可展开”标志沿用旧入口，这个属性不等于已证明能无误差展开。

Hull 的坐标顺序为 Y/Z/X，原单位为英寸。新实现统一除以 12 转为英尺，
保留旧入口最终的英制工程和淡水密度默认值；站位采用相同换算及纵向原点。
其余文本依据文件单位或明确的 Carene 单位选择，英尺保留英制，其他单位转成米。
HUL 的帆装记录继续跳过，不据此生成帆装模型。

这些入口生成的是拟合控制网。采样数、原曲线走向和中心线限制都会影响结果，
不能作为任意外部曲面的无损交换。沿用旧版的中心线限制：采样点 Y≥0 而拟合
控制点 Y<0 时，将其收回到 Y=0；原始标记保持不变。所有输入保留 UTF-8 解析，
工程文字还须能用偏好中的 FBM 编码保存，无法表示时明确失败。

文件未给出设计吃水，新工程先设为 0，主尺度确认标志保持未设置。
进行静水力计算前，应在工程设置中填写实际吃水，而不是沿用一个假定的 1。

## 旧流程中的问题及处理

以下位置相对 `FreeShip-Plus-Lazarus`，旧工程未修改。

- `Units/FreeEdit.inc::File_ImportHull`：点坐标使用 `0.0254`，站位却使用 `0.024`。
  新入口对坐标和站位使用同一英寸换算。旧版最终的 `ProjectUnits := fuImperial`
  会调用 `FreeProjectSettings.FSetProjectUnits` 换算整个模型，并非只改标签；
  新实现直接生成英尺数据，省掉先转米、再转英尺的重复处理。
- `File_ImportCarene/Chines/Hull` 在完成读取前清空当前模型；Chines 捕获错误后
  仍可能调用建网。新流程拒绝不完整输入，只提交完整构建成功的候选文档。
- `File_ImportChines/Surface` 遇到错误单位仅提示后继续，部分短曲线被丢弃。
  新解析器要求合法单位、每条至少两个不同点、有限坐标和完整记录，拒绝静默跳过。
- `Units/FreeShip.inc::ImportChines` 与 `File_ImportSurface` 先建立完整矩阵再求逆。
  这个矩阵实际只有三条非零对角线。新实现直接解方程，耗时及存储随拟合点数线性增长，
  中间使用 double，最终控制坐标仍按原 FBM 的 Single 精度存储。
- 逐面创建控制网时，新边先被当作边界折痕，后续拼接缺少完整重算。
  新实现先建立全部面，再统一确定边界、纵向折角线及艉端折痕，避免内部网格边留下硬折。

拟合方程保持端点固定，内部使用 `(C[i-1]+4*C[i]+C[i+1])/6=S[i]`。
改变求解方法会改变旧版矩阵求逆的舍入误差，不承诺新旧控制点逐位相同。
测试使用独立的 60 位十进制稠密消元预期，并核对最终 Single 坐标；
没有通过降低采样数或放宽已有场景/DXF 对照标准来换取通过。
