# FreeShip 水静力附件诊断

运行：`python basehull_diagnostic.py --model "模型绝对路径.fbm"`。

脚本在隔离的源码副本中构建并调用实际计算和单次水静力报告生成，先使用原模型，再将两个端点均处于 x=0（容差 1e-6 m）的控制边设为折线。输出位于新建的 reports/basehull-* 目录，包括模型、源码和程序哈希、计算结果与异常。原模型不写入。

这是面向该历史案例的诊断：不是原始 3.30+ 程序、桌面菜单交互或物理正确性验证，也不证明设置折线后几何保持不变。改动折线会改变模型；输出值不可视为参考真值。构建时仅在隔离副本去除图标资源以避免重复资源，直接在应用初始化后执行探针。
