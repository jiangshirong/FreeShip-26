## 如何运行

```powershell
python -B run_tests.py --suite historical --suite historical-assets --output reports/history-new
python -B historical_regression.py --run-reviewed --probe smooth_batch_test --output reports/smooth-new
```

每次输出目录必须不存在。--probe 可重复，--model 指定模型的私有副本；没有 --run-reviewed 时只核对清单并给运行项标 not_run。运行期间原源码、测试依赖和原模型变化均使结果成为 error。没有执行桌面输入、Show 或安装替换。

## 结果口径

assertion 检查缓存次数、像素一致性、缩放边界和明确状态行为。observation 保留旧布局/动画参数及性能场景，始终为 review；historical_expectation_met 及 exit_code 表明原预期是否满足。正常退出也不代表视觉或性能合格；编译错误、异常退出不会算通过。原本的数值阈值未改成迎合当前输出。

## 替代范围

“由现有入口承担”不声称每条旧断言逐字等价。旧菜单位置、按钮数量、固定署名行列和全部文字矩形不得相交不再是默认判定规则；现有库存、逐点身份和绘制证据供复核。关于页旧折叠结构已更换，新的 historical_ui_probe.pas 记录四种语言的实际表格与 Esc 回调，另外检查标题栏关闭与原关闭动作的设置接受结果一致。

historical_assets.py 按现有资源文件及尺寸目录枚举并解码，不写死图标数；内嵌图标另由 historical_icons_probe.pas 枚举实际资源，检查声明尺寸及 35px 请求的最近尺寸回退；不锁定图标数，也不证明视觉效果。三个图标生成/报告脚本及盘点工具仍为历史辅助工具，不会在测试时写产品资源。

## 不覆盖的事项

未验证真实焦点、窗口摆放、物理鼠标或屏幕合成。数值/像素断言只针对报告所用模型及样本。观察场景失败不自动等于产品缺陷，必须结合记录中的原预期确认；确定性回归失败仍保留 fail。
