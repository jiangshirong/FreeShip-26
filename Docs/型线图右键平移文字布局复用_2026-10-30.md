# 右键平移：复用内部文字布局

## 实际开销

前一轮改善了填色和折角线绘制，但右键平移仍逐帧重新搜索文字位置。分段计时显示，9a 模型在 1920×1140 画布上的文字收尾阶段中位耗时约 13.26 ms，预览复制约 0.74 ms。继续优化填色复制解决不了主要开销。

## 改动

`Forms/FreeLinesplanFrme.pas` 在右键拖动已激活、缩放和场景参数未变时，允许内部文字复用已有布局。上下文包含模型绘制缓存、字体大小、填色和单色模式；模型缓存失效时同时取消这个资格。记录比例使用 Double，避免单精度存储舍入导致非整数缩放时资格判断失效。

`Units/FreeLabelLayout.pas` 增加默认关闭的 `TranslationOnly` 入口。复用要求上一帧连续可见、文字和尺寸不变、位置随当前整数位移移动、裁切框完整且离窗口边缘足够远。仍先检查本帧已占用的文字矩形，有新障碍就退出复用。边缘、缩放、内容变化及打印、导出不使用该路径。四个主视图默认仍走原来的布局规则。

这次保留的是文字的位置和避让结果，文字每帧仍按原字号绘制。没有把文字截图拉伸，也没有减少曲线采样或船体细分。

## 验证

可复用检查已并入同级 FreeShip-Tests 的 `--case linesplan`，新增分段高精度计时、复用数量观测、六项独立布局规则和拖动中字号/比例/样式变化检查。

报告位于同级 FreeShip-Tests/reports：

- `linesplan-pan-phases4-20261030`：本轮改动前的分段基线。
- `linesplan-pan-reuse-witness2-20261030`：91 pass、0 fail、1 not_run；每个平移帧复用 104～108 个内部标注，滚轮复用数量均为零。停止后的图像、位图和 DXF 对照通过。
- `linesplan-pan-reuse-final-20261030`：三个船型共 282 pass、0 fail、1 not_run。填色覆盖、内部文字连续性、强制精绘、历史输出对照均通过。
- `linesplan-pan-reuse-long-20261030`：连续 96 步、真实时钟和消息泵，70 pass、0 fail、1 not_run。
- `linesplan-pan-reuse-fractional-20261030`：初始比例 1.25、连续 96 步，70 pass、0 fail、1 not_run，确认非整数比例下仍实际使用复用。
- `labels-pan-reuse-20261030`：254 pass、45 review、348 not_run；相关离屏图片已检查，不算原生桌面验收。

1920×1140、9a 模型的观测：

| 场景 | 每步中位耗时 |
|---|---:|
| 改动前，12 步平移 | 21.70 ms |
| 新版，12 步平移 | 11.90 ms |
| 新版，96 步平移 | 11.41 ms |
| 新版，比例 1.25 下 96 步平移 | 18.13 ms |

文字阶段从约 13.26 ms 降到约 6.36 ms。以上是离屏输入和栅格绘制耗时，受机器负载、可见内容和比例影响，不是显示器 FPS，也不保证所有比例恒定 60 帧。原生窗口、输入时延和用户体验仍需实际复核。
