# 源点扩散动画性能优化

2026-10-29。本轮保留原来的源点、连接顺序、1.3秒时长和抗锯齿效果。

修改：同样式的相邻线段共用GDI+绘图上下文与画笔；保持原绘制顺序，不全局按颜色重排。收集缓冲区改为保留容量，逐帧复用；边方向和长度在拓扑构建时预先计算，逐帧只做插值。

固定离屏样本：1000×600画布，32条交叉红蓝长线，60帧，Windows高精度计时，含每帧清屏、线段收集与扩散绘制。不是完整FreeShip_26四视图帧率或真实鼠标延迟。
