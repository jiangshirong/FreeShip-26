# 第一批修复：文件安全

2026-10-30。本批先解决保存、打开失败时丢失当前工作的风险，不调整船型计算方法和精度。

## 改了什么

- **01 保存失败**：完整内容先写同目录临时文件，刷新并关闭后再替换正式文件。`.Bak` 保留原正式文件。失败不会清除修改标志；另存为失败仍保留原文件名和状态。
- **02 打开失败**：新文件先在候选模型中解析、重建；通过后才交接。失败保留原模型对象、选中项、文件信息和撤销/重做。文件对话框和最近文件入口都不再提前清理模型。
- **03 读写停滞**：短读写继续，零进度和异常返回立即退出；文件句柄保证关闭。失败读取不公开半个缓冲区。
- **09 加载状态**：修正同名变量遮蔽，正常及异常退出都恢复原状态。成功交接保留原界面监听器，清掉点编辑器的旧对象引用。
- **04 部分完成**：补 JPEG、字符串、固定记录、部分集合数量和活动图层索引检查。面、边、曲线及底层列表的索引防护还没做完。

主要代码：`Units/FreeSafeFile.pas`、`FreeFileBuffer.pas`、`FreeEdit.inc`、`FreeShip.inc`、`FreeSubdivisionSurface.inc`，以及 `FreeShipUnit.pas`、`FreeGeometry.pas` 的声明和 `Forms/Main.pas` 的打开入口。原上游位置仍保留在各条记录中。这批是本地修改，尚未创建 Git 提交。

失败前后要求原对象和序列化字节保持不变，并实际执行撤销/重做。正常重新加载时，原生保存器会按内存地址重排控点，因此文件字节不一定相同；测试另用控点名称对照浮点位、边连接、面循环、层和曲线，检查项目设置及交线等记录。

测试过程中发现新增的整记录边界检查误用于文本格式，已经修正并补上非零文本记录回归。这是本次修改带来的问题，不记为上游缺陷。过程中的失败报告保留，最终依据是上表所列报告。

入口和复跑方式见 [FreeShip-Tests 说明](../../../FreeShip-Tests/README.md)。原有 17 条总回归入口的保存、加载及读写注入已适配；本批未重新运行全部 17 条，其他问题状态不据此改变。
