# STL 导出忽略图层对称设置

状态：已修复，验证范围见下文及第二批总记录。优先级：P1。

以下问题描述为修复前核对，修改进展见文末。

STL 导出每写出一个三角面，紧接着就把三个点的 Y 坐标取反，再写出镜像面。这里没有检查图层的 `Symmetric` 设置。对称半船需要镜像，单侧附件、非对称船体或已经建好的完整模型却不应一律再镜像一次。

应按图层设置决定是否补镜像，并检查对称面上的三角形，避免重复输出。验证时分别使用对称半船、非对称单侧部件和完整模型，比较导出前后的几何范围与三角面数量。

代码位置：`Units/FreeEdit.inc`，`TFreeEdit.File_ExportSTL`。见[上游三角面写出与无条件镜像](https://github.com/markmal/freeship-plus-in-lazarus/blob/1de17e99fb2b1cc559cdf27c5cafb595a627a641/Units/FreeEdit.inc#L4258-L4273)。当前源码同一函数仍有该流程。

这是核对社区导出反馈时另外查到的代码问题。社区 [#59](https://github.com/markmal/freeship-plus-in-lazarus/issues/59) 讨论的是 IGES 对称导出，作者已经回复修复；本条记录的是不同的 STL 路径。已核对源码，尚未做桌面导出复现。

## 第二批修复（2026-10-30）

`FreeEdit.inc/TFreeEdit.File_ExportSTL` 仅在所属图层设置 `Symmetric=True` 时补镜像。三个顶点都在 `Y=0` 的中心面只输出一次；镜像面继续反转顶点顺序，保持法向。可见图层、原有三角划分和输出小数位不变。

入口：`python -B FreeShip-Tests/stl_symmetry.py`。实际导出对称/非对称半船、中心面、完整双侧模型、负半船、接近中心面的几何，以及带非对称附件和隐藏层的混合模型。核对三角面坐标集合、法向与顶点朝向、重复面和隐藏层排除，不能只凭面数判断正确。

文件选择由隔离适配器提供，未做桌面导出验收。最终源码及报告由第二批总记录统一归档。

最终验证、剩余范围与程序更新见[第二批修复记录](第二批修复-计算与异常处理.md)。
