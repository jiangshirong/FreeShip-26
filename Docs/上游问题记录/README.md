# 上游问题记录

这里记录本项目在上游代码中发现的问题、社区反馈的核对结果，以及后续的修复情况。每条记录保留原代码位置，方便复查改动的原因。

核对的上游是 [FREE!ship Plus in Lazarus](https://github.com/markmal/freeship-plus-in-lazarus)，版本为 [`1de17e99fb2b1cc559cdf27c5cafb595a627a641`](https://github.com/markmal/freeship-plus-in-lazarus/tree/1de17e99fb2b1cc559cdf27c5cafb595a627a641)（提交日期 2026-02-09，按提交者时区）。记录日期为 2026-10-29。

先看[具体问题](#具体问题)，再看[优化方向](优化方向.md)。需要追溯论坛或 Issue 时，查[175 个来源的逐项核对表](资料逐项核对表.md)；此前的作者回应和本地检查见[社区反馈核对](社区反馈核对.md)。

代码问题已对照固定上游提交和本地当前实现。下表 01–17 均有代码修复和专项测试依据。MCP 适配器新增逻辑、本地界面改动不归为上游缺陷，也不推断上游后续版本仍有同样的问题。

截至 2026-10-30，三批已处理 17 条代码问题。最后两条补上了外部计算的独立工作目录、结果校验，以及随附旧 FBM 的计算参数布局迁移。这里的“已修复”限于各条列明的代码和测试范围，不等于全部桌面验收，也不包括下方 O01–O14 的功能优化。详见[第一批：文件安全](第一批修复-文件安全.md)、[第二批：计算与异常处理](第二批修复-计算与异常处理.md)、[第三批：外部计算与旧文件](第三批修复-外部计算与旧文件.md)。

## 记录口径

P1 先处理文件安全、计算正确性和异常恢复；P2 随后处理。这里的优先级是本项目的修复顺序，不是安全漏洞评级。

初次记录主要基于源码核对；三批修复增加了隔离编译、故障注入、数值与导出对照。第二批报告保留当时的 37 个旧文件加载失败；第三批这些样本均可读取。最新整批结果为 1403 pass、3 review、3 not_run，没有 fail 或 error，总状态仍为 partial。三个 review 是数值搜索的全局保证及两个背景 JPEG 重存差异；三个 not_run 是桌面交互或显示验收。记录风险也不等于所有正常模型都会出问题。

本次读入资料文件夹的四份文件，核对 175 个来源。已修复或已实现的 63 个来源不进入当前缺陷清单；操作问题、环境问题和历史资料另留简短去向。IGES 参数范围、板材 TXT 导出、打印、大模型加载等旧修复不算本项目成果。长论坛目录不等于已经逐帖穷尽。

修复时在对应文档补上做了什么、提交编号、验证方法和结果，再更新上表。只有实际修复并有验证依据，才标为“已修复”；原问题和上游链接保留。上游链接固定到原始提交，当前代码可按文件路径和函数名查找。
