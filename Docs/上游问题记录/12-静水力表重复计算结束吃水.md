# 静水力表重复计算结束吃水

状态：已修复，验证范围见下文及第二批总记录。优先级：P2。

以下为修复前核对。

吃水循环允许走到 `EndDraft + DraftStep`，超出结束值后又把实际计算吃水设回 `EndDraft`。当起点为 1、终点为 2、步长为 0.5，且计算没有提前退出时，实际序列是 `1、1.5、2、2`，结束吃水会多算一次。计算结果满足写表条件时，也会出现重复行。

应先生成明确、去重且有数量上限的吃水列表，再按索引计算。终点是否包含要统一处理，避免靠浮点数反复累加决定结束位置。

代码位置：`Forms/FreeHydrostaticsFrm.pas`，`TFreeHydrostaticsForm.Button2Click`。见[循环条件与终点回填](https://github.com/markmal/freeship-plus-in-lazarus/blob/1de17e99fb2b1cc559cdf27c5cafb595a627a641/Forms/FreeHydrostaticsFrm.pas#L277-L288)。

上述序列已按当前循环逻辑独立核算，未运行桌面表格。修复时检查终点恰好落在步长网格上、落在网格外，以及很小步长的情况。

## 第二批修复（2026-10-30）

`BuildHydrostaticDraftSequence` 先生成吃水序列，再交给真实计算按钮逐项计算。终点只保留一次，按索引计算中间值；浮点数舍入后不能前进的步长会报错。拒绝非有限数、倒置区间和非正步长，最多 10000 个吃水值，避免输入错误形成长循环。

`hydro_corrections.py` 覆盖整除/非整除区间、相同起终点、0.1 到 0.3、小步长和数量边界，也调用实际 `Button2Click`，核对进入计算器的吃水而非只检查辅助函数。没有操作真实桌面表格。最终结果见[第二批修复记录](第二批修复-计算与异常处理.md)。
