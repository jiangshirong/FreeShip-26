# 历年讨论资料逐项核对

核对日期：2026-10-29。来源为项目根目录的 `旧版FreeShip网上讨论资料`。175 个来源全部保留编号与去向；重复内容合并到问题记录或优化方向，已修复的问题只留排除理由。这里不是新增 175 个问题。

CSV、HTML 内嵌数据与 Excel 的 175 个编号一致，Markdown 也包含全部原网址；Excel 的“开发方向”和 Markdown 末尾的八项建议已合并到 O01–O14。四份文件是同一批整理资料，不能算四组独立证据。

本次通读本地摘要并对照源码，重点反馈结合此前取得的 Issue/评论、发行说明和可访问原帖核对。未逐页读尽长论坛和目录下全部帖子，也未运行每个原帖样例。失效页面、摘要线索及缺少样例的情况均保留限制。

代码依据：[上游固定提交 `1de17e99`](https://github.com/markmal/freeship-plus-in-lazarus/tree/1de17e99fb2b1cc559cdf27c5cafb595a627a641)，并核查本地当前实现。上游已修和本地已有改进均不作为新修复成果。本次只更新记录，未修改程序源码。

“保留改进”包含功能完善，不等于已确认缺陷；“待验证”只保留线索；“已修复/已实现”来自对应源码或作者、报告者的后续记录，不代表本次已在所有平台验收。关联的 O 编号可能只是后续回归需求。
