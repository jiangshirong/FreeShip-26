# 剖面定位依赖坐标原点

状态：已修复，验证范围见下文及第二批总记录。优先级：P1。

以下为修复前核对。

`CalculateMidshipLocation` 把默认位置设为 `0.5 * ModelMax.X`，没有计入 `ModelMin.X`。没有辅助横剖线时，后续搜索不会修正它。假设船体位于 `x=100～120`，默认位置就会取到船体之外的 `60`，后续剖面积、Cm 和 Cp 有误算风险。

这里还需要明确计算的是设计中剖面还是最大剖面。前者应有明确位置，后者应在船体范围内搜索，不能依赖用户是否添加了显示用横剖线。只改成包围盒中点，并不等于找到了最大剖面。

代码位置：`Units/FreeHydrostaticCalc.inc`，[`TFreeHydrostaticCalc.CalculateMidshipLocation`](https://github.com/markmal/freeship-plus-in-lazarus/blob/1de17e99fb2b1cc559cdf27c5cafb595a627a641/Units/FreeHydrostaticCalc.inc#L1318-L1393)。

已核对源码；上例是公式推演，未跑桌面算例。修复时比较同一船型平移前后，以及增删辅助横剖线前后的剖面积和形状系数。

## 第二批修复（2026-10-30）

`CalculateMidshipLocation` 明确寻找当前水线下的最大横剖面积。搜索范围取参与水静力计算的船体范围，默认位置计入最小 X；不再依赖用于显示的站线。先采样，再在局部峰值附近细化，最终仍调用原剖面求交和面积积分，没有替换成简化几何。

`hydro_corrections.py` 检查同一船体平移、增删站线、负坐标、窄峰及 `CalculateVolume` 入口，并比较面积、Cm、Cp。另用真实细分曲面和课程 9a 模型做较密扫描及耗时对照。有限采样没有证明任意船型的全局最优；病态、多峰模型仍须独立工程校核，报告中保留这条限制。

最终源码、计时与测试结果见[第二批修复记录](第二批修复-计算与异常处理.md)。
