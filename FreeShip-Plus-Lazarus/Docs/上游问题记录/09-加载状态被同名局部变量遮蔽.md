# 加载状态被同名局部变量遮蔽

状态：已修复（加载状态及事件回归通过）。优先级：P2。

类中已有成员 `FIsLoading`，用于加载时阻止中间状态的事件通知。但 `LoadBinary` 又声明了同名局部变量，函数里改动的只是局部变量，事件处理检查的成员状态并没有因此改变。

应去掉同名局部变量，明确设置成员，并用 `try…finally` 恢复进入前的状态。完整加载后再发出必要通知，避免界面和监听器接触到还没读完的模型。

代码位置：`Units/FreeSubdivisionSurface.inc` 的[`LoadBinary` 局部声明](https://github.com/markmal/freeship-plus-in-lazarus/blob/1de17e99fb2b1cc559cdf27c5cafb595a627a641/Units/FreeSubdivisionSurface.inc#L4208-L4219)，以及[事件对成员状态的检查](https://github.com/markmal/freeship-plus-in-lazarus/blob/1de17e99fb2b1cc559cdf27c5cafb595a627a641/Units/FreeSubdivisionSurface.inc#L113-L123)。成员定义在 [`Units/FreeGeometry.pas`](https://github.com/markmal/freeship-plus-in-lazarus/blob/1de17e99fb2b1cc559cdf27c5cafb595a627a641/Units/FreeGeometry.pas#L1744-L1751)。

原始检查（修复前）：已确认变量遮蔽，未测量它引起的界面回调次数。修复时记录加载过程的事件，检查正常完成和中途异常两种情况。

## 本项目修复（2026-10-30）

删除 `LoadBinary` 内同名局部变量，设置真正的 `FIsLoading` 成员，并在 `finally` 恢复进入前的值。中途读取失败和进入前已经处于加载状态的情况都覆盖。

选中、变更和活动对象监听器读取时受这个状态保护；主程序打开文件时还会先读入没有主界面订阅的候选模型，成功交接后再通知界面。部分图层事件本身仍是直接调用，不能把本次修复解释为所有直接 `Surface.LoadBinary` 调用都不产生任何事件。
