# 型线图磁盘缓存、剖面增量与首次显示（2026-10-31）

## 这次改了什么

型线图来自船体模型，不是从四个视图的图像反推。原先首次绘制要逐个向 Windows 提交三角形，生成矢量记录，再把记录播放成填色图。这次先把绘图命令放入连续数组，首次显示直接绘制。高倍率需要的矢量记录在实际使用或写缓存时生成。

不能把所有开销都说成消失了：矢量记录工作有一部分被移到了高倍率首次使用和关闭窗口写缓存时；高分辨率填色仍有约 0.25 秒绘制开销。没有降低曲面精度、剖面精度或导出精度。

代码：Units/FreeVectorFillCache.pas，Polygon、Draw、EnsureNative。直接绘制采用 Windows 自身的矢量播放变换，避免两套浮点换算带来像素差异。

## 跨重启磁盘缓存

缓存位置为 `%LOCALAPPDATA%\FreeShip26\LinesplanCache-v2`。它是可丢弃、可重新生成的磁盘缓存，不是 RAM，也不会写进原始 FBM 文件。

缓存身份由实际细分曲面的几何、图层与布局、吃水、颜色、对称、灯光等条件及渲染版本组成，不依赖文件名。相同内容可以复用，改点会改变身份，恢复原模型能恢复原身份。以后修改绘制规则需要提高缓存版本。

保存完整模型空间填色、原始像素和矢量记录，文字与网格重新绘制。缓存带完整性校验；缺失、损坏或不兼容时回退到生成。先写临时文件再替换，单份超过 80 MB 不保存，总量限制为 256 MB，超限删除旧缓存。目录不可写不影响模型保存。写盘放在型线图解绑/关闭时，所以首次生成后应正常关闭窗口或软件；强行结束进程不保证留下缓存。

代码：Units/FreeMeshFingerprint.pas 的 MeshFillFingerprint；Units/FreeVectorFillCache.pas 的 LoadDisk、SaveDisk；Forms/FreeLinesplanFrme.pas 的 DrawInteractionPreview、FSetFreeShip。

## 控制点修改后的增量范围

本次按整条剖面增量更新。每条剖面记录求交所依赖的输入：切平面、候选细分面及其邻接面、折角、控制网拓扑、相关图层开关和简化设置。输入未变化就复用交线，变化则使用原算法完整求交。临时静水力剖面仍走原流程，避免为一次性对象建立昂贵缓存。

9a 实际改点样本有 22 条剖面：13 条复用，9 条重算；恢复控制点后也是 13 条复用、9 条重算。切换简化设置后 22 条全部重算。逐条与独立完整求交相比，坐标、点数和折角一致。

这不是整个船体的局部细分算法。曲面细分和最终填色合成仍保留完整流程，也没有把一条受影响的交线切成小段局部修补。小模型的一次改点可能影响全部剖面，测试不会强行要求固定复用率。

代码：Units/FreeIntersection.inc 的 Rebuild；Units/FreeMeshFingerprint.pas 的 MeshSectionFingerprint。

## 耗时

最终串行测试使用 9a-Женя.fbm，模型含 23,990 个填色三角形。这些是隐藏原生窗口的准备时间，不是实际桌面点击到显示的测量。

| 场景 | 本次测量 |
|---|---:|
| 无缓存首次完整准备 | 448 ms |
| 其中三角形整理、投影、命令收集 | 约 31 ms，原约 220–300 ms |
| 新进程首次读取缓存并准备 | 359 ms |
| 同进程丢弃内存缓存后读磁盘 | 约 229–233 ms |
| 同进程内存复用 | 约 31–34 ms |
| 损坏缓存后首次回退重建 | 564 ms |

新进程还要初始化静水力和布局，不能把同进程约 0.23 秒当成重启后首次打开的速度。旧版完整准备约 0.6 秒。首次还未达到瞬时显示，磁盘读取也还不是个位数毫秒。
