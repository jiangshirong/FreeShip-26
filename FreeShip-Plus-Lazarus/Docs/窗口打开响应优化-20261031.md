# 窗口打开响应优化（2026-10-31）

这次处理型线图和工程设置的打开等待。没有改型线计算精度、几何数据或导出算法。

## 原因和处理

型线图入口在窗口显示前调用 PrepareForDisplay，生成完整首帧后才 Show。9a 模型原先三次准备耗时约 694、592、619 毫秒。改为先显示窗口，标题显示“正在生成型线图…”，再通过消息队列生成完整图形。计算仍在界面线程执行，并没有变成后台计算。

代码：Forms/Main.pas:3587；Forms/FreeLinesplanFrm.pas:231。等待期间重复打开会识别同一窗口；窗口或模型提前销毁时取消排队回调。没有拿缩放截图代替原图。

工程设置原先每次打开都创建窗口，关闭后销毁。改为由当前模型组件持有窗口，后续打开复用原生控件；每次重新填入模型数据，刷新语言选项，重置模态结果。取消的草稿不会带入下次打开。模型组件销毁时一并释放窗口。

代码：Units/FreeProjectSettings.inc:415；Forms/FreeProjectSettingsDlg.pas:400；Units/FreeShipUnit.pas 中 FProjectSettingsDialog。

剖面线本身没有生成型线图完整首帧的开销，隐藏准备测试约 11–19 毫秒。借鉴的是缩短显示前准备的做法，不能直接用它的窗口代码替代型线图渲染。

## 测量和边界

使用 9a-Женя.fbm，在隔离副本中测试。最终串行测试中，型线图打开请求约 3.4–4.7 毫秒返回；随后完整生成约 589–694 毫秒。工程设置再次打开约 5.1、10.6 毫秒；首次打开仍要创建原生控件，不能承诺首次也达到这个速度。之前每次重新创建窗口约 51–60 毫秒。

这些是隐藏原生控件的准备耗时，不是桌面点击到可见画面的实测。测试替换了模态显示，保留初始化和取消流程；耗时作为 review，真实桌面显示为 not_run。不同测试轮次负载不同，不据此给出精确加速倍数。
