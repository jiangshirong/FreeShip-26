# FreeShip 中文和俄语检查

检查日期：2026-10-28。范围是当前源码、窗体资源和 `locale` 中的中文、俄文语言文件。这里记录的是静态检查和隔离环境中的程序检查，并非所有窗口的人工试用或船舶专业译审。

## 使用的语言文件

当前程序使用 `locale/FreeShip.<语言代码>.po`。`Languages` 目录中的旧版 `.ini` 是历史文件，不是当前界面翻译的主要来源。除了语言文件，一些旧代码还会在运行时拼接文字、设置图表标题或下拉选项，因此只统计语言文件无法证明界面已完全翻译。

## 本次中文处理

- 补充并修订主菜单、常用窗口、建模、图层、项目设置、控制点、静水力结果及大量提示的中文；修复部分代码内写死的英文和俄文提示。
- 让新建模型的单位、项目设置的单位和精度、网格方向、龙骨向导、稳性以及部分阻力和推进计算中的下拉选项显示中文，保留原来的选项顺序和设置值。语言选择框显示中文名称，内部继续保存原语言标识。
- 补充部分图表和计算方法说明，保留公式、数值和必要的专业缩写。采用了旧版已有译文、人工修订和自动翻译辅助；技术术语仍需要专业人员结合实际功能复核。
- 中文界面文件现有 3,333 条非文件头、非复数条目，其中 306 条译文为空，3 条标记为待复核。空白包含公式、计量单位、表格符号和控件内部占位文字，不能简单视作 306 处可见英文。尚有部分专业报告的英文列标题、图表标题或动态文字，不能宣称所有界面都已完全汉化。

## 俄语检查结果

俄语也不完整。俄语界面的项目设置窗口中，“Project name”实际仍显示英文；源码和语言文件中还有其他缺失或待核对的窗口文字。本次为新增的下拉选项和部分动态提示增加了俄文，以免新改动造成额外缺失，但没有全面补齐既有俄语翻译。

俄语文件现有 2,638 条非文件头、非复数条目，137 条译文为空，14 条标记为待复核。部分界面文本没有对应词条，这些数字同样不等于实际缺失的界面文字数量。

## 验证与限制

- Windows 版本编译成功；中文和俄文语言文件通过程序使用的 PO 解析与格式参数检查。
- 在隔离环境中检查了主菜单、图层、项目设置、新建模型、网格选项、静水力表头、控制点标题和语言选择映射；中文、俄文切换和格式化警告有程序级检查。
- 用中文和俄文路径中的模型副本检查加载、编辑、保存和重新打开，并检查拓扑、图层颜色及备份行为；原模型和个人设置未用于这些检查。
- 候选程序在隔离目录中启动并保持运行。没有使用桌面控制工具，也没有逐一进行实际鼠标操作、窗口布局、视觉观感或全部计算结果的人工验收。
